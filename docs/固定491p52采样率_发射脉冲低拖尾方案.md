# 固定 491.52 MS/s：发射脉冲低拖尾方案

日期：2026-09-10。目标为实际发射脉冲，非接收 CIR 美化。

## 结论

可以在不改变 native 发射采样率的条件下，使指定远离主峰区间的拖尾达到或优于原 737.28 MS/s 参考；不能同时精确保留原参考的全带宽、窄主瓣和完整波形。建议重新设计发送脉冲，在降采样前完成成形，并标定射频链的复数频响。

优先比较两个发射目标：

1. Gaussian，sigma=2.2～2.5 ns：拖尾低，主脉冲加宽；sigma=2.5 ns 的数字模型在 ±10～100 ns 达到约 −67 dB。
2. Blackman 频谱，半带宽 B=200 MHz：让目标频谱在 ±200 MHz 平滑归零，避开 native Nyquist 边缘，数字模型在 ±10～100 ns 达到约 −59 dB。

这些数值是数字孤立脉冲模型，尚未验证实际 RF 输出。它们改变原始 HRP 成形脉冲，不能沿用“原标准脉冲完全一致”的结论；接收互操作性需要重新验证。

## 为什么先改发射目标

原链路把仍有强频谱的 Butterworth 脉冲送入约 ±245.76 MHz 的限带阶段，引入振铃。应使目标频谱在这一阶段之前就已平滑衰减，而不是在 Nyquist 附近强行抬升已被衰减的频率。

Gaussian：

    p(t) = exp(-(t-t0)^2/(2*sigma^2))
    |P(f)| / |P(0)| = exp(-2*pi^2*sigma^2*f^2)

sigma=2.5 ns 时，目标频谱在 ±200 MHz 约 −42.9 dB，在 ±245.76 MHz 约 −64.7 dB。相比原脉冲在 Nyquist 附近仍约 −3 dB，边界截断的影响显著降低。

Blackman 频谱：

    Ptarget(f) = 0.42 + 0.5*cos(pi*f/B) + 0.08*cos(2*pi*f/B), |f|<=B
                 0,                                         |f|>B

这是给单脉冲的频谱规定形状，不是给整个数据包的时间波形乘 Blackman 窗。通过逆变换获得脉冲，添加固定延迟实现因果 FIR，再与完整包的带符号脉冲序列卷积。

X410 标称可用模拟带宽最高 400 MHz，不能把 491.52 MS/s 当作 ±245.76 MHz 全平坦通带。B=200 MHz 是初始候选，不是实测通带保证；B=180/200/220 MHz 应以实测频响决定。官方依据：https://files.ettus.com/manual/page_usrp_x4xx.html

## 具体接入位置与顺序

本仓库 `generate_uwb_tx_from_decode.m` 第 124～125 行，以及 `generate_uwb_gnuradio_sample.m` 第 124～125 行，是从未成形脉冲序列施加 Butterworth 的位置。应在这里引入可选 pulse shape；保留 code、脉冲时刻、SFD/PHR/PSDU 符号。

注意 `generate_uwb_tx_from_decode.m` 当前要求 fs_tx 与工作采样率相等，本身并不完成 491.52 MS/s 降采样；实际 native 转换必须在真实 TX 导出链中接入。当前未找到并修改外部 C++ 发射工程。

推荐流程：

    带符号的脉冲序列
      → 新脉冲 FIR / Gaussian 成形
      → 可选实测 TX 预均衡
      → 带抗混叠滤波的 32/65 降采样
      → 按完整包检查峰值和 SC16 量化
      → 491.52 MS/s 发射

成形滤波需要连续维护状态，不能在 SYNC/SFD/PHR 边界重置。固定 FIR 延迟需同步到 guard、发射时间和参考模板；不要裁掉前后滤波过渡。脉冲时刻继续保持精确分数采样关系，不要把每个 chip 独立四舍五入到 native 样点。接收参考需使用新的成形响应。

## 标定实际发射链

在小信号线性条件下，设 DAC、插值滤波、模拟 TX 的总频响为 Htx(f)。希望射频复包络为 D(f)，可采用带正则项的预均衡：

    U(f) = D(f)*conj(Htx(f))/(abs(Htx(f))^2 + lambda(f))

应把预均衡限制在可信通带，对弱响应频率加大 lambda，并限制最大补偿增益。目标仍须在带边平滑衰减；不能通过强行除以接近零的 Htx 恢复失去的频带。补偿也需要相位/群时延信息，不能仅修正幅度。

若测量来自 TX→RX 回环，得到的是 Htx*Hrx。要判断实际 TX 波形，必须校准/去嵌接收响应或使用带宽足够且已校准的测量设备；直接反演回环响应不能证明 TX 单独更干净。

## 如何验收

同时报告两侧 3～5、5～10、10～20、20～100 ns 的最大相对幅度和积分尾部能量，以及主瓣宽度、峰值/总能量、相邻双脉冲或双径可分辨性。宽 Gaussian 在 5 ns 附近可能比原 737.28 参考更高，这属于主瓣加宽，不能只截取 >10 ns 来宣称所有拖尾均改善。

依次验证：孤立单脉冲；完整包的脉冲叠加与削顶；带校准的 RF 单脉冲；新模板解调与 CIR；不同增益/频点和弱径场景。增加重采样滤波器阶数只能降低滤波器本身的误差，不能替代目标频谱重新设计。单纯最小相位变换不能保证前后拖尾同时下降；直接截零拖尾会再度产生频谱泄漏。

## 拖尾抢救：截断线性相位 RC 183–240（2026-09-10，新默认）

min-phase 把全部相位代价堆在主峰后，200 MHz −3 dB 下 post 10–100 ns 只有
−17 dB。改回线性相位可让拖尾对称：线性 RC 的 −3 dB 点在线性过渡的
x = 1−1/√2 处，令 f1 = (200 − x·f2)/(1−x)，取 f2=240 得 f1≈183.4 MHz；
再把 2049-tap 对称核截断到峰位 tap 32（1025 taps），得到因果、
群时延 32 work taps 的线性相位核。
