## 1. 问题

新 X410 使用 **CG400** FPGA 镜像时，主机可见的采样率选项只有
**491.52 MS/s**，不再提供 UC200 的 737.28 MS/s。

雷达 CIR / SFD 算法仍冻结在 **998.4 MS/s** 整数码片网格
（`samples_per_symbol = 1016`，`sampled_code` 每 chip 2 样点）。不能把
现有 `estimateCir` / `UwbRadarCirEstimator` 直接接到 491.52 网格上。

因此生产顺序变成：

```text
X410 CG400 timed burst  SC16 @491.52 MS/s
  → 窗内 SC16→CF32
  → PDU 65/32（本方案新增）
  → CF32 @998.4 MS/s
  → UwbRadarCirEstimator → CirWriter
```

737.28 → PDU 65/48 → 998.4 继续服务 UC200；两条 native 率并存，禁止混用
sample index。

## 2. 速率合同（精确、固定 profile）

```text
491.52e6 × 65 / 32 = 998.4e6          精确成立
737.28e6 × 65 / 48 = 998.4e6          既有，不改
737.28e6 × 2  /  3 = 491.52e6         两 native 率互为 3/2
```

| 域 | 采样率 | 用途 |
|---|---|---|
| Work | 998.4 MS/s | SFD、SYNC 回推、CIR、demod |
| UC200 native | 737.28 MS/s | 既有 X410 / 65/48 |
| CG400 native | 491.52 MS/s | 本方案；TX 与 RX **同一** radio 率 |

不做伪通用运行时 L/M。第二份固定合同是 **L=65, M=32, 491.52→998.4**。

TX 波形：998.4 整包一次性 `resample(x, 32, 65)` 得到 491.52 native。
禁止把 751 点单 SYNC 模板重复成包，也禁止 737.28 包再 2/3 抽点
（那会错相位）。

## 3. Nyquist 限制（必须写进验收，不能藏）

UWB BPRF 占用约 ±249.6 MHz。CG400 复数 491.52 MS/s 的 Nyquist 是
±245.76 MHz，带沿各少约 3.84 MHz。这是 **FPGA/DDC 硬件上限**，软件
65/32 不能补回被模拟/数字前端滤掉或混叠的能量。

65/32 抗镜像滤波器的通带必须落在 491.52 Nyquist 之内。CIR 距离栅格
仍按 998.4 tap（约 0.15 m/tap）报告，但有效射频带宽受 491.52 前端限制。
不得把 CG400 路径写成“与 737.28 信息带宽等价”。

## 4. 为什么是 PDU 65/32，不是连续流、也不是 65/48 级联

GNU Radio 同类块：`gr::filter::rational_resampler_ccf` 是 **stream**
`gr::block` + `forecast/general_work`，taps 按 `i % interpolation` 拆相，
默认 TPP_ALL。本仓库已有结论：连续 host 65/48 达不到 737 in MS/s 实时，
已关闭。491.52 连续升到 998.4 同样不作为生产主线。

本 OOT 的正确同类是 **`UwbPduRationalResamplerCcf65_48`**：

- 块类型：`gr::block`，0 流端口，message PDU
- 调度：无 `forecast` / `general_work`；handler 对每个窗 one-shot
  `process+flush`
- 热路径：scratch 在 `make()` 预分配，handler 不扩容
- 契约：scipy/MATLAB `upfirdn`，`Lout = ceil(((N-1)·L+T)/M)`，
  `map(p) = round((p·L+(T-1)/2)/M)`

491.52 窗约 2/3 于 737.28 同墙钟窗，FIR 更轻。级联
491.52→737.28（3/2）再 65/48 会叠两套群时延，禁止。

不实现连续流 `UwbRationalResamplerCcf65_32`。

## 5. 块与 core 设计

### 5.1 Polyphase core

将 `RationalResampler65_48Core` 改为

```text
template<uint32_t Interp, uint32_t Decim>
class RationalResamplerLmCore

using RationalResampler65_48Core = RationalResamplerLmCore<65, 48>;
using RationalResampler65_32Core = RationalResamplerLmCore<65, 32>;
```

算法、VOLK/AVX2 宏块、chunk 不变性保持不变。65/48 QA 必须继续逐样本通过。
`schedule_arm_` 仍是 `uint8_t`（L=65 可放下）。

### 5.2 PDU 块

新增 `UwbPduRationalResamplerCcf65_32`，与 65/48 **并列固定 profile**，
不把 65/48 类改成运行时 L/M。

| | 65/48 | 65/32 |
|---|---|---|
| 输入率 | 737.28e6 | 491.52e6 |
| 输出率 | 998.4e6 | 998.4e6 |
| `validate_input_rate` | 必须匹配输入率 | 必须匹配输入率 |
| taps 目录 | `testdata/resampler_65_48/` | `testdata/resampler_65_32/` |
| 默认 profile | `quality_minorder` | `quality_minorder` |

相对通带 −70 dB、纹波 ≤ 0.1 dB。通带不得超过 245.76 MHz：
quality B=220 MHz，realtime B=180 MHz。DC 增益 = 65。

### 5.3 雷达块改动（增量）

| 组件 | 改动 |
|---|---|
| `radar_pdu_meta` | `is_native_rate` = 737.28 **或** 491.52；`native_decim(fs)`→48/32；`native_span(work, M)=ceil(work·M/65)`；cal delay `native·L/M` |
| `UwbRadarPacketSource` | 接受 491.52；sidecar `tx_length_491p52` |
| `UwbLoopbackEcho` | 491.52 与 737.28 都按对应 M 校验 SYNC/SFD span |
| `UhdBurstBackend` | 请求率必须是两个 native 之一；读回仍严格等于**请求值** |
| `x410_uwb_radar_validate.py` | `--rate` 允许 737.28e6 或 491.52e6；窗几何用该率重算；其它率仍 `rate_contract_fixed` |

CIR estimator **仍然只收 998.4**。坐标禁止跨率复用。

## 6. 窗几何（时间推导，禁止 2/3 搬样点数）

默认 64 SYNC、4z2、pre=2 µs、tail=4.1 µs、range=15 m：

| 量 | 公式 | @737.28 | @491.52 |
|---|---|---:|---:|
| PRI 5 ms | `pri·fs` | 3,686,400 | 2,457,600 |
| pre 2 µs | `llround(t·fs)` | 1,475 | 983 |
| SYNC64 | `ceil(64·1016·M/65)` | 48,018 | 32,012 |
| SFD 4z2 | `ceil(8·1016·M/65)` | 6,003 | 4,002 |
| range 15 m | `ceil(2R/c·fs)` | 74 | 50 |
| tail 4.1 µs | `llround(t·fs)` | 3,023 | 2,015 |

## 7. 验证门

1. 65/48 既有 core/PDU/e2e QA 全绿（无回归）。
2. 65/32 core：impulse/dc/tone/random golden 对 scipy `upfirdn`，`max_abs≤2e-3`；
   scalar==VOLK。
3. PDU 65/32：`bad_input_rate` 拒绝 737.28；`map(p)` 与
   `round((p·65+(T-1)/2)/32)` 一致；SC16 窗内转换。
4. 雷达 e2e：`PacketSource(491.52) → Loopback → PDU 65/32 → CirEstimator`，
   SFD/origin/peak 相对 mapped 真值 ±2 个 998.4 样点。
5. 验证 CLI：`--rate 491.52e6` dry-run PRI=2457600；`--rate 750e6` 仍拒绝。
6. 全量 CTest；`git diff --check`。

未宣称：CG400 实机 smoke/电缆/OTA、491.52 与 737.28 CIR 带宽等价、
连续 host 65/32 实时。
