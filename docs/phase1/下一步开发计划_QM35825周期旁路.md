### P0：真实 X410 接入

新增运行入口：

```text
X410 UHD Source → UwbScheduledExtractor → PacketWriter
```

支持配置：USRP 地址、频点、增益、采样率、`t0/T`、窗口长度、buffer 和输出路径。

第一版保持：

```text
emit_policy = every_slot
verification_enabled = false
min_output_buffer / max_noutput_items = 512k～1M（实机复测）
```

验收：100/200 slot/s 连续运行 10 分钟，schedule index 连续，`dropped_windows=0`，PDU IQ 与源流逐样本一致。

### P0：UHD `rx_time` 与流中断

建立：

```text
UHD hardware time ↔ absolute sample ↔ radar predicted time
```

处理 `rx_time`、overflow、source restart 和采样率变化。发生不连续时：

1. 丢弃不完整窗口；
2. 发布 `rx_discontinuity/schedule_lost`；
3. 使用新 `rx_time` 重映射或暂停；
4. 禁止继续使用旧 sample index。

注意：schedule reset 与 stream absolute cursor reset 必须分离。

验收：注入时间跳变和真实 overflow 后不会静默输出错误窗口。

### P1：时钟漂移跟踪

QM35825 与 X410 时钟独立，固定 ±10 µs guard 不能支持长时间运行。

用高置信 code-9 检测更新预测：

```text
error = detected_start - predicted_start
phase  += alpha × error
period += beta  × error
```

或对最近 32～64 个可靠 start 做稳健线性拟合。

要求：collision/低 metric 不更新；单次修正限幅；连续 miss 时扩大 guard，不因单个干扰时隙立即失锁。

验收：±20 ppm 和实机 1 小时测试中，雷达起点持续位于窗口内。

### P1：可靠写盘

默认窗口约 203,776 complex samples：

```text
100 slot/s ≈ 163 MB/s CF32
200 slot/s ≈ 326 MB/s CF32
```

使用有界异步 Writer，优先连续数据文件加 sidecar metadata，避免每 slot 创建文件。记录队列最高水位、写入延迟和 drop。

验收：200 slot/s 连续写盘 30～60 分钟，队列不持续增长，0 drop。

### P1：MATLAB 逐 slot 闭环

新增 `run_decode_scheduled_windows.m`，对比：

- predicted/window/detected start；
- PDU IQ 与原始文件 IQ；
- code-9 检测、PHR/FCS；
- collision、SIR 和 SIC 前后结果。

未验证成功的 slot 也必须进入 MATLAB。

验收：窗口坐标和 IQ 逐样本一致，干扰严重窗口不被丢弃。

### P2：雷达/通信分类

在后台 scheduled ROI 内计算 code-9/code-10 metric，输出：

```text
radar_verified
radar_metric
comm_present
comm_metric
collision
timing_error_samples
```

分类只增加 metadata，不改变默认 `every_slot` 输出数量。启用前必须测量 200 slot/s 下的 worker 延迟和队列水位。

### P2：自动捕获与重捕获

未锁定时使用短候选：

```text
能量门 → 短 code-9/code-10 分类 → 连续周期确认 → LOCKED
```

通信包不得生成完整 Region。失锁后先扩大预测窗口，再局部搜索，最后才进行全局短分类。
