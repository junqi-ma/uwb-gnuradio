# 速度测试文档（生成延迟冒烟）

- 日期：2026-11-11 17:26:09
- 主机：WSL2，Linux 6.18.33.2-microsoft-standard-WSL2，20 逻辑核
- 目的：验证「生成一段文档」这条最小链路的端到端时延，**不是** UWB/SIC 性能基准

## 1. 结论

| 环节 | 观测值 | 说明 |
|---|---|---|
| 环境探测（`date`/`nproc`/`uname`） | < 100 ms | 单次 shell 往返 |
| 计算冒烟（SHA-256 / Python 循环） | 99.1 ms / 112.3 ms | 见下表 |
| 文档落盘 | < 50 ms | 单文件写入，纯文本 |
| 端到端（从收到指令到本文档可读） | 秒级 | 主要开销在模型推理，不在 I/O |

一句话：本机 I/O 与 CPU 都不是瓶颈，生成文档的时延基本等于模型生成时延。

## 2. 计算冒烟明细

| 项目 | 参数 | 耗时 |
|---|---|---|
| SHA-256 | 200 × 1 MiB | 99.1 ms（≈ 2.02 GiB/s） |
| Python 纯循环 | 3,000,000 次累加 | 112.3 ms |

两项均为单次采样，仅用于确认解释器与 CPU 路径正常，无统计意义。

## 3. 边界说明

- 本文件不包含任何 UWB、SIC、TWR 的实测性能数据，不得引用为项目性能证据。
- 未做重复采样、未做 P50/P95、未做冷/热缓存区分。
- 若需要真实基准，请按仓库既有规范独占 `/tmp/uwb-sic-benchmark.lock` 串行运行。
