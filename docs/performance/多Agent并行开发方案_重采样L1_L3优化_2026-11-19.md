#### 详细技术要求
1. **`RS-1` Burst 零拷贝重采样 + 惰性 `work_` 分配**：
   - 在 `RationalResamplerLmCore` 新增 `size_t process_window_sc16(const std::complex<int16_t>* in, size_t ninput, float scale, gr_complex* out, size_t max_out)`（one-shot 整窗接口，内部包含 reset + head + body + tail + flush）：
     - 开头前导零边界（仅当读取窗口起始落在 `in` 之前时，即开头 `<= 2` 个宏块）拷贝到栈上定长小缓冲 `head_buf`（包含 `H-1` 个前导零 + 足够覆盖这些宏块的输入样点）执行；
     - 中间所有不再触及前导零和结尾越界的完整宏块，**直接以 `in + offset` 零拷贝送入宏块内核**，彻底消灭整窗 1.8 MB `memcpy`；
     - 末尾 remainder 与 flush 零填充拷贝到栈上定长小缓冲 `tail_buf` 一次算完；
     - 若 `ninput` 极短（如 `< 2 * kDecim + H_`）则直接走栈小缓冲回退，确保长度 `0, 1, 7, 48, 65...` 全覆盖。
   - 更新 [uwb_resample_window.h](file:///home/junqima/workspace/uwb-gnuradio/gr-uwb/include/gnuradio/uwb/uwb_resample_window.h) 中的 `resample_sc16_window()`，直接调用 `rs.process_window_sc16(...)`（当 `output` 容量不足 `expected` 时才 resize）。
   - 将构造期 `work_.reserve(H_ + (1u << 20))` 与 `work_sc16_.reserve(H_ + (1u << 20))` 改为**仅在流式 `process()` / `process_sc16()` / `flush()` 首次进入时惰性 reserve**，为每个 worker 节省 ~12 MB 内存。
2. **`RS-2` AVX-512 C1 全宏块单次批处理 + 合并 Tail**：
   - 在 `uwb_rational_resampler_avx512.h/.cc` 中，将 `fir_sc16_macroblock_c1_hp{16,24,32,48,generic}` 升级（或新增 `fir_sc16_macroblocks_c1_hp*`）支持 `size_t n_macroblocks, size_t decim, size_t nout, const C1TailDesc* tails, size_t ntails` 参数：
     - 一次跨 TU 调用内循环处理全部 `n_macroblocks` 个宏块，且每个宏块内顺手把 `kMacroblockTail`（65/48 为 1 个尾部输出）一起算完；
     - `run_mb_sc16_candidate` 循环外只写一次 `current_sc16_` / `have_current_`。
3. **`RS-3` 系数表 64 字节对齐**：
   - 将 `arms_rev_dup_` 与 `arms_rev_dup_scaled_` 改为 64 字节对齐内存（可写一个极简 `AlignedVector` 或 `AlignedAllocator<float, 64>`，基于 `::operator new(n, std::align_val_t(64))`）；
   - 确保 `2 * H_pad_` 为 16 floats（64B）倍数时，AVX-512 内核可安全使用 `_mm512_load_ps`（保留对非 16 倍数 `H_pad` 走 `_mm512_loadu_ps` 的兜底）。
4. **`RS-4` 寄存器滑窗移位 + 消灭 `reuse` 分支 + 向量化成对归约**：
   - 对 AVX-512 C1 路径（`ctr_ == 0` 常见热路径或全部相位）：在 `fir_sc16_4x_impl` 中引入编译期 `ReuseMask` 或针对 4 输出窗口偏移 `w0..w3`（`w3 - w0 <= 3`）的**无分支寄存器滑窗拼接**：
     - 每次 `q` 步进只从 `win0` 连续加载 `v0 = load_sc16_x8_as_ps(win0 + q)`、`v1 = load_sc16_x8_as_ps(win0 + q + 8)`，用 `_mm512_alignr_epi32(v1, v0, shift)`（`shift` 为偏移差 `× 2` 个 32-bit float）直接构造 `x1, x2, x3`，彻底消除每 4 输出 6 条 `jne` 分支并减半 load+convert 次数；
     - 同步优化收尾归约：保持 `(lo256 + hi256) -> (lo128 + hi128) -> unpack_pd` 顺序不变，减少冗余 shuffle。
   - 对 AVX2 C1 路径：将 `w1_same/w2_same/w3_same` 拆入 `fir_avx2_sc16_4x_hp` 之外或使用无分支掩码/分组特化消除热循环内的 `jne` 分支；注意 AVX2 没有单指令跨 128-bit lane 的 `valignd`，请先实测对比避免跨 lane permute 反慢，确保 `memcmp == 0`。
5. **QA 验收**：
   - 在 `qa_uwb_resampler_avx512.cc` 与 `qa_uwb_resampler_burst_opt.cc` 新增用例：
     - `process_window_sc16` / `resample_sc16_window` 与原 `reset + process_sc16 + flush` 覆盖长度 `0, 1, 7, 47, 48, 49, 65, 128, 1024, 4096, 56000` 及 4 组 `65/48` taps + `65/32` taps，**逐位 `memcmp == 0`**；
     - AVX-512 与 AVX2 在开启 `RS-2/3/4` 后继续保持 **逐位 `memcmp == 0`**。

- **涵盖优化项**：`RS-5`

#### 详细技术要求
1. **数据布局与系数压缩**：
   - 设计 `TransposedTapTable`，直接按 `[arm][k]`（`k = 0..H-1`，**无需补齐到 8 的倍数**！）存储预缩放后的标量 float32 系数（或进一步利用偶数长度对称性只存一半、或按 `H` 紧凑展开；优先保证连续读写带宽最小、L1d 命中率最高）。
   - 验证：`realtime (H=21)`、`quality (H=42)` 真正只算 `21` / `42` 个 tap，不再为 padding 0 多算 14.3% FMA。
2. **4-宏块 AVX2 微内核（驻留 `uwb_resampler_transposed.h`）**：
   - 一次处理 **4 个连续宏块**（输入步进 `4 * Decim` 个 SC16，输出步进 `4 * Interp` 个 CF32）。
   - **输入转置与单次转换**：将 `4` 个宏块对应同一相对位置的 `[mb0, mb1, mb2, mb3]` 复数 SC16 样点转为 float32 并打包为 4 复数连续向量 `X_tile[Decim + H - 1]`（即每槽位为 `[re0, im0, re1, im1, re2, im2, re3, im3]`，恰好 1 个 `__m256`！共 `48 + 15 = 63` 个 `__m256` = **2 KB**，稳驻 L1d）。
   - **多输出寄存器复用**：一次同时推进 4 个或 8 个输出相位（如同一 group 内连续 4 个输出 `o0..o3`），对 `k = 0..H-1` 加载 `X_tile[win_off + k]` 与 `_mm256_broadcast_ss(&tap)` 执行 `_mm256_fmadd_ps`，**零水平归约、零 `reuse` 分支**。
   - **输出转置写回**：将 4 个宏块同一输出相位 `o` 的 `[re0, im0, re1, im1, re2, im2, re3, im3]`（可攒 4 个相位一起）用 4×4 复数转置写回 `out + mb * Interp + o`。
3. **8-宏块 AVX-512 微内核（隔离在 `uwb_resampler_transposed_avx512.cc`，带 `UWB_AVX512_TARGET`）**：
   - 一次处理 **8 个连续宏块**：`X_tile[u]` 为 `[re0, im0, ..., re7, im7]`（1 个 `__m512`，`eq16` 全块仅 **4 KB**）。
   - 同时计算 4–8 个输出相位的 `__m512` 累加器，`X_tile` 加载一次喂给多条 FMA，系数用 `_mm512_set1_ps(*h_ptr)`（编译器可折叠为广播内存操作数 `{1to16}`）。
   - 8×8 复数转置写回 `out`。
   - 注意在 `uwb_resampler_transposed.h` 通过 `gr::uwb::core::simd::runtime_supported()` + `UWB_SIMD_HAVE_AVX512` 宏安全分发，遵循 `UwbSimd.cmake` 契约。
4. **头尾与任意长度支持**：
   - 处理整窗 `process_window_sc16_transposed(in, ninput, scale, out, max_out)`：头部前 1-2 宏块、中间 `4-MB`/`8-MB` 批量循环、剩余 `< 4/8` 个宏块 + remainder + flush（复用单宏块/标量参考尾部）。
5. **独立 float64 参考 QA（`qa_uwb_resampler_transposed.cc`）**：
   - 在测试内部实现独立的 `double` 精度 `upfirdn` 参考函数；
   - 覆盖 `65/48`（4 组 shipped taps：`eq16` H=16、`realtime` H=21、`eq32` H=32、`quality` H=42）和 `65/32`（`realtime` H=17、`quality` H=42），覆盖随机 LCG、rails、impulse、非对齐指针、短长度及生产长度（`4096`、`56000`、`450000`）；
   - 断言长度完全匹配，最大绝对误差 `< 1e-5`（远严于既有 `1e-4` 契约），且 AVX2 4-MB 与 AVX-512 8-MB 在 AVX-512 机器上各自严格通过。
