# 距离提升优化：实验数据与解码问题交接

更新时间：2026-11-16。供后续 agent 在已有录波上改进捕获、同步、CFO、SFD 与时间网格算法。

## 1. 当前结论与工作边界

现有失败同时包含**环境非目标信号影响**和**可复现的接收算法问题**。在已选出的 20 个失败时隙中，按已知位置补截后默认算法可恢复 2 个；不同诊断改动的成功集合共覆盖 10 个，并有独立 CRC 复核。尚未将这些改动接入生产接收器，也没有证明全量收包率提升。

优先处理已有因果证据的 SFD 搜索漏峰、内侧 SYNC 命中后的跟踪衔接，以及短峰列导致的周期/CFO 失准；同时检查预测窗口调度。再评估频带抑制。当前不宜优先修改 payload 纠错：大部分失败尚未进入 payload。

本轮工作只增加离线分析工具、切片、图表和报告，没有改生产 DSP、安装库、提交或推送。整理时工作区分支为 `feature/sic-research`，HEAD 为 `487c5d97834ba707d62f2869b3a505b166bf7b37`；它是**交接时源码位置**，不能代替原实验二进制的构建哈希。诊断工具和数据中有未跟踪文件，换 worktree/机器前应显式复制；不要假设 git checkout 自带全部材料。

## 3. 实验配置与原始数据

- DW3000 发送周期 **1 ms**，code 10、256 SYNC、127 B PSDU、6.81 Mb/s；接收工作于信道 5，中心 **6489.6 MHz**。
- X410：**ch3，UHD 天线名 RX1**（用户称第二个物理接收端口 RX2），采样率 **737.28 MS/s**，接收增益 **60 dB**。
- 每距离只采集一组 **2 s**，原始 SC16：小端 int16，I/Q 交错，ADC LSB 单位。每文件 **1,474,560,000 个复样点、5,898,240,000 字节**。
- 七组 metadata 均 `got=requested`、`errors=[]`；无削顶。既有回放零原始丢样、source error、gap、队列丢弃和过期。现有证据不支持本批损失由主机算不过来导致。
- 本实验 `clean` 仅表示没有主动设置干扰源，**不表示场地无环境干扰**。
- 本批 TX 发射功率/衰减值未在采集 JSON 中独立记录，不能直接从历史 1.5 m 实验的“发送衰减 10 dB”推定；继续实测前应回读或补记。天线姿态、场地布局亦没有完整量化记录。

必须保留以下限制：

1. 2000 是采样时长/名义周期，没有独立发送计数。以首个 CRC 成功包建立网格，按最近 1 ms 时隙去重；成功优先，否则取最深失败阶段。5.2 m 没有成功包，原日志统计相位仅来自首个失败候选，不是可靠真实包相位。
2. `NO_WINDOW` 是该名义时隙没有 PACKET 日志，原始 ADC 数据仍在。可能是捕获、失锁、调度接续或边界，不能直接算作不可解调。
3. 0.8 m 唯一名义失败是文件尾部包未完整覆盖；完整包口径为 1999/1999。其他采集边界也应单独报告。
4. 热噪声 SNR 排除了谱异常，不是总 SINR；背景 SINR 来自包外抽样，不是逐包/逐阶段 SINR。原 SNR 脚本使用的包时长近似值与接收器 `capture=329161` 不完全相同，应保留旧结果口径并在新分析中注明改动。
5. 各距离依次采集，背景干扰变化明显。这些结果不能作为只随距离变化的传播曲线，4.2 m 的突降也不能全部解释为路径损耗。

现有全部尝试中，613 次 CFO_FAILED 有 569 次（92.8%）SYNC 峰不足 4；644 次 SFD_FAILED 有 626 次（97.2%）日志定位在 bootstrap SFD。状态是退出位置，不是根因；`sfdmetric=0` 也可能是失败时未填值。

2.5 m 已有同 IQ 的 acquire 对照：**1800/2000（90.0%）**，locked 为 1736/2000；两者成功时隙并集 **1815**。其他距离尚无同等完整 A/B。

## 5. 信号处理链与复现入口

当前顺序：

```text
原始 SC16 → 连续固定单音消除 → 捕获/目标窗装配
→ eq16 65/48 重采样 → SYNC/timing → CFO → 原始 IQ SFD
→ 尾部重跟踪/CFO 重估/最终 SFD → CIR/soft-chip → NS-SFD → PHR → payload/FCS
```

- 固定单音 **−232.96 MHz**（RF 6256.64 MHz），模型每 **20 ms** 更新，以 epoch 前 **0.5 ms** 训练，模型交叉渐变 256 原生样点；原实验已开启消除，不能把未消单音的谱功率全部算作现有解调器所受干扰。
- eq16：1039 taps，65/48，工作采样率 **998.4 MS/s**。系数 `testdata/resampler_65_48/taps_realtime_eq16.txt` 虽名为 txt，实际为二进制浮点资源，勿当文本解析。
- 模板：`testdata/reference_preamble_code10_998p4.cf32`，每 SYNC 1016 工作样点。
- 生产窗口：pre 36864、capture 329161、post 8192，共 **374217 原生样点，约 0.5076 ms**。
- 基线 locked ROI 为 ±256 工作样点，inner symbols=4；初始 SYNC 门限 0.25、尾部 0.20、SFD/NS-SFD 0.30。原始 IQ 与软 chip 指标定义不同，不能直接互比为同一物理 SNR。

在仓库根目录执行单组基线回放，输出到新目录，保留原日志：

```bash
mkdir -p /tmp/uwb_distance_baseline
gr-uwb/build-avx512-smtcheck/apps/uwb_dw3000_live \
  --replay /media/oi/Data/uwb/clean_distance/2026-11-16/d3p8m_period1ms/rx_2s_r01.sc16 \
  --period-ms 1 --workers 4 --sync locked --fused on --cir full \
  --taps eq16 --print packets --summary 1000 \
  > /tmp/uwb_distance_baseline/d3p8m.log 2>&1
```

这是已用的旧构建路径，不代表新修改后的二进制；算法改动须用独立 build 并明确记录路径/构建版本。`build-native-cleanup-main` 的旧二进制曾缺少 `--taps`，不要混用。当前构建方式见 [原生接收与 GNU Radio 构建说明](../原生接收与GNU_Radio构建使用说明.md)。回放与重型编译/SNR 分析串行进行，避免负载干扰。

统计工具在 `tools/rx/summarize_distance_failures.py`：读取各目录既有日志及 summary。新算法验收应另建结果根目录并适配解析，不能把旧 summary 的成功数断言直接用于新结果。

## 6. 环境频谱证据

| RF 频段/MHz | 基带/MHz | 已有观察 |
|---|---|---|
| 6256.64 | −232.96 | 强固定 CW，拔天线后仍存在；来源未彻底定位，生产已消除 |
| 6306.6–6316.6 | −183…−173 | 4.2/5.2 m 时显著增强，额外功率分别 −44.55/−45.21 dBFS，相对 UWB −0.29/+2.08 dB |
| 6384.6–6403.6 | −105…−86 | 突发；多个已定位 Timing/SFD 失败窗中比相邻成功包同带功率高约 12–20 dB |
| 6445.6–6462.6 | −44…−27 | 强短突发；Timing 失败例中同带功率增加约 18–21 dB |
| 6430.72、6584.32 | −58.88、+94.72 | 其他窄线，不能全部视为外部干扰 |

0 dBFS 定义为复数功率 32768² LSB²，**未标定 dBm**。七组频谱每 4 ms 取包间 131072 样点，覆盖整记录的约 4.44%，Welch 32768 点；不能据抽样占比宣称精确连续占空比。

4.2 m 的 6306.6–6316.6 MHz 干扰比 3.8 m 高 **7.17 dB**。另一次有无天线对照中，有天线 ch3 的这一段总功率比无天线 ch2 高 **13.32 dB**，支持环境接收成分的重要性。但通道不同、先后采集、无天线为开路而非 50 Ω 终端，不能精确分离天线效应。

用户观察到宽带成分拔天线后消失，固定 CW 不消失。现有 IQ **没有识别协议**；“路由器、Wi-Fi 6E/7、5G 实验网”仍是假设。

每例以预期起点前 100 µs 至后 900 µs 的原始 1 ms SC16 切片保存；`manifest.json`、各 JSON、`summary.csv` 保存源文件、绝对偏移、实际 DSP 窗和前后成功锚点。位置由前后各三个 CRC 成功包验证，锚点最大残差约 **0.64 原生样点**；15 个已记录失败窗的预测起点误差不超过约 1 原生样点。

完整 256 SYNC 的模板投影与相邻成功包基本保持，支持目标信号在窗中。但未解码样例不能据此独立证明完整 PSDU 正确发送；5.2 m 也不在这些已确认例子中。

关键例子与优化方向：

| 优先项 | 证据与因果对照 | 建议改进与验证 |
|---|---|---|
| **SFD 粗搜索漏峰** | `sfd_failed_01`：真峰位置 310027，metric 0.305931>0.30；stride=8 粗格点最大仅 0.018934，只在错误粗峰旁细搜。**仅 stride 8→1 即 CRC 成功**，CFO/门限不变；有独立 NumPy 复核 | 保证窄峰覆盖，比较全搜、多个格点/候选精搜等；验证所有格点相位、真峰覆盖、误检及耗时 |
| **inner SYNC 衔接** | `cfo_failed_02/03/05`：#2 达门限反推起点，后续却从 #1 跟踪，#1 弱于 0.25 便 break，最终仅 1 峰，未进入 CFO 拟合 | 从实际命中符号延续/允许受控缺失，保留真实符号索引；同步检查复相关相位和峰坐标一致性 |
| **短峰列周期估计** | `sfd_failed_05`：24 SYNC 得 1016.025652，累积 6.57 工作样点误差；原始 SFD 两次已过，软 chip NS-SFD 仅 0.1493。**只设名义周期**便 NS-SFD=0.7992、CRC 成功 | 稳健拟合、置信度/跨度约束、历史周期保持，锚定 SFD 后重估；名义周期仅为因果诊断，必须兼容真实 SFO |
| **CFO 少峰失准/保持** | `sfd_failed_04`：5 峰给 −16.57 kHz；**只替换为邻成功包 +2.055 kHz 即 CRC 成功**。其他样例借用 CFO 仍失败 | 建立有质量门限的跨包 CFO 先验/保持，处理过期、失锁和跳变；不能把未来成功包先验用于正式线上验收 |
| **预测窗接续** | `no_window_02/03`：原日志无窗，补截后默认 CRC 成功 | 记录反馈应用游标，研究缓冲历史补截/去重；不能仅按日志空档断言具体分支 |
| **干扰下归一化与跟踪** | 五例 Timing 前五 SYNC 均未过 0.25；同带功率上涨但模板投影基本稳定。02/05 后段前导恢复，现算法却早退 | 受控容错跟踪、后段重捕、鲁棒归一化/频域抑制。单降 SYNC 至 0.20，五例均未恢复 CRC |

`cfo_failed_01/04` 的 CFO_FAILED 实为首次 SFD 通过后的尾部 40 SYNC 重跟踪失败。`sfd_failed_03` 则初始有 239 峰，干扰出现在尾部及 SFD，SFD metric 0.1857，本轮诊断未恢复。这些例子说明不能按最终状态“一刀切”修复。

预测调度还需理解状态机：VERIFY/LOCKED/HOLDOVER 均可预测窗；当前连续失败 3 次进入 HOLDOVER，8 次进入 REACQUIRE 并停止原周期窗调度。4.2 m 有 29 次重捕获，5.2 m 从未锁定。`next_future_slot()` 选接收游标之后的窗，异步反馈接续可能遗漏尚可从历史缓冲恢复的时隙，但目前缺精确游标日志做逐例证明。

## 9. 建议开发顺序与验收

1. **固定回归基线。** 用现有二进制和相同 IQ 核对日志/计数；保存新实验的源码版本、构建配置、参数和新日志。先跑 20 例和相邻成功对照，再做七组全量回放。
2. **先做有独立证据的小修复。** SFD 窄峰覆盖、inner SYNC 跟踪与峰相位/坐标，各自单独 A/B，避免多项同时修改后难以归因。
3. **再做稳健时间/CFO 模型。** 少峰质量评价、缺失符号拟合、历史保持；验证低 SNR、突发、真实 ±SFO/CFO、失锁重捕和参数突变。周期锁定的逐包一致性限制仍须遵守。
4. **处理窗口连续性与频谱异常。** 给调度增加能定位空档的日志；频带抑制应放在捕获之前才可验证恢复无窗的效果，同时量化 UWB 信号损失、模板失配和真实 CRC。
5. **全量验收后再上板。** 比较每距离去重成功数、新增成功/丢失成功时隙、各失败阶段、误触发/重复、零 gap/drop/queue loss，以及 compute/demod p95/p99。离线全速改善还需验证 1 ms 实时吞吐；每次只测 2 s 的 PRR 不足以证明长期稳定。

验收至少保住 0.8/1.6 m 基线，同时提高 2.5–4.2 m，明确报告 5.2 m 的真实相位与捕获不确定性。新增成功应有完整 PSDU/FCS，并尽可能与发送内容/序号核对。降低门限或历史先验算法需加入无目标信号、仅干扰录波等误检检查；不能以探测到相关峰替代 CRC 成功。
