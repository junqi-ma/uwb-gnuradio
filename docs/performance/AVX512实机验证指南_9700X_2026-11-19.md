# AVX-512 实机验证指南（AMD Ryzen 7 9700X）

本文档用于在支持 AVX-512 的机器（如 **AMD Ryzen 7 9700X**）上验证本轮 `RS-5` 转置重采样 AVX-512 内核、既有 AVX-512 重采样/SIC 内核以及 `UWB_SIMD=AVX512` 构建下的端到端性能与逐位一致性。

> [!NOTE]
> 当前开发机为 Intel i7-12700（仅支持 AVX2/FMA，不支持 AVX-512），因此 `UWB_SIMD=AVX512` 仅完成了编译验证，尚未执行 AVX-512 运行时测试。

---

## 一、环境准备与双构建（AVX2 对照 vs AVX-512）

在仓库根目录执行：

```bash
git fetch origin
git checkout feature/sic-research
git pull origin feature/sic-research

# 记录当前硬件与提交信息
git rev-parse --short HEAD
lscpu | grep -E "Model name|Architecture|CPU\(s\)|Flags"

# 1. AVX2 基线构建（同机对照）
cmake -S gr-uwb -B gr-uwb/build-avx2 \
  -DCMAKE_BUILD_TYPE=Release \
  -DUWB_SIMD=AVX2 \
  -DENABLE_UHD_BACKEND=AUTO
cmake --build gr-uwb/build-avx2 -j

# 2. AVX-512 构建
cmake -S gr-uwb -B gr-uwb/build-avx512 \
  -DCMAKE_BUILD_TYPE=Release \
  -DUWB_SIMD=AVX512 \
  -DENABLE_UHD_BACKEND=AUTO
cmake --build gr-uwb/build-avx512 -j
```

> 请在 CMake 输出中确认 `UWB_SIMD=AVX512` 生效，且 `UWB_SPARSE_MF_AVX512_16LAG` 为 `ON`（默认随 AVX-512 开启）。

## 二、核心 QA 与逐位一致性回归

所有测试均需加 `env -u LD_LIBRARY_PATH`，避免命中系统旧安装库：

```bash
# 1. AVX-512 与重采样/解调核心 QA
env -u LD_LIBRARY_PATH ctest --test-dir gr-uwb/build-avx512 \
  -R "avx512|resampler_transposed|resampler_burst_opt|uhd_sc16_pipeline|demod_core" \
  --output-on-failure

# 2. 单独运行 AVX-512 与转置内核 QA（查看详细输出）
env -u LD_LIBRARY_PATH ./gr-uwb/build-avx512/lib/uwb_qa_uwb_resampler_avx512.cc
env -u LD_LIBRARY_PATH ./gr-uwb/build-avx512/lib/uwb_qa_uwb_resampler_transposed.cc
env -u LD_LIBRARY_PATH ./gr-uwb/build-avx512/lib/uwb_qa_uwb_demod_sic_avx512.cc

# 3. （可选）全量 CTest
env -u LD_LIBRARY_PATH ctest --test-dir gr-uwb/build-avx512 --output-on-failure
```

**验收标准**：所有用例 100% 通过，特别是 `uwb_qa_uwb_resampler_transposed.cc` 中 AVX-512 路径与标量/流式路径的逐样本一致性检查。

## 三、重采样微基准对比（`RS-5` AVX-512 vs AVX2 vs `c1_fixed_phase`）

使用 `taskset -c <CPU_ID>` 绑定单个物理核（建议避开 0 号核，例如 `-c 2`），串行运行以下 4 组对比（450,000 samples 窗口，`--fixed-phase 1 --window-mode 1`）：

```bash
CORE=2

for TAPS in \
  testdata/resampler_65_48/taps_realtime_eq16.txt \
  testdata/resampler_65_48/taps_realtime_minorder.txt \
  testdata/resampler_65_48/taps_quality_minorder.txt
do
  echo "=== $TAPS ==="
  echo "[AVX2 build | c1_fixed_phase]"
  env -u LD_LIBRARY_PATH taskset -c $CORE ./gr-uwb/build-avx2/apps/benchmark_sc16_burst_core \
    --taps "$TAPS" --length 450000 --reps 30 --warmup 10 \
    --fixed-phase 1 --window-mode 1 --kernel c1_fixed_phase

  echo "[AVX2 build | transposed]"
  env -u LD_LIBRARY_PATH taskset -c $CORE ./gr-uwb/build-avx2/apps/benchmark_sc16_burst_core \
    --taps "$TAPS" --length 450000 --reps 30 --warmup 10 \
    --fixed-phase 1 --window-mode 1 --kernel transposed

  echo "[AVX512 build | c1_fixed_phase]"
  env -u LD_LIBRARY_PATH taskset -c $CORE ./gr-uwb/build-avx512/apps/benchmark_sc16_burst_core \
    --taps "$TAPS" --length 450000 --reps 30 --warmup 10 \
    --fixed-phase 1 --window-mode 1 --kernel c1_fixed_phase

  echo "[AVX512 build | transposed]"
  env -u LD_LIBRARY_PATH taskset -c $CORE ./gr-uwb/build-avx512/apps/benchmark_sc16_burst_core \
    --taps "$TAPS" --length 450000 --reps 30 --warmup 10 \
    --fixed-phase 1 --window-mode 1 --kernel transposed
done
```

重点记录每组的 `mean_us` / `p50_us` / `p95_us` / `MS/s`：
1. `AVX512 transposed` 相比 `AVX2 transposed` 的加速比（关注 9700X 上双发射 512-bit/AVX-512 FMA 吞吐与 L1/L2 缓存行为）。
2. `AVX512 transposed` 相比 `AVX512 c1_fixed_phase` 的加速比（检查 `eq16` / `realtime` / `quality` 是否均明显更快）。

## 四、端到端 `uwb_dw3000_live` 回放对比（AVX2 vs AVX-512）

建议在 9700X 上使用同一份 SC16 录波/合成文件，按 **ABBA** 顺序对比 `build-avx2` 与 `build-avx512`（单 worker、关闭干扰/单音模块以测纯接收链路）：

```bash
# 若没有现成 clean comm SC16 文件，可用仓库内置工具或已有录波文件；
# 例如使用 <REPLAY_SC16> 路径，按 A(avx2) -> B(avx512) -> B(avx512) -> A(avx2) 顺序运行：

for BIN in ./gr-uwb/build-avx2/apps/uwb_dw3000_live ./gr-uwb/build-avx512/apps/uwb_dw3000_live; do
  echo "=== $BIN (timing-sparse on) ==="
  env -u LD_LIBRARY_PATH taskset -c 2,3 $BIN \
    --replay <REPLAY_SC16> --mode continuous --sync acquire \
    --cir full --fused on --workers 1 --period-ms 5 \
    --interference off --tone off --print summary --summary 40

  echo "=== $BIN (timing-sparse off -> auto shaped MF) ==="
  env -u LD_LIBRARY_PATH taskset -c 2,3 $BIN \
    --replay <REPLAY_SC16> --mode continuous --sync acquire \
    --cir full --fused on --workers 1 --period-ms 5 \
    --timing-sparse off \
    --interference off --tone off --print summary --summary 40
done
```

重点对比两项指标：
1. `FCS` 成功率是否与 AVX2 完全一致。
2. `compute_mean`、`resample_mean`、`demod_mean`（重点看 `resample_mean` 与 `UWB_SPARSE_MF_AVX512_16LAG` 对 `demod_mean` 的影响）。

```text
请在这台 AMD Ryzen 7 9700X 机器上完成以下 AVX-512 实机验证，并把完整测试输出与对比表格汇总给我：

5. 若本机有 SC16 回放数据，按 ABBA 顺序对比 `build-avx2` 和 `build-avx512` 的 `uwb_dw3000_live` 单 worker 耗时（`compute_mean`、`resample_mean`、`demod_mean`）及 FCS 成功率；若有异常或 AVX-512 反超/退化情况请特别标出。
```
