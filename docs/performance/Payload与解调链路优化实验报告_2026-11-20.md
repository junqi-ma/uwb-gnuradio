## 3. 实现改动

### 3.1 FEC（`uwb_hrp_codec.h`、`uwb_demod_fec.h`）

- `constexpr` 生成 GF(2^6) 表：`mul[64][64]`、`exp/log`、`inv`、`α^k`、`α^-k`；
  表由原逐位乘法生成，`rs_gf_mul/pow/inv` 的掩码、负指数取模、`inv(0)=0`
  语义不变。
- `rs_syndromes` 改 Horner（j=62→0），`rs_chien_search` 用 `α^-j` 表 + Horner，
  `rs_forney` 的 Ω/奇次导数用查表；Berlekamp-Massey 结构不变、乘法/求逆走表。
- CL-3 4-state ACS 展开为 8 条显式边，保持原 `(st,u)` 全局顺序与严格
  `m < ns[nst]`，tie 语义不变；`N ≤ 2048` 用 8 KB 栈回溯缓冲，超限回退堆。
- 位打包/解包与 `pack_psdu_bytes` 内层展开，语义逐位一致。

### 3.2 融合 CMF（`uwb_rx_fused_cmf.h`）

- 新增 `correlate_payload_fused_cfo(rx_raw, …, cfo_w_rad, …)`：
  `M(s,p) = e^{-jw(win0+off_p)} Σ_m tpl_w[m]·rx_raw[win0+off_p+m]`，
  `tpl_w[m] = Σ_c pn[c]·e^{-j2wc}·h_w[m-2c]`，`h_w[q]=h[q]e^{-jwq}`。
  38 taps 用 8+8 个 44 点半模板（高半模板 = `e^{-j8w}·低半模板`）、
  52 点合并模板；非 38 taps 走通用精确模板路径。
- `dot4_shared_fixed52`：13 组 ×4 复数、0 标量尾，模板每组只 load 一次，
  4 个候选各 2 路独立 `fmaddsub` 累加器。
- 相位用 `double` 递推、每 32 符号 `cos/sin` re-anchor；`cfo=0` 时零三角函数。
- LUT/`h_w`/`tpl` 全部进 `rxfusion::Scratch`，稳态零堆分配；
  `write_complex=false` 时跳过 38 KB 诊断缓冲。

### 3.3 CIR（`uwb_cir_fir_simd.h`、`uwb_demod_softchips.h`）

- `estimate_cir` 在主 SYNC 循环内，对整数网格且位于平均区间、`wlen` 界内的
  最后 32 个 SYNC 同步累加 `cir_avg_tail`，复用主 ramp；任一条件不满足即保留
  原独立 tail 循环（非整数网格、越界、区间外三种回退均实测覆盖）。
- 新增 `dot_avx2_fixed38_x4`：4 个相邻输出（`spc=2`）共享 `h_conj` 遍历，
  每输出保持与单输出核相同的双链累加与归约顺序，逐位一致；尾部 `<4` 输出
  仍走 `dot_avx2_fixed38`。

### 3.4 Wave 2 集成

- `try_fused_payload_decode` 不再对 payload 区间调用
  `rotate_uncovered_tail_range`，`pay_derot` 恒为 0；直接把原始 `rx` 和
  `cfo_w_rad = 2π·cfo_hz/fs` 传给融合内核。
- 失败回退保持原语义：`run_full_stream_fallback` 自行旋转 `[0,n)`，
  非融合 on-demand 路径自行旋转 extension 区间；`timed` fail-closed 未改。
- `DemodScratch::FusedCmfState` 新增 `g0/g1/soft_g0/soft_g1/llr0/llr1` 与
  `detail::PayloadDecodeWorkspace`（`rx_bits/decoded/rs_cw/psdu_bits/llr0_joint/
  llr1_joint`），`decode_payload_hard/soft` 增加可选 workspace 参数并复用容量；
  旧调用（legacy 路径、QA）传 `nullptr`，行为与分配方式不变。

## 7. 目标达成分析

1. **`pay_derot = 0`**：达成。payload 区间不再写入 `scratch.derotated`，
   相位精确融合进模板与符号相位；`cfo40k` 逐包 PSDU/FCS 零差异证明无退化。
2. **`pay_rs`**：control 4.4 µs（达标 1–5 µs）；低 SNR 9.0 µs、40 kHz 8.9 µs
   （目标 1–5 µs 未达，但已是 5.5× 提升）。剩余成本主要是低 SNR 下
   `rs_decode_block` 的 Chien/Forney 路径与 4 块串行。
3. **`pay_vit`**：10.0→8.2 µs、35.5→28.8 µs、28.2→22.7 µs（约 1.23×），
   未达 2–5 µs。Agent A 的反汇编/微基准显示 GCC 已把旧双层循环完全展开并
   常量折叠，展开收益 <10%；本轮保留位精确展开与零堆回溯，但不再宣称更大加速。
4. **`pay_soft` 未达 40–55 µs（实测 80–96 µs）**：
   - L1 常驻微基准中新内核为 **36–45 µs**（1300 符号，cfo=0/40k），说明算术
     已接近目标；
   - 真实 payload 窗口约 `1208 符号 × 128 样本 × 8 B ≈ 1.24 MB`，4 个候选窗口
     合计读取约 `251k complex ≈ 4 MB`（约 1.6× 放大），在共享 L3/DRAM 上
     对应约 50 GB/s 有效带宽，正好解释 80–96 µs；
   - 即瓶颈已从 FMA 吞吐转为**候选窗口的内存读取**。若要继续下探，需要
     候选间共享样本读取（例如按 8-chip 分组重排）或降低精度/分块驻留，
     不属于本轮“精确等价”约束下的安全改动。
5. **`st_cir` 仅 1.13–1.19×（141/145/127 µs）**：
   `estimate_cir` 合并节省约 8–15%，NS-SFD FIR 的 x4 在 on-demand 区间约
   1.34×；但 `st_cir` 还包含 SYNC 相关、模板与固定开销，因此未整体进入
   100–130 µs。`cfo40k` 达到 127 µs。
6. **`st_total`**：1.23–1.36×。payload 已是最大单项，剩余为 timing/SFD/CIR/
   PHR 与固定开销，符合任务书“payload 为第一大热点”的判断。

## 8. 边界、未做与风险

- **未上板**：所有结果为软件/文件回放；未验证 UHD 实时流、队列丢弃、硬件
  CFO/SFO 与多径。
- **未做 AVX-512 运行时验证**：本机无 AVX-512，仅 `build-resamp-avx512`
  编译通过；9700X 数据缺失。
- **未做 MATLAB 交叉验证**：本轮改动为查表/代数重排/展开，已用逐位参考与
  标量 derotate 参考验证；未逐样点对照 `UWB_demodulation/`。
- **浮点边界**：融合相位使用 `double` 递推 + 每 32 符号 re-anchor；与生产
  4 链 derotator 的数值差约 `1.7e-5`（Agent B 自测），但端到端 6 组夹具
  逐包 PSDU/FCS 完全一致。若未来修改 derotator 内核或 `-ffp-contract`，
  需重跑本报告 §5.4。
- **性能环境**：共享主机、频率不可控；ABBA 每侧 4 次 run 取中位数，已给出
  极值。绝对 µs 不应与其它机器/其它日期直接比较。
- **RS 5 符号错误**：RS(63,55) 最小距离 9，存在 5 错误字恰好距另一码字 4 个
  符号的“误纠”情形；QA 要求新旧实现一致，不把该情形当作可纠能力。
- **Viterbi 栈占用**：`N ≤ 2048` 时每次调用多 8 KB 栈帧；超限自动回退堆。
- **CIR x4 收益依赖缓存规模**：L1 常驻仅约 1.06×，生产流式读取收益更大；
  非整数网格、稀疏 RAKE、Volk/multi-acc 路径未改动。
