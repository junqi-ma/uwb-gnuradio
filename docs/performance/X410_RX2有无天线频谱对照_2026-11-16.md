# X410 RX2 有无天线频谱对照（2026-11-16）

通道 2 未接天线、通道 3 接天线的两组 1 s 实采频谱差异明显：**通道 3 的 6306.6–6316.6 MHz 有强烈且随时间变化的频谱隆起，平均同带总功率比通道 2 高 13.32 dB（约 21.5 倍）**。此前距离实验中关注的这一段，在本次接天线数据中再次出现；未接天线数据中没有同样明显的宽带突发结构。

这支持环境接收信号是此前宽带成分的重要来源。两次采集使用不同通道且依次进行，不能将所有功率差值精确归因于天线，也不能据此给信号标注 5G/Wi-Fi 协议。通道自身的窄线谱需要单独处理。

## 采集与端口核对

- 中心频率 6489.6 MHz，737.28 MS/s，RX 增益 60 dB，与此前距离实验一致。
- 用户称呼的第二个物理接收连接器 RX2，在当前 UHD 的可选名称中是 **`RX1`**。通道 2/3 查询均为 `TX/RX0, RX1, CAL_LOOPBACK, TERMINATION`。项目既有 `tools/rx/README.md` 和 wrapper 的帮助也注明 `RX1` 为第二接收连接器。本次正式采集显式设置 `--antenna RX1`，回读为 RX1。
- 先采通道 2，后采通道 3，**不是同时采样**。
- 每份原始数据 737,280,000 个复样点、2,949,120,000 字节，精确 1 s；两组 metadata 均 `got=requested`、`errors=[]`。
- 无削顶：通道 2 最大分量绝对值 827 LSB，通道 3 为 2536 LSB。
- 原始文件目录：`/media/oi/Data/uwb/antenna_comparison/2026-11-16_151907/`。

正式分析使用：

| 条件 | 文件 |
|---|---|
| 通道 2，物理 RX2，无天线 | `ch2_rx2_no_antenna_r02_1s.sc16` |
| 通道 3，物理 RX2，有天线 | `ch3_rx2_with_antenna_1s.sc16` |

目录内另外保留了最初以 `--antenna RX2` 发起的通道 2 检查采集 `ch2_rx2_no_antenna_1s.sc16`，驱动回读 RX1。它没有用于本报告的数值比较，正式采集改用受支持的名称。

## 主要频段

下表是**估计包间空隙内的同带宽总功率**，包含该段噪声；固定单音单列。统一以复数功率 32768² LSB² 为 0 dBFS，未标定为天线端 dBm。

| 射频频段 / MHz | 通道 2 无天线 / dBFS | 通道 3 有天线 / dBFS | 有天线组高出 / dB |
|---|---:|---:|---:|
| **6306.6–6316.6** | **−61.42** | **−48.10** | **+13.32** |
| 6371.6–6381.6 | −62.28 | −60.37 | +1.91 |
| **6384.6–6403.6** | **−59.84** | **−55.07** | **+4.77** |
| **6445.6–6462.6** | **−61.28** | **−58.10** | **+3.18** |
| 6480.6–6490.6 | −64.42 | −61.35 | +3.07 |

6306.6–6316.6 MHz 在有天线组平均高于估计同带宽底噪 17.82 dB；扣除该估计底噪后额外功率为 −48.17 dBFS。总功率中位数 / 95 分位 / 最大值分别是 −48.45 / −44.80 / −43.81 dBFS，存在明显时间起伏。无天线组同频段中位数 / 95 分位 / 最大值约 −61.42 / −61.23 / −61.07 dBFS，较稳定。

6384.6–6403.6 MHz 有天线组的最强空隙窗口总功率达到 −38.31 dBFS，无天线组最大约 −59.56 dBFS。

6445.6–6462.6 MHz 则以短突发为主：有天线组中位数 −62.99 dBFS、95 分位 −62.27 dBFS，但最强窗口 **−40.47 dBFS**；无天线组最强窗口 −60.97 dBFS。突发峰值相差约 20.5 dB。这里的峰值是 177.78 µs 窗口的积分平均功率，不是单样点峰值。

## 固定单音与其他窄线谱

6256.64 MHz（基带 −232.96 MHz）由精确频率投影直接测得，**不因本次无天线条件而完全消失**：

| 条件 | 单音功率 / dBFS | 单音复数 RMS / LSB |
|---|---:|---:|
| 通道 2，无天线 | −47.96 | 131.1 |
| 通道 3，有天线 | −31.11 | 911.7 |

相差约 16.84 dB。由于通道也不同，这不是同一通道拔插天线后的衰减测量，不能据此定位单音来源。结合用户此前同通道拔天线后单音仍在的观察，它应与环境宽带成分分开分析。

另外，**无天线通道也有明显窄线**：

- 通道 2：约 6563.84 MHz（基带 +74.24 MHz）窄线额外功率 −65.08 dBFS，最高频点比局部底噪约高 24.5 dB；约 6451.20 MHz（基带 −38.40 MHz）窄线为 −74.67 dBFS。
- 通道 3：约 6430.72 MHz（基带 −58.88 MHz）窄线额外功率 **−54.99 dBFS**；约 6584.32 MHz（基带 +94.72 MHz）为 −74.74 dBFS。相应频率在通道 2 中未见同样明显的线谱。

窄线功率以中心 ±0.15 MHz 积分并扣除附近局部底噪。单个 FFT 频点的峰值高出底噪多少，与积分功率是不同量。通道 2/3 的窄线位置不同，说明**不能把全部窄线都当成环境干扰**；内部杂散、通道相关耦合、开路输入拾取等仍需区分。未接天线是开路输入，不等价于 50 Ω 匹配终端。

## 频谱处理与结果边界

1. 对每个 1 ms 段独立拟合已知 −232.96 MHz 单音并扣除，避免强单音淹没其他成分；原始单音功率另行保存。此处拟合不是实时接收器的 20 ms 模型更新算法。
2. 整段频谱采用 Hann、32768 点、无重叠 Welch。每个 1 ms 段使用 22 个 FFT，覆盖该毫秒的约 97.78%；频点间隔 22.5 kHz，Hann 等效噪声带宽 33.75 kHz。
3. 另从 1 ms 折叠功率估计包起点，在预测空隙中央取 131072 样点（177.78 µs）作 50% 重叠 Welch。通道 2/3 分别使用 999/1000 个窗口；通道 2 因最后窗口越过文件尾而少用 1 个毫秒。该相位估计没有经过包解码确认，所以称为**估计空隙**。不以此证明所有窗口严格无 UWB。
4. 两组折叠功率的 90/10 分位对比：无天线仅 0.024 dB，有天线约 1.396 dB。无天线组没有明显的 1 ms 折叠包络；有天线组存在相位结构，但尚未据此判定协议或包成功率。
5. 整段频谱与估计空隙频谱都呈现相同的主要窄频带隆起，支持这些峰并非仅由目标 UWB 包内能量造成。时频图中的宽带突发只在有天线组明显出现。
6. 估计底噪仍用频率中位 PSD，通带并非完全平坦；无天线组某段“高于全带中位底噪”不自动代表该段存在外部干扰。主要对比采用同频段总功率与时间形态。

本次没有改动 DSP 参数、系统网络缓冲设置或解调器，也没有追加发射操作。下一步若需严格排除通道差异，最有价值的是固定同一个通道做有天线 / 无天线 / 50 Ω 终端对照。
