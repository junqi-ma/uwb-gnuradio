## 2. `WindowResult` 新增字段（Subagent B 实现）

// 单调时间戳，供 runner 计算稳态测量区间边界。steady_clock。

## 3. 就绪 / 失败传播接口（Subagent B 实现）

```cpp
enum class WorkerReadyState { Pending, Ready, Failed };

struct WorkerReadyInfo {
    WorkerReadyState state = WorkerReadyState::Pending;
    std::string error;       // state == Failed 时的原因
    bool affinity_requested = false;
    bool affinity_applied = false;
    int affinity_core = -1;
};

class UhdSc16Pipeline {
public:
    // 等待所有 Worker 发布 Ready，或任一 Worker Failed，或 stop()。
    // timeout_ms == 0 表示无限等待（仍可被 stop() 打断）。
    // 返回 true 仅当"全部 Ready"；Failed / 超时 / 被 stop 打断均返回 false。
    bool wait_ready(unsigned timeout_ms = 0);

    bool ready_ok() const;                       // 全部 Ready 且无 Failed
    bool failed() const;                         // 任一 Worker Failed
    const std::vector<WorkerReadyInfo>& worker_ready_info() const;
    std::string init_error() const;              // 首个失败原因，空表示无失败

    const RxDiagnostics& rx_diagnostics() const;
    const CommitDiagnostics& commit_diagnostics() const;
    void reset_diagnostics();                    // 只清计数/累加，不改变功能
};
```

`RxDiagnostics` / `CommitDiagnostics`：

```cpp
struct RxDiagnostics {
    bool enabled = false;
    uint64_t read_calls = 0;
    uint64_t samples_read = 0;         // 实际读入样点
    uint64_t bytes_read = 0;           // samples_read * 4
    uint64_t windows_published = 0;
    uint64_t windows_dropped = 0;
    uint64_t slot_copy_bytes = 0;
    uint64_t stream_buf_resize_count = 0;   // 仅统计"改变容量/长度"的 resize
    uint64_t stream_buf_zero_init_bytes = 0; // 为读入而做的值初始化字节数
    uint64_t compact_move_bytes = 0;   // 缓冲压缩实际移动的字节数
    uint64_t max_buffered_samples = 0; // stream_buf 峰值有效样点数
    double read_us = 0.0;              // source_->read_samples 累计
    double assemble_us = 0.0;          // 压缩/搬移累计
    double slot_copy_us = 0.0;         // slot memcpy 累计
    double dispatch_us = 0.0;          // 池探测 + 发布累计
    double ledger_wait_us = 0.0;       // 账本锁等待累计
};

struct CommitDiagnostics {
    bool enabled = false;
    uint64_t commit_calls = 0;
    uint64_t results_emitted = 0;
    uint64_t max_out_of_order_span = 0; // 最大 (最大已完成 id - next_commit_id_)
    double lock_wait_us = 0.0;
    double reorder_us = 0.0;            // 插入 + 排序冲刷
    double callback_us = 0.0;
};
```

**并发语义**：诊断计数器由 RX 线程 / 各 Worker 线程写入，`reset_diagnostics()` 只在
`start()` 之前或 `wait()` 之后调用；读取只在 `wait()` 之后进行。实现可以用
`std::atomic<uint64_t>`/`std::atomic<double>`+relaxed，或 `std::mutex`；但
**不得**在热路径引入比一次 relaxed atomic 更重的同步，也不得复用 `ledger_mutex_`。

## 4. 就绪屏障语义（A2）

1. `initialize()` 只做内存准备，**不启动采集**。
2. `start()` 先 spawn RX 与 N 个 Worker。每个 Worker：
   - 绑核（若配置）→ 记录 `affinity_requested/applied/core`；绑核失败必须置
     `affinity_applied=false` 并向 stderr 打印一行，**不得**静默当作成功；
   - 在 `try` 中完成全部构造/模板加载/scratch 准备；
   - 成功 → `Ready`；抛异常 → `Failed` + `error`，唤醒等待者；
   - `Ready` 之后才进入消费循环。
3. RX 线程在**全部 Worker Ready** 之前不得调用 `read_samples()`，也不得让源开始
   采集：调用 `source_->start_stream()`（新增虚函数，默认 `return true`）之后才读。
   UHD 源的 `STREAM_MODE_START_CONTINUOUS` 从 `open()` 移到 `start_stream()`。
4. `stop()` 置位 `stop_requested_` 并唤醒 ready 等待者；`wait_ready()` 返回 false。
5. Worker `Failed` 时：RX 不再读流，已准入窗口由对应 Worker 排空/或计入
   `processing_failed`；`wait()` 必须有限时间返回，账本守恒仍成立。
6. `wait()` 幂等；`start()/stop()/wait()` 可重复。重复 `start()` 前必须清除上一轮
   ready 状态。
7. 保持既有退出闸门：Worker 只有在 `rx_finished_` 且池空时才退出，不得因为
   `stop_requested_` 提前退出丢弃已准入窗口。

## 5. 测量字段语义（主 agent 在 runner 实现）

| 指标 | 定义 |
|---|---|
| `cold_total` | `start()` 前一刻到 `wait()` 返回，含初始化、drain、线程退出。保持历史口径。 |
| `startup_ready` | `start()` 前一刻到 `wait_ready()` 返回 true 的单调耗时；失败另报。 |
| `warm_service` | 测量区间内逐窗 `resample_us`/`convert_us`/`sic_us`/`sensing_us` 的 mean/P50/P95/P99。 |
| `steady_throughput` | 测量区间 `[最早 rx_push_time, 最晚 commit_time]` 内 Completed 窗口数 / 区间时长。边界显式打印。 |
| `drain_tail` | `wait()` 返回时刻 − 最晚 `commit_time`。 |
| RX | `rx_diagnostics()` 的累计值 + 派生"每窗字节/样点"。 |
| 提交 | `commit_diagnostics()`：锁等待、重排、回调、最大乱序跨度。 |

区间选择：`--warmup-windows W` 跳过前 W 个 Completed 窗口；`--measure-windows M`
取接下来的 M 个（0 = 剩余全部）。测量窗口数不足 M 时如实报告实际样本数，
**不得**只挑快窗。

诊断计时与正式计时分开跑：正式计时 `enable_rx_diagnostics=false`。
