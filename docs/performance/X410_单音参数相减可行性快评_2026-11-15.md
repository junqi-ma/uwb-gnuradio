# X410 单音参数相减可行性快评

基于此前同一份通道3、40 ms SC16数据，运行 `testdata/capture_compare_20261115_ch3/evaluate_tone_model.py`。未重新采集、未修改生产代码。

## 模型

设单音 `i[n]=c*exp(j*2*pi*f*n/fs)`。已知频率时，复幅度最小二乘估计是 `c=mean(x[n]*exp(-j*2*pi*f*n/fs))`；幅度=abs(c)、相位=arg(c)。频率先FFT粗估，再通过分块复幅度的相位斜率细化。然后生成单音并相减。

本轮为可行性诊断，分块32768样点=44.444 µs，在FFT粗频率坐标系提取每块的单音复投影。用采集起点后0.1–1.5 ms背景段32块估计频率、幅度和相位，并预测后续背景块。评估背景时，离线排除模板参考到达时间前0.4 ms至后0.7 ms，故不是在线盲评。

- FFT插值初估 −232960040.16 Hz。
- 前1.5 ms背景相位斜率细化 −232960000.45 Hz。
- 全部背景事后拟合 −232959999.98 Hz，仅作模型潜力诊断，使用了未来数据。
- 归一化复幅度模约0.01048；背景分块幅度5/50/95百分位为0.010437/0.010495/0.010553。

| 用前段模型预测的背景区间 | 分块单音复投影残余的抑制比 |
|---|---:|
| 0.1–1.5 ms（拟合段） | 47.80 dB |
| 5–10 ms | 34.32 dB |
| 15–20 ms | 26.55 dB |
| 30–40 ms | 20.01 dB |

全背景事后拟合的复投影残余抑制比46.05 dB。

这些数字衡量的是在该粗频率附近、44.444 µs分块上的复投影残余；**不是已生成相减IQ的全带抑制、也不是全部窄带相噪/边带的抑制**。本轮没有输出相减IQ，没有重新运行自相关/解调，没有验证UWB EVM、FCS或弱目标保护。不能据此宣布实际消除链验收通过。

## 判断

该谱线高度接近稳定单音，参数重构相减值得作为陷波的对照。一次估计后整段外推受亚Hz频率误差和相位漂移限制，需要慢速跟踪；不能把FFT峰位置直接当精确频率使用。

建议FFT粗定位→背景段细化频率与复幅度→连续相位NCO重构相减→分块小步更新。前导出现后冻结或减慢参数学习，避免将期望信号的该频率投影学入干扰。跟踪必须保持跨块相位连续，不能重置振荡器。多谱线需多单音模型，相噪/调制边带可能需要更宽模型或滤波。若ADC已饱和，后端相减不能恢复失真。

复杂度：估计和相减均为O(N)，振荡器可递推；与单节IIR陷波同属每样点固定工作量，没有实测不能宣称更快。潜在优势是仅相减所估计的干扰，而不对邻近全部期望信号频率统一施加陷波响应。每块直接拟合并投影仍会消掉期望信号的同频分量，因此背景学习和包内冻结很重要。
