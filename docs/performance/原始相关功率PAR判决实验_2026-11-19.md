# 原始相关功率 PAR 判决实验

## 判决

原生接收器的 `--par-only` 默认值为 `off`。单项实验用 `sync` 或 `sfd`，
直接同时替换用 `both`，带复核的版本用 `guarded`。

| 判决位置 | 原版 | `guarded` |
| --- | --- | --- |
| SYNC 局部捕获 | 归一化峰 ≥ 0.25，或峰 ≥ 0.06 且 PAR ≥ 20。尾部探测使用较低峰门限 | 原始相关功率 PAR ≥ 20。若接受后的跟踪峰少于配置的 CFO 拟合目标（默认 32），尝试现有的相干折叠回退 |
| SFD ±64 样点窄窗 | 归一化峰 ≥ 0.30，或峰 ≥ 0.02 且 PAR ≥ 25。弱峰另检查符号极性 | 原始相关功率 PAR ≥ 25，检查符号极性 |
| SFD ±36 符号网格 | 归一化峰 ≥ 0.008、网格 PAR ≥ 1.5，检查符号极性 | 原始相关功率网格 PAR ≥ 1.5。围绕赢家重新扫 ±64 样点，要求样点域 PAR ≥ 20 并检查符号极性 |

样点域背景排除峰中心 ±12 样点。网格背景排除峰中心 ±2 个符号。
4z2 序列和普通 SYNC 仍有相关，因此网格的两个背景分布分别反映符号序列和样点旁瓣。
`both` 采用同一原始相关功率口径，省去表里的两项复核，保留 SFD 符号极性。

三个搜索都省去逐候选滑窗能量归一化，PAR 通过比较
`peak * background_count >= threshold * background_sum` 判定。
给下游跟踪和诊断的归一化度量只在赢家位置计算。SC16 自相关粗检、
纯绝对门限的跟踪与折叠分支、解码和 FCS 沿用原路径。

## 结果

AWGN 完整帧仿真采用 code 10、256 SYNC、4z2、127 B、1 ms 周期和 ±250 MHz
带内 SNR。固定窗口按仿真真值逐包核对完整 PSDU 和 FCS。
每组固定窗口跳过缺少前保护的第一个时隙。
SFD 位置以 998.4 MS/s 样点计，真值包含 eq16 群延迟。下表是主夹具固定捕获。

| 带内 SNR | 正确完整帧，原版 → 直接替换 → 带复核 | 正确 SFD（±4 样点），原版 → 带复核 | 解调均值 µs，原版 → 带复核 |
| --- | ---: | ---: | ---: |
| +4 dB | 79 → 79 → 79 / 79 | 79 → 79 | 362.6 → 359.7 |
| −8 dB | 119 → 118 → 119 / 119 | 119 → 119 | 649.8 → 393.1 |
| −10 dB | 119 → 119 → 119 / 119 | 119 → 119 | 749.2 → 394.9 |
| −12 dB | 114 → 114 → 114 / 119 | 118 → 118 | 942.8 → 642.1 |
| −14 dB | 0 → 0 → 0 / 119 | 117 → 117 | 3011.7 → 2775.1 |
| −16 dB | 0 → 0 → 0 / 119 | 87 → 103 | 2355.7 → 2557.9 |

在主夹具锁定窗口中，−10 dB 解调由 425.9 降到 397.3 µs，−12 dB 由 628.4
降到 540.1 µs。额外 −8/−12/−16 dB 夹具也保持带复核版的正确 PSDU 集合。
两个种子的 −8 dB 固定捕获中，直接替换分别丢了 1 帧，均能用 SYNC 单项替换复现。
主夹具丢帧的初始 CFO 拟合从 16 个折叠锚点变为 10 个单符号峰，
估计值从 −1.3 Hz 变为 −1813 Hz，最后在 payload 阶段失败。
额外的 +10/+40 kHz CFO 和 +27 ppm SFO 夹具各 40 帧。两种固定策略的正确完整帧
集合与原版一致，三个场景分别为 38、36、39 帧，检出的 SFD 均距仿真真值 ≤ 2 样点。

向 SFD 强制注入位置假设后，两套独立纯噪声夹具共 798 窗，原版 0 次误报，
直接替换 239 次（30.0%），带复核 0 次。完整链路的同批噪声窗口都未进 SFD。
在仅保留前导的负例上，带复核版仍会把残余 SYNC 误判为 SFD。238 个固定窗口中，
捕获误报 4 次，锁定误报 7 次，FCS 均为零。原版两种策略各 0 次误报。
强制注入位置时，原版、直接替换和带复核分别误报 0、21 和 8 次。
这项退化仍然存在，因此保留原版作为默认判决。

在 −16 dB，两套主/额外夹具的正确 SFD 数均增加，完整帧 FCS 均为零，
进入后续解码的窗口增多使整窗解调均值上升。

原生动态回放使用 4 workers、队列 64、默认 FCS 进锁。带复核版与原版逐档有
同一组正确帧（以 CRC 和发端 PSDU 前 12 字节识别）。−12 dB 均为 114 帧，
平均解调耗时 776.2 → 699.1 µs。−16 dB 的 SC16 前端两版均产生 33 个种子，
SFD 通过 21 → 30，FCS 均为零。动态回放无原始采样或队列丢失。

Octave 独立点积复核 −12 dB、−16 dB 和纯噪声各 16 个窗口。
两个实验 SFD 模式共 96 次判决一致，接受位置逐样点一致。
GCC 14.3 构建和原生 CTest 57/57 通过。完整 MATLAB 接收器交叉运行、真实信道、
上板测试尚未执行。

## 峰值及相邻样点的联合判决

`guarded` 的样点域峰值为单个最大相关功率。对于接收到的模板，匹配滤波峰形由
有效 CIR 和模板自相关共同决定，相邻样点通常仍有能量。新增 `--par-only window3`
在 SYNC 捕获、SFD 窄窗和 SFD 网格的样点域复核中比较
\(P[k-1]+P[k]+P[k+1]\) 和背景三点功率和的均值。背景窗整体落在保护区之外，
判决仍用乘法，位置与 CFO 相位仍取相关功率最高的单点。边界处缺少完整三点窗时，
这一候选无法通过三点判决。离散 SFD 网格继续按符号间隔评分。

`--par-only window3-sfd` 只在 SFD 用三点，SYNC 沿用 `guarded` 的单点 PAR。
这两个模式沿用单点实验的数值门限。峰旁能量使分子增加，背景窗求和也提高分母，
所以同一数值门限会改变灵敏度。在各 16 个窗的窄窗 SFD 点积中，−12 dB AWGN
的相邻点功率中位数为峰值的 45% 和 26%，三点 PAR 是单点 PAR 的 57%。
另加一条延迟 1 个工作样点、幅度 0.8 的同相路径后，三点 PAR 保留约 65%。
工作采样率 998.4 MS/s 下，一个样点约为 1.00 ns。

对照沿用上面的夹具、绑核、构建和 ABBA 测量口径。使用 `par_only.py
--par-window window3` 或 `--par-window window3-sfd` 启动对应对照，
每项均以同二进制的 `guarded` 作为单点参照。

两径夹具用发端种子 4218 生成 120 个时隙，在 998.4 MS/s 波形上叠加
`wave[1:] += 0.8 * tx[:-1]`，按首包含回波的 444353 个样点标定 542 LSB RMS，
再用相同 48/65 重采样和种子 4218 加噪。−12 dB、−16 dB SC16 的 SHA-256 分别为
`7f8cd514ac18f701c7049ff1e32e724e017c15b4dc381b454847ca8584d4b2f5`、
`a01f916905b799fd20bf5707e0f213b8c6ea5d2d8e0f8288b5341a3e66d430d3`。

耗时行是最终工作区的两组 ABBA 复测，每组使用同一二进制。
两种三点模式的完整帧正确集合均与各自的单点参照一致。额外 −16 dB 夹具中，
强制注入 SFD 位置时检出 119 → 118，完整解调链路的 SFD 检出数一致。
SYNC 也使用三点时，沿用原数值门限会更常进入宽搜和折叠回退。
主夹具 −12 dB 上，只有 SFD 使用三点保留了固定捕获速度，动态回放的
正确帧保持 114 个，无采样和队列丢失。本轮保留 `off` 为默认值。

命中位置逐样点一致。完整 MATLAB 接收器和上板验证待做。
