# DW3000 原生实时收包控制台（2026-11-15）

启动：`python3 tools/rx/live_dw3000_packets.py`。默认 X410 192.168.10.2、通道 3 / RX1、737.28 MS/s、6489.6 MHz、60 dB；固定 code10/256/4z2/6.8 Mb/s、STS 关闭。Ctrl+C 停止；也可 `--seconds 10`。

## 实现

- Python 入口自动构建当前源码后 exec 原生 `uwb_dw3000_live`，无 GNU Radio scheduler、无 PMT、连续 IQ 不落盘。
- 修复原生 `UhdDeviceSc16Source` 的 RF 参数设置：采样率、频率、增益、回读均指向所选 channel；新增可选 `uhd_antenna`，空值保持设备默认。实机回读 channel=3、antenna=RX1。
- UHD → 生产版固定单音源装饰器（−232.96 MHz、20/0.5 ms）→ SC16 环形历史 → 流式稀疏延迟自相关 → 有界包窗口池 → 私有 scratch 的解码 workers → 有界独立打印队列。
- 自相关 lag=750，每 100 点取一对，60 对滑窗，阈值 0.15、峰值 >0.5、持续跨度至少 50 µs、40 µs 合并间隔、0.8 ms holdoff。不是此前密集 6000 对离线统计的逐值等价实现。每窗 450,000 native 样点、提前 36,864 点；搜索余量与回溯适配盲捕获 seed。
- 默认 2 worker、24 窗池、128×65536 样点（32 MiB）原始队列；全部大缓冲在 start_stream 前分配。`--cir auto` 先用现有 Bypass 最强径采样，有前导和 SFD 但解码失败时用 Full CIR 重试；`--cir bypass/full` 可固定路径。库的解调默认配置不改变。
- 每包打印捕获 id、候选时间、失败阶段、SYNC/SFD/PHR、长度、CFO/拟合点数、FCS、独立 CRC、窗口就绪后的排队加处理时间、重试标志。多 worker 按完成顺序输出。
- 每 50 个完成的候选（包括明确的丢弃/失败）汇总本批和累计 FCS/CRC 成功率、失败原因及完整 CIR 重试数；同步显示源错误、原始队列丢样和 gap。停止时输出不足 50 的部分汇总与 FINAL。无包也每秒 HEARTBEAT。
- RX gap 清空候选与训练连续性；跨 gap 待完成窗口明确报 INVALID_GAP。解码池满报 DROPPED_QUEUE；慢终端只影响有界打印队列，省略行会累计 output_omitted，统计仍保留。停止时先关 UHD，再排空已提交任务。

## 验证

- 本次 1 秒原始实采按采样率回放：自动捕获 200 包，**200/200 FCS 与独立 CRC 通过**；1 包经 Full CIR 重试恢复；4 次完整的 50 包汇总。原始队列丢样、源错误、gap 均为 0。
- 默认配置 X410 3 秒实测：**599/599 FCS 与独立 CRC 通过**，11 次 50 包汇总、1 次 49 包部分汇总；0 原始队列丢样、0 源错误、0 gap；150 次单音模型更新。观察到的最大“窗口就绪到解码完成”时间 12.305 ms，不等于每包延迟都小于 5 ms。
- 开发中另一次 10 秒运行使用早期捕获配置，记录了 10 次源错误/gap，1756 个候选、1734 成功。该日志单独保留，不能由 3 秒成功片段推出长时间零溢出或 PER 通过。
- 新增 CTest 用公开生成的有限 DC burst 验证真实自相关捕获、UWB 模板拒绝、批汇总、SIGINT 排空/退出以及源打开失败，不依赖硬件或私有实采 IQ。
- 全量串行 CTest **84 项：83 通过，1 按设计跳过，0 失败，106.39 s**。跳过为 `uwb_qa_install_consumer`。全量日志包含最新控制台 QA。

数据与源码指纹：`docs/performance/data_dw3000_live_console_20261115/`。实机与回放后只增加了满打印队列时保留最终 FINAL 行的收尾保障；最终二进制通过了全量测试及线程收尾 QA。独立 build `gr-uwb/build-cfo-tail-fix`，未 install、未提交或推送，原有其他工作区修改保留。

成功率分母是捕获候选，未检测到的发射包没有包含在分母中。传输计数约每 100 ms 取快照，最终值在接收停止后刷新。逻辑样点坐标遇硬件丢样不代表完整无线时间轴；gap 会明确输出。本轮不是 ToA/测距、长时 PER 或端到端 P99 验证。
