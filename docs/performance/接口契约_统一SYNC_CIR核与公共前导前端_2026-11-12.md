# 接口契约：统一 SYNC-CIR 核与公共前导接收前端

本文件是 `OpenCode_Sensing与Comm统一前端和CIR_开发方案_2026-11-12.md` 的实施
契约。所有并行工作流必须按本文件的名称、签名、数值顺序和失败语义实现，不得各自
另立约定。基线代码 `bd311cd`，实验分支 `feature/sensing-shared-cir`。

## 0. 硬约束

- 不新增 GNU Radio block，不安装，不上板，不移动 tag，不推送。
- 头文件不得引入 include 环：`uwb_sync_cir_core.h` 只依赖
  `uwb_rx_sync_opt.h` / `uwb_rx_cfo_opt.h` / `uwb_phy_profile.h` /
  `uwb_detector_core.h`，**不得** include `uwb_demod_core.h`、
  `uwb_hrp_mod_core.h`、`uwb_preamble_sic*.h`。
- 公共前导前端**留在 `uwb_demod_core.h` 内部**（方案 §4 允许“先在原头文件内部
  提取”），不新建独立头文件，避免与 `DemodScratch` 形成环。
- 热路径零堆分配、零 vector 增长；所有缓冲在 prepare 阶段按最大窗口预留。
- 失败必须 fail-closed：输出有效长度清零，不返回 seed-only 或上次窗口残留。

## 1. 共享 CIR 内核 `uwb_sync_cir_core.h`

命名空间 `gr::uwb::demod::sync_cir`。

### 1.1 类型

```cpp
enum class SyncCirStatus : uint8_t {
    Ok = 0,
    InvalidInput = 1,        // 空指针/零长/非法 pre/post/未 prepare
    CapacityInsufficient = 2,// scratch 容量不足（prepare 之后不应出现）
    NoValidRepetitions = 3,  // 全部窗口被缓冲边界裁掉
    NonFinite = 4            // 输入或输出出现非有限值
};

struct SyncCirRequest {
    int64_t cir_axis_origin = -1;    // tap0 参考的绝对样点（SYNC 原点）
    double samples_per_symbol = 0.0; // 重复周期 P，可为分数
    size_t total_repetitions = 0;    // 前导 SYNC 总数
    size_t skip_initial = 0;         // 跳过前若干个
    size_t max_repetitions = 0;      // 0 = 用尽剩余
    size_t pre = 0;
    size_t post = 0;
};

struct PreparedSyncCode {
    bool ready = false;
    size_t code_index = 0;      // 9..12，仅作身份记录
    uint64_t fingerprint = 0;   // 原始 ternary code 的 FNV-1a
    rxopt::SparseCirTemplate tmpl; // entries + code_energy，复用现有实现
};

struct SyncCirScratch {
    std::vector<std::complex<float>> avg;  // capacity >= code_len + max_taps - 1
    std::vector<std::complex<float>> raw;  // capacity >= max_taps
    std::vector<std::complex<float>> norm; // capacity >= max_taps
};

struct SyncCirResult {
    SyncCirStatus status = SyncCirStatus::InvalidInput;
    size_t tap_count = 0;
    size_t valid_repetitions = 0;
    size_t first_repetition = 0;
    size_t peak_tap = 0;
    float peak_abs = 0.f;
    float raw_l2_norm = 0.f;
    float code_energy = 0.f;
    int64_t first_window_sample = -1; // 首个合法窗口绝对 lo
    int64_t last_window_sample = -1;  // 末个合法窗口绝对 lo
};
```

### 1.2 函数

```cpp
// 允许分配。code_len 必须是 1016（2*chips_per_symbol）由调用方保证一致性。
bool prepare_sync_code(const int8_t* code, size_t code_len, size_t code_index,
                       size_t max_pre, size_t max_post,
                       PreparedSyncCode& prepared, SyncCirScratch& scratch);

// 纯计算，不分配。返回全部合法窗口（未裁剪）的并集 [lo, hi)，供 CFO 覆盖规划。
// 裁剪规则与 estimate_sync_cir 完全一致：窗口 k 的 lo_k = origin + round(k*P) - pre，
// 只有 lo_k >= 0 且 lo_k + wlen <= n 才参与；本函数返回未裁剪的并集包络。
bool required_input_range(const SyncCirRequest& req, size_t code_len, size_t n,
                          int64_t& lo, int64_t& hi);

// 热路径，不分配。rx 必须是**已经按最终 CFO 补偿**的 IQ。
bool estimate_sync_cir(const std::complex<float>* rx, size_t n,
                       const SyncCirRequest& req,
                       const PreparedSyncCode& prepared,
                       SyncCirScratch& scratch,
                       SyncCirResult& out);
```

### 1.3 数学合同（必须逐条照做）

窗口长 `wlen = code_len + pre + post - 1`，`tap_count = pre + post`。

1. `avg[0..wlen)` 清零。
2. 对 `k = skip_initial .. skip_initial+count-1`，`count = min(max_repetitions
   或剩余, total_repetitions - skip_initial)`：
   - `rs = cir_axis_origin + llround((double)k * P)`
   - `lo = rs - pre`，`hi = lo + wlen`
   - `lo < 0 || hi > n` → 跳过（clipped），不计入分母
   - 否则 `rxopt::vector_accumulate_complex(avg.data(), rx + lo, wlen)`，`valid++`
3. `valid == 0` → `NoValidRepetitions`，`tap_count=0`。
4. `rxopt::vector_scale_complex(avg.data(), 1.f/valid, wlen)`。
5. `rxopt::correlate_cir_sparse(avg.data(), prepared.tmpl, tap_count, raw)` ——
   **注意**：为保持 comm 逐位一致，raw 的直接写入目标就是 `scratch.raw`，
   `correlate_cir_sparse` 内部已做 `/ code_energy`，不要在外部再乘除一次。
6. `nrm = sqrt(sum |raw|^2)`（float 累加，顺序 0..tap_count-1）；
   `nrm <= 0` 或非有限 → `NonFinite`。
7. `norm[i] = raw[i] / (nrm + 1e-12f)`，**不覆盖 raw**。
8. `peak_tap = argmax(|raw|)`（严格大于，首个最大值胜出）；`peak_abs = |raw[peak]|`。

数值一致性要求：comm 现有 `stage_cir_softchips` 的 `values` 等价于本核的
`norm`，必须**逐位相同**（同一 float 运算顺序）。因此第 5-7 步不得改写为
double 累加、不得改变除法顺序、不得先除以 nrm 再做 sparse 相关。

### 1.4 边界

- `pre + post == 0`、`code_len == 0`、`P <= 0`、`origin < 0` → `InvalidInput`。
- `skip_initial >= total_repetitions` → `InvalidInput`（不是 NoValidRepetitions）。
- `wlen > scratch.avg.capacity()` 或 `tap_count > scratch.raw.capacity()`
  → `CapacityInsufficient`，且输出清零。
- 输入含 NaN/Inf 时允许产生非有限 raw，但必须在第 6 步以 `NonFinite` 失败关闭。

## 2. 公共前导接收前端（在 `uwb_demod_core.h` 内）

命名空间 `gr::uwb::demod`。

```cpp
enum class PreamblePurpose : uint8_t {
    SyncSfdOnly = 0, // preamble-only SIC：停在 final SFD，保留现有早停
    CirOnly = 1,     // sensing：补齐 CIR 并集覆盖
    FullPacket = 2   // comm：保留现有按需旋转
};

struct PreambleRxContext {
    bool ok = false;
    DemodStatus status = DemodStatus::InternalError;
    TimingResult timing;     // final（SFD 锚定后的完整 SYNC 网格）
    CfoResult cfo;           // final CFO
    SfdResult sfd;           // final SFD
    double final_cfo_hz = 0.0;
    double samples_per_symbol = 0.0;   // 统一周期 P（measured_period，无效时回退 sps）
    int64_t detected_sync_origin = -1; // 检测原点（timing.preamble_start_sample）
    int64_t phase_reference_sample = 0;// 去 CFO 的绝对参考样点
    size_t covered_lo = 0;             // derotated 有效区间 [lo, hi)
    size_t covered_hi = 0;
    uint32_t cfo_epoch = 0;            // bootstrap=1, final=2；epoch 变化即旧覆盖失效
    bool derotated_valid = false;
    // 子计时（诊断用，父阶段已包含，不得二次累加）
    uint64_t timing_us = 0, cfo_us = 0, sfd_us = 0, coverage_us = 0;
};

bool acquire_preamble(const std::complex<float>* rx, size_t n,
                      const Qm35825Profile& profile,
                      const std::vector<std::complex<float>>& template_wf,
                      int64_t rel_seed,
                      PreamblePurpose purpose,
                      const sync_cir::SyncCirRequest* cir_req, // CirOnly 时必须非空
                      DemodScratch& scratch,
                      PreambleRxContext& out);
```

### 2.1 行为

1. `stage_timing` → `fit_cfo` → bootstrap `stage_sfd` → tail 重跟踪 + CFO 复估
   → final `stage_sfd`，与 `demodulate_one()` 现有顺序和回退完全一致
   （含 `rx_seed_refine_tail` 的 radius-8 → radius-0 回退）。
2. final CFO 确定后**第二次旋转**覆盖：
   - `SyncSfdOnly`：final SFD 搜索区间（现状）。
   - `CirOnly`：`required_input_range(cir_req, code_len, n)` 的并集，**再加**
     final SFD 区间，取两者并集；覆盖不足时先补齐，仍不足则
     `status = CirFailed` 且 `derotated_valid=false`。
   - `FullPacket`：现有 on-demand/整段规则不变。
3. 旋转**始终从 raw `rx` 计算**，不在旧旋转结果上二次相乘。
4. `cfo_epoch`：bootstrap 旋转后为 1，final 旋转后为 2。读取 derotated 的调用方
   必须校验 epoch 与 `[covered_lo, covered_hi)` 覆盖所需区间，否则失败关闭。
5. `phase_reference_sample` = 第二次旋转的绝对相位锚点（当前实现为 0，即
   `dst[i] = src[i]*exp(-j w i)`，i 为绝对样点下标）。sensing 与 comm 共用同一
   约定，跨窗复数相位因此可比。

### 2.2 与 `demodulate_one()` 的关系

`demodulate_one()` 必须改为调用 `acquire_preamble`，不得保留第二份等价实现。
现有 `res.stage_*` 字段语义不变：前端把子计时放进 `PreambleRxContext`，
`demodulate_one()` 负责拷贝到 `res` 并保持“子计时不加给父计时”。

## 3. Sensing 适配

- `RadarCirConfig` 增加 `bool compensate_target_cfo`（默认 true）与
  `size_t max_pre/max_post` 语义不变。
- `RadarCirResult` 增加显式三个原点与 CFO 字段：
  `detected_sync_origin`、`cir_axis_origin`、`phase_reference_sample`、
  `final_cfo_hz`、`valid_repetitions`（已有）、`raw_l2_norm`（已有）。
- `RadarCirCoreScratch` 增加 `sync_cir::SyncCirScratch cir_scratch` 与
  `sync_cir::PreparedSyncCode code`；`RadarCirScratch cir` 保留给
  `estimate_radar_cir_repetition`（逐重复发射）使用。
- `use_predicted_timing=true` 且配置已有目标 CFO 时可直接补偿；需要估计时调用
  `acquire_preamble`。**不得**把“跳过 SFD”当成“目标 CFO 为零”。
- raw/norm taps 必须来自共享核的 `raw`/`norm`，不得复用只有实部的
  `cir_values` 或已归一化的 `cir_filter_taps`。

## 4. 验证门槛（摘要）

- 公共核：codes 9–12、38/116 tap、64/256 SYNC、skip10、整数/分数起点、非整数 P、
  clipped 边界、0 有效重复、容量不足、非有限输入。非零能量例相对 L2 ≤ 2e-5，
  峰 tap 一致。
- comm：黄金向量、PSDU/FCS 逐例一致，失败原因与回退不退化。
- SIC：训练仍限前 8 符号，末 4 SYNC 实减保持。
- CFO 覆盖：bootstrap 与 final CFO 不同时，首/中/末 SYNC 都用 final 补偿，
  无旧 epoch、无 double rotation。
- 距离轴：检测起点变化时 sensing 物理峰**不得**重新归零。
