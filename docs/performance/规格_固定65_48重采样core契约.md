# 固定 65/48 重采样 core/block 实现规格

> 依据：`开发方案_GNURadio软件升采样_737.28M到998.4M.md` §3/§4/§5/§6/§8/§10
> 与 `docs/performance/测试报告_GNURadio软件升采样_65_48.md` §2（契约）。
> 本文是 Claude/Grok 实现 Level B/C 的单一实现规格。

## 1. 数值契约（必须精确复现）

**参考实现 = scipy/MATLAB `upfirdn`（输入两侧零填充的完整卷积）。**

- 输入 `x[0..N)`（737.28 MS/s CF32），taps `h[0..T)`（quality: T=5363；
  realtime: T=2635），L=65, M=48。
- 输出 `y[0..Lout)`，**`Lout = ceil(((N−1)·L + T) / M)`**（逐 N 验证）。
- 相位律：**`y[m] = Σ_k h[(mM mod L) + Lk] · x[floor(mM/L) − k]`**
  - 输出 m 用 polyphase arm `ctr = (mM) mod 65`；
  - 输入窗口 `x[floor(mM/48) − (ceil(T/65)−1) .. floor(mM/48)]`；
  - `x[j] = 0` 当 `j < 0` 或 `j ≥ N`（两侧零填充）。
- 群时延：quality `(T−1)/2 = 2681`（虚拟域）→ 55.85 输出样本、41.25 输入样本。
- 增益：滤波器 DC(sum)=65；重采样器对常数输入的平均增益 = sum/L = 1.0
  （逐样本按 arm 变化）。taps 已含 ×L 缩放，**不再额外缩放**。

**流式 chunk 等价**：core 维护 `hist` 延迟线（长度 `ceil(T/65)`，初值零）与
整数 phase；任意 chunk 切分（含单样本、EOS 尾部 flush）输出 == 一次 upfirdn。
chunk 边界不允许改变样本、长度或 phase。

## 2. core（`uwb_rational_resampler_core.h`，纯算法，无 GNU Radio/PMT 依赖）

```
namespace gr::uwb::core {

class RationalResampler65_48Core {
 public:
  // 构造期：载入并校验 taps，拆 65 相，padding 对齐，预计算每相 taps 起点/长度。
  explicit RationalResampler65_48Core(const float* taps, size_t T);

  // 处理 ninput 个输入，写入 out（容量 ≥ 调用者按契约预留），返回实际输出数。
  size_t process(const gr_complex* in, size_t ninput, gr_complex* out);

  // EOS：以零输入 flush 尾部，返回剩余可输出样本（可多次调用直到返回 0）。
  size_t flush(gr_complex* out, size_t max_out);

  void reset();                     // 清 hist/phase（discontinuity/restart 用）
  uint64_t input_items() const;     // 累计输入
  uint64_t output_items() const;    // 累计输出
  uint32_t phase() const;           // 当前 (output_items·M) mod L
 private:
  // hist 延迟线、phase、taps arms（固定数组/预分配，禁止 process 内分配）
};

}
```

- `process()` 热路径禁止：`new/delete`、`vector` 扩容、PMT、日志、文件 I/O、mutex。
- 保留 **scalar reference kernel**；任何 SIMD/VOLK 版本必须逐样本对照 scalar。
- `flush()` 对 N 输入应使总输出恰为 `ceil(((N−1)·65+T)/48)`（一次调用或分多次）。

## 3. block adapter（`UwbRationalResamplerCcf65_48`）

```
class UWB_API UwbRationalResamplerCcf65_48 : public gr::block {
 public:
  static sptr make(const std::string& taps_path_or_profile);
  // 或 make_from_taps(const std::vector<float>&);
  // profile: "quality" / "realtime"（读 testdata/resampler_65_48/taps_*.txt）
  // 或绝对路径到 float32 二进制 taps 文件。
  // GRC 第一版只暴露 taps 文件/profile、tag_propagation_enable、reset_on_discontinuity。
};
```

- 构造：`gr::block("uwb_rational_resampler_ccf_65_48",
  io_signature::make(1,1,sizeof(gr_complex)), io_signature::make(1,1,sizeof(gr_complex)))`；
  `set_relative_rate(65, 48)`（整数重载）；`set_output_multiple(65)`；
  `set_max_noutput_items(1048576)`；`set_tag_propagation_policy(TPP_DONT)`。
- 不用 `set_history()`（core 内部维护延迟线；避免双重历史）。
- **forecast()**：
  `macroblocks = ceil(noutput_items / 65)`（noutput_items 是 65 的倍数）；
  `ninput_required = macroblocks*48 + (ceil(T/65) − 1)`（含延迟线余量，勿用
  double 向下取整导致活锁，勿永远多要一大 chunk 阻塞 EOS）。
- **general_work()**：只处理完整可证明安全的输入/输出范围；调用 core.process；
  `consume_each(实际消费)`；返回 `实际产出`。`noutput_items < 65`、EOS、
  reset 均有 QA。
- **统计**（原子/volatile 快照）：`input_items`、`output_items`、`resets`、
  `discontinuities`、`tag_errors`。

## 4. tag / rx_time（§6）

- `TPP_DONT` + 手动传播：
  - `rx_time`：值不变；offset 按 tag 映射律映射（见下）。
  - `rx_rate`/`sample_rate`：改为输出率 998.4e6（或按 UHD 合同），值定义见 §6。
  - `rx_freq`：值不变。
  - `overflow`/`discontinuity`：**触发 core.reset()**（清 hist、phase=0）、
    `discontinuities++`，并在输出发出明确 tag/status。
  - 其他用户 tag：按映射律映射或按 TPP_DONT 策略丢弃（需文档化）。
- **tag offset 映射律**（与相位律同源，禁止 `round(p×65/48)` 单独近似）：
  输入 tag 在 offset p（“第一个受影响的输入样本”），映射到输出 offset
  `m_tag = ceil((p·L − d) / M)`，其中 `d = (T−1)/2`（滤波群时延在虚拟域）……
  **该律必须先用 impulse/tag QA 固定**：给输入在 p 处打 tag，检查输出 tag 落点，
  并覆盖 offset 0/1/47/48/49、跨 chunk、暖机前后、overflow 前后（§8.4）。
- 坐标 metadata（PDU/写盘追溯）：`input_sample_rate=737.28e6`、
  `output_sample_rate=998.4e6`、`resample_interp=65`、`resample_decim=48`、
  `resample_filter_delay`、`input_absolute_sample`、`output_absolute_sample`、
  `discontinuity_epoch`。

## 5. QA 矩阵（§8，Boost.Test 注册到 CTest）

### 5.1 core 数值 QA（`qa_uwb_rational_resampler_core.cc`）
读 `testdata/resampler_65_48/golden/*_in.cf32` 与 `*_out.cf32`，要求逐样本匹配：
- zero 输入、单位冲激、复冲激、DC、复单音（低频/通带边缘/阻带）、随机复数、
  真实 UWB 窗口；SC16 极值（-32768/32767 与饱和）在 C 阶段覆盖。
- 容差：golden 为 float32 导出；设 `tol_abs`（约 2e-3，由 taps 长度/舍入决定，
  写成明确常量并注释依据）；报告 `max_abs_error`、`relative_L2_error`、
  `normalized_correlation`、`gain_error`、`phase_error`。
- 很短输入：0、1、47、48、49、95、96 个输入 → 长度按 `ceil(((N−1)·65+T)/48)`，
  与 golden（如 N≤T 时补零 upfirdn）逐样本对齐。
- 长输入计数：输出/消费数量、phase 无漂移。

### 5.2 chunk 不变性
同一输入用：一次性、固定 48、固定 4096、`{1,2,47,48,49,随机}` 混合、流式多次
`process+flush` 调用 → 输出长度/IQ/phase 完全一致。

### 5.3 scheduler QA
`forecast` 不活锁；有限 source 在 `set_output_multiple(65)` 下正常 EOS；小 buffer；
多次 general_work；consume/produce 精确；stop/restart；taps/reset API；析构不死锁；
热路径无动态扩容（可用 valgrind 或计数验证）。

### 5.4 tag/rx_time QA
tag 在 offset 0/1/47/48/49、跨 chunk、暖机前后、两个连续 rx_time epoch、
模拟 overflow 前后；验证输出 offset、值、reset、epoch。

### 5.5 UWB 算法回归
用 testdata cfile（998.4M 域 → 48/65 抽取为 737.28M 输入 → 重采样回 998.4M），
对照 `UWB_demodulation/` MATLAB：packet start、SYNC 相关峰、CFO、SFD、CIR、
PHR、PSDU、FCS。保留无噪 + 带噪两个 golden。
