### 3. 先冻结接口（你在派发前完成）

在派发 subagent 前，你先写出并提交给所有 subagent 的接口（仅声明，可放在消息里）：

```cpp
// gr-uwb/include/gnuradio/uwb/uwb_autocorr_gate.h  (header-only, no UHD)
namespace gr::uwb::live {
enum class AutocorrWhenLocked { Scan, Suspend, Auto };
AutocorrWhenLocked parse_autocorr_when_locked(const std::string&); // throws on bad value
// resolved: Suspend 仅当 mode==Suspend 或 (Auto && !interference)
bool resolve_autocorr_suspend(AutocorrWhenLocked mode, bool interference); // Suspend+interference -> throw
struct AutocorrGate {
    bool enabled = false;
    bool suspended = false;
    uint64_t suspend_events = 0, resume_events = 0;
    uint64_t suspended_samples = 0, resume_backlog_samples = 0;
    struct Action { bool scan; bool reset; int64_t reset_at; };
    // 每个 RX 块（拷贝进 ring 之后、扫描之前）调用一次；n = 本块新样点数
    Action update(bool scheduled, int64_t end, int64_t valid_begin,
                  int64_t lookback, size_t n);
};
}
```

语义：`!enabled` → 永远 `{scan=true, reset=false}`；`enabled && scheduled` → 进入/保持暂停
（首次进入 `++suspend_events`），`scan=false`，`suspended_samples += n`；
`enabled && !scheduled && suspended` → 恢复，`reset=true`，
`reset_at = max(valid_begin, end - lookback)`，`++resume_events`，
`resume_backlog_samples += end - reset_at`，`scan=true`。
