## 目标与本机证据

同一份源码按目标 CPU 选择自研 DSP 后端，保留 AVX2 和标量实现，避免为每台机器维护分支。
本机 `lscpu` 报 Ryzen 7 9700X，flags 包含 avx2、fma、avx512f/bw/dq/vl。
现有重采样/CIR/融合内核主要通过 `__AVX2__ && __FMA__` 编译；固定单音模块已有
函数 target attribute 与运行时 AVX2 检测。apps/lib/QA 多处使用 `-march=native`。
因此本机编译可使用其 ISA，但不等于已经实现或验证专用 AVX-512 内核。

本轮不修改协议、融合准入门限、CIR 降级、锁定策略、默认 taps 或滤波群时延。
不预设 512 位必然快于 256 位；以实际内核和端到端对照决定采用范围。

## P1：统一编译期选择

拟提供 `UWB_SIMD=AUTO|AVX2|AVX512|SCALAR`（名字及枚举需随实现写入使用文档）。

| 模式 | 拟定行为 |
| --- | --- |
| AUTO | 本机原生构建时检测实际可执行的 CPU/OS ISA 和编译器能力，选择通过验收的后端；没有已验收 AVX-512 内核时保持 AVX2 |
| AVX2 | 明确生成 AVX2/FMA 自研路径，避免 `-march=native` 偷带 AVX-512 |
| AVX512 | 生成已声明所需子集的 AVX-512 内核；不支持的编译器明确报错 |
| SCALAR | 关闭自研显式 SIMD 内核，用于参考和兼容验证；不声称控制外部 VOLK 的运行时分派 |

AUTO 必须结合 CPU 与 OS 向量状态可用性，不能仅以“编译器接受 -mavx512f”为检测。
交叉编译时不能以构建机代表部署机：要求指定目标后端/能力，不运行目标探测程序。
显式目标允许面向另一机器编译，执行前检查必要能力并明确拒绝不支持的机器；检查入口
必须使用基线 ISA 编译。编译期选择的制品有目标 CPU 要求，不承诺单二进制跨所有 CPU。
若后续需要同一二进制部署多种机器，再评估多版本内核运行时分派。

集中管理自研内核的选项和能力定义，替换相关位置散落的 `-march=native`，
确保 core/native/app/GR adapter/QA 的设置一致。避免同一 header-only 内核在不同 TU
被编译成不同后端而产生 ODR 风险；优先把新增 ISA 内核放独立实现文件，提供稳定接口。
保持 `-O3` 等原优化级别；不通过 `-ffast-math` 改变浮点语义。configure 和 benchmark
输出请求模式、实际后端、所需 ISA；需要时用反汇编确认热点实际生成了目标指令。

## P2：首个优化对象——SC16 65/48 重采样

重点为 `uwb_rational_resampler_core.h` 的融合 SC16 转换/FIR 与 C1 fixed_phase 内核。
尝试更宽输出并行，减少单输出横向归约与尾部开销；不能只机械把 256 改为 512。
当前 Hpad 16/24/32/48 均纳入比较，避免只优化一个档位而拖慢其他档位。
保留相位/游标、历史缓冲、max_out、flush、输出长度和时间原点契约。

QA 覆盖 SC16 极值、随机输入、非对齐地址、短尾、奇数长度、分块、极小 max_out、
reset/flush 及多 worker。先尽量保持累加顺序并争取逐样点位级一致；若改变求和树，
先明确容差合同，再做独立数值参考与完整解调对照，不能静默放宽现有断言。

## P3：按测量扩展

只有 P2 证据充分才扩展：

1. 融合 CMF/soft-chip/CIR 与 SYNC/SFD 相关；固定 38 tap 需要单独评估尾部效率。
2. 固定单音饱和相减。若测量表明带宽已限制吞吐，则不因指令更宽而自动替换。
3. 分数网格 FIR 保留正确性，另测真实时钟偏差场景；融合 fast path 的收益不能覆盖
   网格被拒包的代价。禁止顺带放宽门限来制造性能提升。

## 验收与回退

- 使用同一环境跨轮交替 ABBA，至少 3 轮；基准独占，记录负载及 worker 数。
- 准确性：长度、状态、IQ 对照及完整 PSDU/FCS；测到不同输出必须定位原因。
- 系统：原生/GR、UHD ON/OFF 的相关构建与 QA，安装消费者及 backend 输出。
- 保留 AVX2 路径做持续参考。已有运行时分派如被纳入统一选择，不能丢失强制后端 QA。
- 首个内核建议准入门槛：目标生产格中位收益至少 5%，跨轮同向；其他生产格不得出现
  可重复退化。无法满足时保持 AVX2 默认，AVX-512 仅显式实验启用，并如实记录。
- 固定窗口通过不代表动态锁定逐包一致；动态回放、paced、丢样与尾延迟单列证据。
- 本轮先完成软件/回放验收，上板由单独验证步骤执行；未验证的机器型号不宣称性能收益。
