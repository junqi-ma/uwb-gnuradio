# AGY SIC 整改二次复核

复核提交 `cc47799`。结论：紧凑四径、32 B、20 tap、lag_lo=-1 主场景功能与性能通过；前次 R01–R04 的核心问题已修复。分数网格范围保证仍有一项 P2 未闭环，不把主场景通过写成全部配置验收通过。

## 已关闭的主要问题

- R01：归档脚本确实以 old/new/new/old 运行两个 fast runner，输入、tap、lag 和 RX 选项相同。原错误的 41.6% 结论已改正。
- R02：默认 CFO 分支恢复四路独立递推，逐样点 sin/cos 仅作参考。新增绝对区间数值 QA；感知解码及完整 service 回退已消除。
- R03：新增显式原子内核选择，QA 确实切换 SIMD/通用内核；AVX 调用点补充了平台及编译器保护。本机两内核 QA 通过，未做跨平台实编译。
- R04：fallback_t0 已移至全窗补偿前，补偿被计入 fallback 父桶与 stage_total_us。新增回退 QA；该 QA 的不等式本身不足以单独证明守恒，本轮结合代码位置确认修复。

复核清除 LD_LIBRARY_PATH 后运行相关 8 项 CTest，8/8 通过，约 2.11 秒；没有重新跑性能矩阵。

## N01：非整数网格回退判断使用了错误的量（P2，未关闭）

位置 `uwb_demod_core.h:3104–3109`。

新增 is_integer_grid 用 profile.sample_rate / 499.2e6 判断；实际 soft-chip 网格在同文件 :1036 使用 timing.measured_period / 508。名义采样率保持 998.4 MS/s 的接收信号仍可能存在 SFO，二者并不等价。

仓库现有分数网格例 period=1016.25：名义 spc=2，实际 spc=2.000492125984252。新 guard 仍进入硬编码 spc=2 的局部补偿分支，不能证明报告所称“非整数网格显式全窗回退”。常量 halo 可能覆盖小偏差，但不构成该回退保证。本轮未观察到主场景失败，也未宣称所有分数网格都已解码失败。

最小修复：以 cfo_timing.measured_period/508 判断实际网格；偏离受支持的 2 sample/chip 就保守补偿全窗，或由实际网格推导所有补偿上界。增加一个名义 fs 不变而 measured_period 非整数的针对性 QA，确认走全窗且不会读取旧包残留。无需重跑主场景计时。
