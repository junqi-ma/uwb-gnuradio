## 四、 正式 ABBA 串行配对计时（持锁运行）

- **测试环境**：持锁 `/tmp/uwb-sic-benchmark.lock` 独占串行运行；
- **协议**：4 轮（128 tap → 20 tap → 20 tap → 128 tap），每轮 8 次热身、64 次观测（各配置总计 128 次独立观测）；
- **产物目录**：`gr-uwb/build-sic-fullpacket-agy-opt/results/agy_opt_timing_20261108_121619`。

### 主场景 20-tap（`lag_lo = -1`）新旧配对耗时分解

| 阶段（单位：µs） | 基线均值 (pulse-list) | 本轮优化均值 (agy-opt) | 优化 P95 (agy-opt) | 变化量 (均值) | 收益来源 |
|---|---:|---:|---:|---:|---|
| **参数估计 (`estimate`)** | 254.4 | **229.3** | 259.2 | **-25.1 µs** (-9.9%) | C1 合并前缀扫描 + C2 周期残差预测 (detail_fit_check 47.7→44.2 µs) |
| **通信解码 (`comm_demod`)** | 1369.4 | **1098.2** | 1228.1 | **-271.2 µs** (-19.8%) | A1 旋转区间裁剪 (~10万样点替代全窗) + A2 三元 CIR 稀疏加减 |
| **旁路准备与校验 (`validate`)** | 276.7 | **2.2** | 2.9 | **-274.5 µs** (-99.2%) | B1 延迟旁路拷贝 + B2 内部脉冲列表免重复二次线性扫描 |
| **TX 脉冲生成 (`tx`)** | 35.5 | **10.2** | 12.1 | **-25.3 µs** (-71.3%) | C3 `HrpModScratch` 跨包缓存扩频 PN 序列，消除重复 LFSR 推进 |
| **重构卷积 (`channel`)** | 398.9 | **122.0** | 168.1 | **-276.9 µs** (-69.4%) | B3 20-tap 专用 AVX2/FMA 向量加减累加内核 (卷积本身仅 58.6 µs) |
| **相减与输出 (`subtract`)** | 75.4 | **107.1** | 147.1 | +31.7 µs | 统计口径转移：B1 成功路径直接写 `out = y - recon` 计算并入此段 |
| **包装拷贝开销 (`copy`)** | 282.1 | **3.0** | 3.6 | **-279.1 µs** (-98.9%) | 消除全窗 1.89 MB 内存无意义复制 |
| **总 SIC 耗时 (`sic_total`)** | **2692.4** | **1572.0** | **1803.7** | **-1120.4 µs** (-41.6%) | **总耗时降低 41.6% (从 2.69 ms 降至 1.57 ms)** |

## 五、 构建与运行命令

1. **编译构建**：
   ```bash
   mkdir -p gr-uwb/build-sic-fullpacket-agy-opt
   cd gr-uwb/build-sic-fullpacket-agy-opt
   cmake -DCMAKE_BUILD_TYPE=Release ..
   make -j$(nproc)
   ```
2. **运行单元测试**：
   ```bash
   env -u LD_LIBRARY_PATH ctest --test-dir gr-uwb/build-sic-fullpacket-agy-opt -R 'uwb_qa_uwb_(demod_core|discrete_cir_estimator|discrete_cir_reconstruct|hrp_mod_core|rx_fused_cmf|fullpacket_fast_rx|rx_fused_phr|fullpacket_sic_core)' --output-on-failure
   ```

   ```bash
   python3 gr-uwb/build-sic-fullpacket-agy-opt/results/run_timing.py
   ```
