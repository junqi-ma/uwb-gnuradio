# 稀疏脉冲列表与 CFO 融合重构：可行性任务书

## 目标与工作位置

在当前 Ipatov full-packet SIC 实验路径上，将“整包实数采样序列 → 稀疏卷积 → 整包 CFO 旋转”改为：

**编码/扩频 → 非零脉冲位置与正负号 → 脉冲位置的 CFO 相位 → CIR 叠加 → 相减。**

验证这一表示能否降低重新调制、信道重构及总 SIC 耗时，同时量化短 CIR 内忽略 CFO 变化的消减损失。本轮交付可运行实验和简短结论，不要求推广为默认路径。

## 原理：按非零事件叠加响应

令脉冲列表为 `{m_i, a_i}`：`m_i` 是相对整包起点的 work-grid 整数采样位置，`a_i∈{-1,+1}`。CIR 第 j 项的实际时延 `k_j=lag_lo+j`，包起点 q，CFO 相位参考 anchor。

当前精确重构：

```text
yhat[q+m_i+k_j] += a_i * g[j] * exp(jω(q+m_i+k_j-anchor))
ω = 2π CFO / sample_rate
```

本轮采用用户指定近似：CIR 持续期间 CFO 相位不变，**不旋转 CIR**：

```text
c_i = a_i * exp(jω(q+m_i-anchor))
yhat[q+m_i+k_j] += c_i * g[j]
```

`a_i=+1` 直接取相位，`a_i=-1` 取负。只在非零脉冲处计算相位并累加响应；保留复数相位与 CIR 的乘加。当前模型 anchor=q 时，相位简化为 `ω*m_i`，代码必须保持参考点语义。

这会省去完整 ±1/0 缓冲生成/清零/扫描，以及输出后的整包 CFO 旋转。输出重构缓冲仍需要清零；响应重叠处仍需累加。

近似漏掉的相位为 `ω*k_j`，需按实际 lag 范围评估，不只看 active_count。998.4 MS/s、50 kHz 下，每 12 个采样间隔约 0.22°，128 个约 2.31°。小相位误差也可能影响深度消除，不能由相位小直接推断抑制无损。

## 接口先约定（主 agent，随后并行）

在现有头文件中确定接口，建议如下，名称可随项目风格调整：

- `PulseEvent { sample_offset, sign }`，sign 仅 ±1；位置递增、位于 `[0, packet_samples)`，同点脉冲不允许被静默覆盖。
- `PulseList`/scratch 保存事件数组、有效事件数和 `packet_samples`。**整包长度独立于最后一个事件**，保留尾部零区及现有支持范围约定。
- 新调制入口返回事件列表与整包采样长度；失败返回现有错误语义，不留下可被消费的半包。
- 新重构入口读取列表、冻结 CIR、q/CFO/anchor 和 ROI；沿用现有结果结构及旁路契约。
- 新增显式实验开关（如 `--sparse-pulse-reconstruct`），仅对 `ipatov_cir` 生效；旧单位实数路径可直接配对运行。不静默切换旧后端。
- 配置/模板一致性在准备阶段检查；热路径不重新生成完整 SYNC 来做逐点比较。
- 事件容量按支持的最大包长预留；实际容量不足明确失败。禁止逐脉冲 push 导致热路径扩容。

## 并行任务与文件归属

接口约定完成后，调度三个 subagent 并行，主 agent 集成。共享头文件由主 agent 先落接口，后续修改先协调。

| 任务 | 负责内容与文件 | 完成反馈 |
|---|---|---|
| A：脉冲列表调制器 | `uwb_hrp_mod_core.h`、modulator QA。复用既有 RS/PHR/卷积编码/扩频决策，直接输出 SYNC、SFD、PHR、payload 的位置与符号；缓存前导事件并按段追加。不生成完整实数/复数波形，也不通过扫描旧波形提取事件。 | 接口、事件数/容量、覆盖段、定向 QA 结果；下一步交 B 接入。 |
| B：事件重构 | `uwb_discrete_cir_reconstruct.cc`、reconstruct QA。按事件生成相位并累加 CIR，移除新路径整包旋转；零 CFO 专用加/减，非零 CFO 复数 AXPY。保留绝对坐标、支持范围、ROI、最终有限值检查和失败旁路。 | 新旧计算路径差别、CFO 近似落点、定向 QA 结果；下一步交主 agent 集成。 |
| C：运行入口与配对统计 | `benchmark_fullpacket_compare.cc` 及一个小型运行/统计脚本。接入实验开关、输出事件数/包长/分项耗时，准备相同源窗的新旧比较，检查每一轮结果。依赖接口可先用声明，不等待 A/B 完成再准备脚本。 | 可复现命令、统计口径、待执行对照清单；下一步集成后串行测量。 |

主 agent：准备接口和 scratch、处理集成点、构建定向目标、完成最终报告。性能测量仅由主 agent 串行执行，subagent 不并行跑 benchmark。

实现优先采用现有 helper/缓存；不新增 GNU Radio block、不重构整套编码器、不提前做多套 SIMD 内核。若逐事件 sin/cos 成为主要瓶颈，再选择一种简单相位生成优化，并保证按真实采样位置推进，不能按事件序号推进。

## 最小验证：足够定位问题即停止

### 1. 调制器定向 QA

使用 2/32/127 B 三种现有测试长度：将列表展开，仅在 QA 中与旧单位实数序列逐样点比较，要求相同 packet_samples、位置、符号和尾部零区。检查容量不足拒绝，以及预分配后事件数组不扩容。无需扩展全部 PHY 配置矩阵。

### 2. 重构定向 QA

- 零 CFO：使用旧单位实数实现作对照，保持脉冲顺序和累加顺序，目标逐位一致。若只是明确的浮点运算次序差异，说明原因并报告误差，不能忽略位置/幅度错误。
- 非零 CFO：用小型标量参考直接实现上面的**近似公式**，核对 q、负 lag、anchor 和重叠累加；不要求与旧精确公式逐位一致。
- 复用已有容量/边界/失败旁路测试，补一个不足支持拒绝即可。保留损坏包 FCS 门槛；不生成新一轮庞大负样本集。
- 只构建并跑 modulator、discrete CIR estimator/reconstruct 相关 QA。通信解码未改，不重跑完整通信 QA 矩阵。

### 3. 小规模端到端对照

复用已有 fixture，不重新生成大 IQ：32 B 单径、32 B 分数多径、±50 kHz CFO、SYNC 重叠，各 8 窗；127 B 和损坏包各 2 窗。新旧使用相同估计模型/配置和源窗，确认 CIR、q、CFO 没有被意外改变。

逐窗检查通信/感知 PSDU、FCS、状态、提交结果；损坏包必须零提交并保持原始旁路。比较真实输出消减幅度及已有目标保护指标。区分零 CFO 的实现误差与非零 CFO 的近似误差，不拿重构 NMSE 代替真实抑制。

可行性效果目标：相对当前单位实数路径，各正常 cell 聚合抑制下降不超过 1 dB，原有通过的解码不新增失败；同时列出最差单窗差值。超出目标就给出实际结果，保留实验开关，停止推广；不自动扩大扫描或另开发精确 CFO 方案。SYNC 碰撞仅比较本轮增量，已有约 19.63 dB 退化不在本轮修复。

### 4. 性能仅测两格

测 32 B 分数多径与一个非零 CFO cell。独占 `/tmp/uwb-sic-benchmark.lock`，串行 ABBA，每轮预热 8、计时 64 窗，每变体共 128 次，报告 mean/P95。若结果在波动范围内无法判断，只允许补一次同规模配对；仍不明确就写结论未定。

报告：调制/事件生成、信道重构、总 SIC；重构内只补清零、相位生成、CIR 累加、最终检查等必要子计时。父阶段与子阶段不重复求和，细分时钟避免放进每脉冲循环。性能可行性以信道重构和总 SIC 均有可重复收益为目标，不预承诺固定加速比。

使用新 build 目录（如 `gr-uwb/build-sic-fullpacket-pulse-list`），保留旧 binary/run。`env -u LD_LIBRARY_PATH`，用 ldd 确认实际 build/lib；记录 commit+dirty patch、profile、CIR lag 范围、源窗、二进制/库哈希。结果放 build/results 独立时间目录，不进 Git，不覆盖历史结果。
