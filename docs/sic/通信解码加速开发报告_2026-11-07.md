# 通信解码加速开发报告（2026-11-07）

## 1. 结论

本轮按 `docs/sic/OpenCode_通信解码加速任务书_2026-11-07.md` 完成 A/B/C 三项
显式实验路径，并保持默认 RX 行为不变：

- **A 同步/SFD**：SFD 粗/细相关改用现有 VOLK 复共轭点积，按 template+SFD 内容
  缓存归一化模板；SFD 锚定尾部首符号先搜 ±8，失败回退原 ±max(256,stride)。
- **B CFO 旋转**：相位拟合不动，只把全窗旋转替换为 1024 点绝对相位块 + VOLK
  复乘。两次 CFO 调用的顺序、符号和失败行为不变。
- **C 按需 soft-chip**：先只生成 SYNC/SFD/PHR 前缀，按已校验 PHR 长度扩展
  payload 范围；复用同一 CIR/tap 选择和整数网格 kernel。分数 spc、RAKE、bypass、
  修正 PHR 或失败路径回退完整旧流一次并计数。

**性能目标已达到**：`payload_base` comm demod mean **2816.0 → 1933.1 µs
（比值 0.686，-31.4%）**，P95 **4183.6 → 3572.1 µs（0.854）**。另外两格也下降，
无格 mean 超过旧值 5%。8 格 × 16 源窗逐窗 comm/sensing PSDU、FCS、status 全部
一致。正式数字绑定 commit `d2d18be`、干净工作树和本轮同 binary 配对。

### 2.2 sync_base 的阶段边界

`sync_base` 旧流已被输入长度截到约 68.8k chip，按需模式生成 67.9k chip 再加
约 87 µs 扩展，因此 CIR 父阶段 **669.7 → 689.0 µs（+2.9%）**，soft FIR 本身
504.9 → 490.4 µs。该格总 comm 仍为 2226.8 → 1718.9 µs（0.772），未出现整体
退化。不能把这一子阶段写成“C 对所有格都降低 CIR 时间”。

### 3.2 数值/等价证据

- **A**：8128 点 VOLK 点积对 double scalar 参考最大相对误差 2.8e-6；缓存模板
  与旧 `kron+L2` 构造逐位一致；尾部 seed +3 窄搜命中、+12 超出 ±8 回退后仍
  恢复 40 个峰、+400 两路径都失败，不伪造捕获。option 关闭时 timing/SFD 输出
  与旧路径逐位一致。
- **B**：块旋转对独立 double 参考最大绝对误差 1.09e-6、最大相对 8.8e-7
  （旧循环同参考约 2.5e-5）；首样点不变；option 关闭时旧循环逐位一致。
- **C**：32B 长窗（n=236416）按需流前 67871 chip 与旧流按全局正尺度对齐后
  **最大绝对误差 1.19e-7、最大相对 1.8e-7**，多数样本逐位相同；合成 32B QA
  中 scale=1、max_err=0。PHR 长度来自校验后的 `phr.psdu_length`，没有使用
  sidecar/注入长度。
- **集成 QA**：全选项与旧路径 PSDU/FCS/`ns_sfd`/`first_path` 一致；32B 前缀
  chip 数小于旧流；PHR/SFD 损坏时回退完整旧流一次且最终 status 与旧路径一致；
  尾部 seed 偏移 ±8 外回退；分数 spc 按需路径拒绝、旧路径可运行。

## 4. 实现边界与回退

- 新增 `uwb_rx_sync_opt.h`、`uwb_rx_cfo_opt.h`、`uwb_rx_softchip_opt.h`，均为
  header-only，不含新 GNU Radio block；已加入安装头文件列表。
- `FastRxPipeline::Options` 与 profile 开关默认全关；已有调用者不改变默认
  PHY、FCS 门槛、CIR 估计器/ tap 选择、重构 FIR 或硬件路径。
- C 的前缀用自身可见范围归一化，扩展后按最终最大值统一重标定；这是实验行为，
  不宣称逐位等价。数值差在 1e-7 量级，且 8 格逐窗 PSDU/FCS 一致。修正 PHR
  因旧路径可检查全范围尾部能量，按需路径直接回退，不改变该判定。
- 失败回退：PHR 失败、范围不足、修正 PHR 或 payload FCS 失败/解析失败时，
  最多重跑一次完整旧 soft-chip 流；`stage_softchip_fallbacks` 与耗时单列。
  本轮正式与功能行均为 0 次回退。
- 旧 build `gr-uwb/build-sic-fullpacket-fused` 未覆盖；新 build
  `gr-uwb/build-sic-fullpacket-rxopt`。
