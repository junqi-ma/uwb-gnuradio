# SIC 第二阶段全链路算力优化开发计划（修订版）

修订日期：2026-11-10。本文修正原方案的收益预估、NS-SFD 裁剪、搜索等价性、缓存生命周期及验收口径。本文是开发计划，不表示已经实施或达标。

## 1. 目标与基线

基线为文档提交 `efd9bb4` / 代码提交 `4697980`。历史报告记录 Preamble-Only mean 828.12 µs、Full-Packet mean 1,142.42 µs；报告内还存在不同统计值，正式收益以本轮同环境新旧配对结果为准。

本轮优先消除可证明冗余的计算，保持输入契约、候选集合、解码决策和事务旁路语义。Preamble-Only 480–550 µs、Full-Packet 700–780 µs 仅作为探索目标，不作验收硬门槛，也不预先分配各轨道的微秒收益。

当前 `bench_unified_timing` 使用固定 32 B 合成包、零背景、无注入多径/非零 CFO/噪声，重复测量同一输入。其约 63 dB 是该输入下的功率下降结果，不代表碰撞场景效果、弱目标保护或实时吞吐。mean≤0.5 ms、P99≤1 ms、200 窗/s 仍须另行验证，本轮不扩展这些实验。

## 2. 并行轨道与文件所有权

保留三个 Subagent 的实现分工，由主 Agent 负责集成、统一构建与正式计时。文件互斥不代表没有语义依赖：共享接口和缓存规则必须先约定，所有性能测试串行执行。

| 轨道 | 独占修改范围 | 任务 |
|---|---|---|
| A：信道估计 | `uwb_discrete_cir_sic.h`、`uwb_discrete_cir_estimator.cc`、`qa_uwb_discrete_cir_estimator.cc` | 实数相关、局部能量、训练去旋转与残差 |
| B：通信解调 | `uwb_rx_sync_opt.h`、`uwb_demod_core.h`、`qa_uwb_demod_core.cc` | SFD 四滞后相关、相干累加、固定序列复用 |
| C：统一控制器 | `uwb_sic_unified.h`、`uwb_sic_unified.cc`、`qa_uwb_sic_unified.cc` | 固定前导缓存、能量统计 |
| 主 Agent | `apps/bench_unified_timing.cc`、必要构建登记及本轮报告 | 基准逐轮检查、集成与验收 |

表中文件位于 `gr-uwb/include/gnuradio/uwb/` 或 `gr-uwb/lib/`，以实际源码路径为准。

约定：

1. 子 Agent 只修改各自文件；不并行写共享 build，也不运行正式 benchmark。需要其他文件时先交主 Agent 协调。
2. B 保留已有 `RealSyncTemplate`、`real_template_dot_4lag`、`real_template_dot_single` 接口，A 只读调用。新增辅助函数保持向后兼容。
3. 每项优化保留可供针对性 QA 对照的旧实现或参考入口；不要求为每项建立独立性能实验。
4. 使用独立新 build，保留旧 build；不覆盖历史产物、不安装到 `/usr/local`、不推送、不上板。

## 3. 实施规格与优先级

### Track A：信道估计

**A1，优先：复用实数模板相关核。**

- 在准备阶段检查有限实数模板，预生成 `[s0,s0,s1,s1,...]`；含非零虚部的模板走原复数相关，不为加速而丢弃虚部。缓存随模板或配置变化重新准备。
- `stride == 1` 时，连续四个合法候选调用现有四滞后核，尾部使用单滞后核；其他 stride 保留原候选集合，可使用单滞后实数核。
- 重复符号确认、局部精搜也可复用单滞后核。保留归一化、阈值、候选访问顺序及 `>` 比较的先到先得规则；不越过 `visible_end`，四滞后调用须检查最后一行的完整支持。

**A2，第二优先：局部能量前缀和与有限性检查。**

- 保留对整个 `[0, visible_end)` 的 NaN/Inf 检查及标量回退。AVX2 实现需对指数掩码结果做全 1 比较和归约，并处理尾部，不读取前缀外样点。
- 根据裁剪后的 ROI、模板长度、确认符号偏移，构造覆盖全部相关窗口的局部能量区间；ROI 为空或无效时保留原失败语义。
- 显式记录 `energy_base`、`energy_end`，前缀和索引相对 `energy_base`。只有整行位于有效区间内才能读能量缓存，禁止沿用原来仅检查 `ehi <= energy_fill` 的条件或读取上包残留。
- 区间外的合法请求使用双精度自能量参考计算或扩展有效区间；不要直接以 float VOLK 自点积替换 double 归一化而宣称数值等价。

**A3，第二优先：去旋转与残差循环。**

- 优先尝试四路独立双精度递推或 AVX2 double 计算；保持相位原点、每 1024 点按绝对采样位置重锚定，以及训练首尾支持。
- 相位表依赖本包估计 CFO，只在同包复用，不作为跨包固定缓存。保留 double 累加及原残差门槛，不新增 CFO 近似。
- 不预设固定有 7 个有效窗口，继续依据训练边界判断有效符号数；无收益或边界难以保持时保留原实现。

### Track B：通信解调

**B1，优先：SFD 四滞后符号相关。**

- 新增 `sfd_real_dot_4lag`，对 SFD 非零符号调用现有四滞后实数核，再按原符号幅度及归一化累加。
- 只在合法的连续细搜候选上批处理，保留原搜索窗口、滑动功率更新、候选顺序、阈值和并列处理；不足四点走单点尾部。
- 批处理减少模板加载与调用开销，不把四个相关值描述为四倍算术量缩减。15 点细搜应为三组四点加三个单点尾部，按实际非零 SFD 符号数统计调用。

**B2，优先：相干累加与固定序列复用。**

- 对 SYNC 相干累加比较现有循环与 VOLK/显式 SIMD；按符号保持原浮点加法顺序，检查目标 VOLK 内核的原地写入及对齐要求。不预设现有编译器完全没有向量化。
- 将 `pcode`、SFD 序列等固定内容放入现有 scratch 缓存，按 code/SFD mode 失效；只读指针方案须满足现有接口及生命周期。
- 这两项仅影响完整解调阶段，Preamble-Only 在 SFD 后提前返回，不计入其预期收益。

**B3，本轮不实施：bootstrap 锚定的 final SFD ±8 窄窗。**

窄窗出现过阈值次峰时，不会触发原建议的失败回退，但完整搜索可能选择另一个峰，因此不属于保持候选集合的等价优化。为保持本轮验收简洁，继续使用现有 final SFD 搜索；该策略留作后续单独实验，不新增开关或验证矩阵。

**B4，删除原建议：4,081 chips 裁成约 500 chips。**

当前融合路径已通过 `skip_sync_fir` 跳过 SYNC FIR。NS-SFD 相关仍读取完整 8 符号模板，长度为 `8 × 508 = 4,064 chips`，加上搜索余量后约 4,081 chips。±8 chip 搜索半径不等于只需生成几百 chip。

本轮保留现有 FIR 范围、soft-chip 绝对索引、相位统计及失败回退。CMF 与 NS-SFD 相关融合需要新的推导，不纳入本轮。

### Track C：统一控制器

**C1，优先：缓存实际使用的固定数据。**

- 在 `prepare_sic_unified` 中缓存 `sync_vec`，并按实际后端准备需要的前导波形或事件。稀疏路径优先避免生成随后不会使用的稠密前导；保留稠密回退所需内容。
- 调制器已缓存前导事件，本项新增收益主要来自避免逐包物化复数波形、复制模板和重复准备，不把已有缓存的收益重复计算。
- `PulseList` 是借用存储的视图，不能只把裸视图跨调用保存。使用 scratch 自有 `std::vector<mod::PulseEvent>` 存储固定前导事件，并在消费时从当前 `.data()` 构造视图；或提供明确同等有效的所有权实现。后续整包调制不得覆盖该存储。
- 缓存身份包含配置及模板内容中所有影响生成结果的字段，不能只比较指针。重新 prepare 时先使旧缓存失效，全部成功后才置有效；失败不得沿用旧包缓存。处理时拒绝配置/模板不匹配，遵守现有准备契约。
- 覆盖 PreambleOnly、FullPacket、AutoFallback 及 scratch 重复使用；保持容量检查、失败旁路和输出支持不变。仅宣称消除了本项指定分配，不预先宣称全链路零分配。

**C2，优先：ROI 能量统计向量化。**

- 将 `suppression_db` 的输入/输出能量遍历改为 SIMD float 读入、double 累加，并处理尾部；保持 ROI 和零能量分支语义。
- 不直接用 float 输出的 VOLK 点积替代 double 总和而要求完全一致，允许规定范围内的归约误差。
- 字段含义仍为 `10*log10(E_input/E_output)`，报告称“ROI 功率下降”，不能单独据此声称混合场景干扰抑制或目标保护通过。

## 4. 简洁验收

不新增大矩阵、不测硬件/实时到达、不为每项优化另开性能实验。只做以下两步。

### 4.1 针对性 QA + 相关回归一次

在现有 QA 中补少量用例，使用原实现或独立标量参考：

- A：实数/复数模板、四点尾部与 prefix 边界；局部能量重复使用 scratch 不读旧值；可见前缀内 NaN/Inf 被拒绝；去旋转用一个非零 CFO 用例核对模型和残差。
- B：四滞后 SFD 与单点参考一致，包含尾部；保持现有候选和解码决策。
- C：缓存重复使用、切换配置重新准备及整包调制后前导事件不被覆盖；能量核与 double 参考一致。
- 对相关输出 IQ 使用相对 L2 ≤ `2e-5`，归一化相关绝对误差 ≤ `1e-5`，能量相对误差 ≤ `1e-6`；模型浮点量按相应参考误差检查，`q`、状态、提交决策及已解码 bits 保持一致。边界 QA 继续采用原有门槛，不放宽已有断言。
- 沿用已有损坏包/旁路 QA，失败输出逐位保持输入。不因本轮另建功能场景矩阵。

主 Agent 集成构建后，清除 `LD_LIBRARY_PATH`，确认测试实际加载新 build/lib；一次运行覆盖实际修改模块及已有 demod/SIC/SFD/unified 回归。原 9 项筛选未必包含 estimator/reconstruct 等模块，须按实际 CTest 名称补入；记录实际通过数，不固定称“全套 9/9”。有新修改或失败时仅重跑受影响项。

### 4.2 一组持锁新旧配对计时

- 基于现有 `bench_unified_timing`，维持固定输入、配置及两种 policy，不扩充信道场景。新旧使用相同基准协议，均为每种 policy 10 次预热、50 次观测。
- 独占 `/tmp/uwb-sic-benchmark.lock`，串行执行 old → new → new → old；每版本、每 policy 合计 100 次观测。绑定源码版本/补丁、构建配置与实际加载库，使用独立产物目录。
- 基准需逐轮检查调用结果、`committed`、状态/level/字段、有限输出，失败立即报错并非零退出。保留逐次总时间和阶段时间，统计 mean/P50/P95，不只打印最后一轮状态。
- 对这一个固定输入做一次新旧输出比较：相对 L2 ≤ `2e-5`，ROI 功率下降差异 ≤ `0.01 dB`；此输入下历史约 63 dB 仅作核对，不设置面向所有场景的 ≥63.2 dB 门槛。负样本由已有 QA 覆盖，不将正样本全提交称为“零误提交”。
- 两种 policy 分别报告总核心 mean 与 P95，新版应有明确净收益，P95 不应明显恶化。若收益小到与轮间漂移相当，记录“未证实”，不反复加跑追求达标。探索目标未达到不等于正确性失败，按实测保留有收益且正确的实现。

最终提交一份简短报告：变更、相关 QA 结果、新旧 mean/P50/P95、输出差异及未达目标。阶段时间是定位依据，父子桶不重复累加；本轮结果仅证明该离线输入下的功能保持与性能变化。
