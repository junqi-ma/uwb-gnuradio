# 稀疏重构跳过最终数值检查

当前稀疏脉冲重构路径跳过最终整包有限值扫描，`check_us=0`；保留输入、模型/CIR、CFO、事件、容量及支持检查。通用复数波形/旧单位实数路径仍保留原有最终检查。稀疏路径不再检测累加及最终相减产生的浮点溢出，这是本次实验明确采用的语义。

## 结果

32 B 紧凑四径，20 tap，lag_lo=-1，fast RX/fused PHR+payload，输入同 `compact_channel_20261108`。同机串行 ABBA，每轮 8 次预热、64 次计时，每变体 128 次；独占 benchmark lock。使用各自 build 的 binary/library，未覆盖旧 build。
