### 必须声明的 caveat

**ISR=20 dB 且 offset=−8 时，SIC 的“清理”是好的（该 6 个 cell 抑制中位数 ~17.10–17.31 dB，

（SIC 的核心验收对象是 sensing CIR 与目标保护；完整包 demod 是辅助结果与算力对照，

### 6.5 独立审查整改（F1–F8）

对 iter5 优化做对抗性审查后发现 F1–F8，均在**本报告初稿之后**修复并复测
（结果目录 `core_reviewfix`、`core_reviewfix2`、`gr_reviewfix`、`effect_reviewfix`、
`effect_reviewfix2`）：

- **F1（导出 `taus` + golden tau 交叉 + `enable_fractional` 差分）**
  核心 `SicResult` 现导出 `taus[kSicMaxPaths]` / `n_taus`（comm 相对分数时延，只作
  调试/检查，不参与门控）；QA 新增“golden `expected.taus` 逐路径交叉”用例，把核心
  选择的时延与 `tools/sic/sic_reference.py` 参考逐条比对（相对/绝对容差双判），并新增
  **`enable_fractional` on/off 直接差分**：同一窗口在分数关闭/开启下的检测与路径数
  必须一致，分数选择错误会直接暴露，而不再仅靠 NMSE 上界。对应 golden 用例
  `cross_model` 的 NMSE 1.953e-8（tol 1e-3）等。
- **F2（最终 gain fit + commit `cond` 改为 DOUBLE 精度 Gram/Cholesky）——关键正确性修复**
  iter5 的 float32 **正规方程**分解在 κ² 上不安全（条件数平方放大）。现最终增益拟合与
  commit 判据使用 **double 精度**的 Gram/Cholesky（仍不显式求逆）。
  `gain_fit` **512 µs → ~90 µs**：安全修法比不安全的 float32（68 µs）只贵 **+~20 µs**，
  但仍是原 double QR（~512 µs）的 **5.6×** 加速。新增**声明式病态条件 QA**：
  `cond ≈ 1e3 / 1e4 / 3e6`，double 分解恢复 `cond(A)` 到百分之几、解在全范围保持
  稳定，同时断言同设计下 float32 正规方程在 1e4/3e6 处偏差 >50%（或非正定）——
  即“float32 不安全”的可复现证据。
- **F3（`energy_prefix` 回退 + 空前缀 QA）**
  前缀和 sized by prepare 时的 ROI；运行期 ROI 超出前缀时回退到逐 lag 的 VOLK 自点积，
  且**与全搜索前缀的结果一致**；`prepare` 用 `roi 0,0`（空前缀）后运行全窗 ROI 也必须
  得到相同检测。QA 用例 `test_sic_core_energy_prefix_fallback` 覆盖 (a)–(d) 四种
  prepare/runtime ROI 组合并断言回退确实被触发（窄前缀 < 宽前缀、空前缀为空）。
- **F4 / F5 / F7 / F8（文档 / 潜伏问题）** 一并整改（接口/注释与边界潜伏缺陷；不改变
  主配置的数值结果口径）。
- **F6（verifier 复算其门控的 holdout 指标）**
  `tools/sic/verify_s0.py` 不再只“读”声明的 holdout 指标，而是**从 `recon/*.npz`
  的 `i/i_hat` 数组复算** `holdout_nmse` / `holdout_suppression_db`，与声明值比对；
  声明了 holdout 指标但没有可复算数组的 run 直接判失败。核验计数因此由 830026 升到
  **867033/867033**（§11）。

**整改对效果的影响**：double 精度 gain fit 后主效果的抑制中位数
**+2.4e-7 dB**（`effect_reviewfix` 28.3336301848 dB
对比冻结基线 `main_opt1` 28.3336299461 dB），即**数值等价**（只是把不安全路径换成
安全路径，效果不变）。`effect_reviewfix` / `effect_reviewfix2` 仍为

## 9. 四个判断（汇总）

**(a) 效果**：不同 code 的重叠前导能被估计并消除，目标被保留——
main 矩阵 72/72 cell `eff_pass`，总体抑制中位数 21.60 dB、`frac≥3dB=1.0`、

审查整改（F2 double 精度 gain fit）后效果数值等价：抑制中位数 **+2.4e-7 dB**（§6.5）。

**(b) SIC 新增开销**：宽/窄搜、K、fit_reps、fractional/CFO 的真实成本由 §6 表给出。
热点是 `fractional_refine`、`detect_coarse`、`reconstruct`、`gain_fit`；对应 5 次优化：
polyphase 前导、VOLK 检测、VOLK 浮点分数打分、prefix-sum 滑窗能量、VOLK 重构 +
Gram/Cholesky `gain_fit`，随后经**独立审查整改 F1–F8**（尤其是把最终 gain fit + commit
改为 double 精度 Gram/Cholesky）。core 34.06 → **~4.1 ms**（最佳轮 4047 µs）；
P99 46.96 → **5.56–7.52 ms**；GR/PDU **228 窗/s**。

**(c) 完整解调成本**：clean 2.10 ms、radar CIR-only 2.26 ms、sic 路径 3.14 ms；
+10 dB ISR 起 raw 整包失败，SIC 恢复名义 cell 16/16，但在 ISR20/offset−8 的
4 个 cell 仍失败。成功/失败路径分别计时（失败阶段计时为 0，不并入成功子集）。

**(d) 运行边界**：work core ~235–247 窗/s、GR/PDU ~228 窗/s **达到 200 窗/s**；
native ≈180 窗/s **未达标**；mean≤0.5 ms / P99≤1 ms **未达标（core ~4.1 ms ≈8×）**。
200 窗/s 通过只证明有界窗口处理，**不证明连续入口实时**。CIR-only 与 full demod
