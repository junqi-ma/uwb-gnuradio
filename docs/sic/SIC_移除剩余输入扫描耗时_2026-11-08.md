# 移除稀疏事务剩余的整窗 IQ 扫描

稀疏 full-packet SIC 事务不再遍历整个接收窗口检查 NaN/Inf。保留便宜的 CRC/PHR、模型/CFO、事件列表、容量和边界检查；保留一次旁路复制/清零。独立公共 apply 和旧波形事务仍保留输入检查。稀疏事务不负责拒绝原始 IQ 中的 NaN/Inf，也不检测最终重构溢出（上一轮已关闭输出检查）。

## 测量结果

紧凑四径、32 B、20 tap、lag_lo=-1；新旧都已去重、跳过最终检查，仅本次 IQ 扫描策略不同。独占 benchmark lock，串行 ABBA，每轮 8 次预热、64 次观测，每配置 128 次。

| SIC 阶段 | 原 mean µs | 新 mean µs |
|---|---:|---:|
| 参数估计 | 257.8 | 215.0 |
| 通信解码 | 1159.7 | 1161.4 |
| 一次旁路准备及少量帧检查 | 293.9 | 127.0 |
| 调制/事件列表 | 38.1 | 38.9 |
| 干扰重构 | 190.4 | 188.7 |
| 相减 | 81.2 | 81.1 |
| 包装余项 | 10.6 | 10.2 |
| 总 SIC | 2031.8 | 1822.5 |

validate 字段仍包含输出复制及干扰缓冲清零，因此没有归零；该字段这次下降 166.9 µs。总 SIC mean 2.032→1.822 ms，约降低 10.3%；总 P95 2.270→2.070 ms。总平均差值还包含参数估计等未改阶段的波动，不把全部 209.3 µs 归因于删除扫描，也不与过去不同负载运行直接作差。

新重构：相位表 3.28、事件相位/CIR 累加 185.15、检查 0 µs。调制+重构约 227.7 µs，最终相减另计。总 SIC 不含后续感知 CIR 与感知解调。
