## 3. A-R02：相干/随机能量分解（完成）

### 代码位置

`tools/sic/accum_metrics.py::coherence_stats`：

```
mu = (1/N)Σ_r E_r ; e_coherent = N·||mu||² ; e_centered = Σ_r||E_r−mu||²
e_total = e_coherent + e_centered ; coherent_fraction = e_coherent/e_total = eta
```

`mean_energy` 保留为 `||mu||²`（单符号平均能量，**不可**与 `e_centered` 相加），
并新增 `mu_energy`、`e_coherent/e_centered/e_total`、`energy_conservation_rel`；
`mean_fraction` **置空**并带 superseded 说明（旧式 `||mu||²/e_total` 把单符号平均
与 N 符号总量混用）。verifier 独立复算全部能量字段并校验守恒。

### 实测（acceptance_rectification，support-disjoint N=54，`sic`/`all` ROI）

| cell | eta=coherent_fraction | e_coherent | e_centered | e_total | 守恒相对误差 |
|---|---|---|---|---|---|
| isr0/10/20_cfo0_single | 0.9995 / 0.9996 / 0.9996 | 0.0676 | 2.5e-5…3.1e-5 | 0.0676 | ≤5e-16 |
| isr0/10/20_cfo∓50k_single | 0.0122–0.0125 | 0.014–0.016 | 1.13–1.28 | 1.14–1.30 | ≤4e-16 |
| isr0_cfo+50k_four | 0.0122 | 0.0241 | 1.957 | 1.981 | 2.4e-16 |
| isr10_cfo0_four / off0.4 | 0.9997 / 0.9999 | 0.103 / 0.224 | 3.1e-5 / 3.2e-5 | 同 | ≤5e-16 |

`e_centered` 大不等于随机：CFO≠0 的 `e_centered` 就是确定性相位斜坡（§5.3 的
centered lag-1≈0.999 佐证）。旧字段的错误幅度示例（CFO=0、N=54）：
`mean_fraction = eta/N = 0.0185`，而 `eta = 0.9996`；对 64 个完全相同的残余旧字段
给 1/64≈0.0156 而不是 1。

### QA（A-R02）

N=1/8/64 重复残余 → `coherent_fraction=1`、`e_centered=0`；人工独立零均值序列 →
≈1/N；相位斜坡 → 守恒成立而 eta 很低且 `e_centered>0.9·e_total`；零能量 → N/A；
`e_coherent == N·mu_energy`；`mean_fraction` 为 None 且带 superseded 说明。
拒绝 QA：**“丢掉 N 因子”（令 e_coherent=mu_energy）被拒**；CSV/汇总篡改被拒。

## 4. A-R03：残余误差来源（用户新增研究任务，完成）

### 方法（真值隔离）

* 在线结果仍由真实 `uwb.preamble_sic` adapter 产生（不注入真值，`uses_truth=False`）。
* 诊断重建使用 **C++ core 的真实 polyphase 算子**（32 相位、Hamming 窗、逐相位
  线性混合），在 `tools/sic/residual_budget.py` 中独立实现；对
  **全部 600 窗**的 `i_hat` 与 adapter 公布值比对，NMSE ≤ **3.4e-15**（即诊断路径可信）。
* 真值辅助替换（`uses_truth=True`，独立命名空间，不回流在线）：
  S1 仅 CFO、S2 仅 tau、S3 仅复增益、S4 路径集+增益、S5 tau+CFO、S6 全真值（可达地板）、
  C1/C2 为**条件重拟合**（分别标注，不当成单项贡献）。路径以**显式延迟配对**（一对一，
  不做 tap 序号硬对应）；增益统一换算到 `pref=0` 帧，保证“只换 CFO”真的只换 CFO。
* 训练输入对照：同一 s/i/w 与同一幅度尺度，用 adapter 分别估计
  `i_only / s+i / i+w / s+i+w`（**不按 ISR/SNR 重新归一化 i**）。
* 误差预算在固定 mask/ROI/N 上按复残余向量分解
  `i−i_hat = (i−i_true) + (i_true−i_hat)`，显式给出交叉项。
* 覆盖：4 个指定类 + ISR0/20 nominal，共 6 class × 100 acceptance 窗；
  与 `acceptance_rectification` 的归档窗**逐位比对 24/24 一致**（raw+clean），
  不是在相同 seed 下推定。

### 4.2 训练输入对照（IQ，dB 相对输入；`fit_vs_truth` = 相对真实干扰波形的模型误差）

| class | i_only cancel | i+w cancel | s+i cancel | i+w fit_vs_truth | s+i fit_vs_truth |
|---|---|---|---|---|---|
| isr0_cfo0_single | **−145.3** | −29.87 | **−2.53** | −49.3 | −20.8 |
| isr0_cfo+50k_single | **−127.7** | −29.89 | **−2.03** | −50.4 | −9.0 |
| isr10_cfo0_single | **−153.2** | −39.89 | **−10.17** | −59.8 | −28.4 |
| isr20_cfo0_single | **−148.0** | −49.87 | **−20.00** | −69.6 | −38.3 |
| isr10_cfo0_four | −32.2 | −31.49 | −10.25 | −32.1 | −25.4 |
| isr10_cfo0_off0.4_single | −24.7 | −24.54 | −10.06 | −24.7 | −23.1 |

结论（整数时延类，清晰可分）：
1. **只有干扰**时模型几乎完美（−128…−153 dB）→ 估计器 + 冻结算子**不是**瓶颈，
   模板/有限长/数值地板在此类可忽略（也由 §4.1 的 −152 dB 佐证）。
2. 只有 AWGN 时：`i+w` 的 cancel 精确等于噪声/干扰功率比（如 ISR10/SNR30 期望
   −40 dB，实测 −39.89；ISR20 期望 −50，实测 −49.87），而 `fit_vs_truth` 仅
   −49…−70 dB → **噪声是次要项**。
3. **加入 sensing 信号（无任何噪声）后**：`fit_vs_truth` 掉到 −20.8/−28.4/−38.3 dB，
   cancel 掉到 −2.5/−10.2/−20.0 dB → **训练区被 sensing 污染是主因**。
4. 绝对残余的 ISR 无关性由此解释：把 `fit_vs_truth` 换成绝对能量
   （`e_input·10^(dB/10)`）得 ISR0/10/20 = 10^−2.08/10^−1.84/10^−1.83，
   即**绝对泄漏能量跨 ISR 近似不变（1.7 倍内）**，与初版“绝对残余不随 ISR 缩放”
   一致；泄漏幅度 ∝|s|，与干扰幅度无关。

  仅换增益反而变差 1.6 dB（增益偏差与 CFO 误差在此耦合）。
* four-path：全真值地板只有 **−27.3 dB**（≈ §4.1 的 −29.8 dB 不匹配）；
  参数替换最多再得 4.3 dB。
* off0.4：任何替换都无效（±0.4 dB 内），全真值地板 −19.7 dB →
  **地板由生成器/算子分数内插不匹配决定，不是 SIC 参数**。

### 4.4 误差预算与确定性

| class | e_impl/total | e_param/total | e_cross/total | 恒等式残差 | 窗口均值向量能量 / 跨窗波动能量 |
|---|---|---|---|---|---|
| isr0/10/20_cfo0_single | 0.000 | 1.000 | 0.000 | 0 | 0.0675 / 1.4e-4…1.6e-4 |
| isr0_cfo+50k_single | 0.000 | 1.000 | 0.000 | 0 | 1.2948 / 1.0e-3 |
| isr10_cfo0_four | 0.353 | 1.035 | −0.388 | 1e-16 | 0.1032 / 1.6e-4 |
| isr10_cfo0_off0.4_single | 1.131 | 1.189 | −1.320 | 2e-16 | 0.2235 / 1.7e-4 |

* 整数类：残余**100% 来自参数误差**（impl 项数值为零）。
* 分数类：impl 与 param 同量级且**交叉项强负**——两部分在总残余里部分抵消，
  因此**不能把各分量 dB 相加成 100% 贡献**（本报告不做这种加法）。
* 确定性：均值向量能量/跨窗波动能量 = 4e-4…2.4e-3 → 残余 **>99.7% 可跨窗重复**，
  与初版“相干地板”一致；跨窗只贡献千分之几。

## 6. 两组结论

### 6.1 仍然成立的原始发现

1. **CFO=0 nominal 的 CIR SIC 收益 ~28.4 dB**（ISR10）与 ISR 线性关系（18.4/28.4/38.4 dB）
   在 support-disjoint 集合上原样复现（28.39 dB）。
2. **残余是相干且跨窗可重复的**：`coherent_fraction` 0.9995（CFO=0），
   均值向量能量/跨窗波动 ≈2.4e-3 → 不随 N 衰减：support-disjoint 上
   `G_sic(54) = −0.007 dB`（ISR10/CFO0，即完全无累加收益）；
   困难 CFO（ISR10/CFO−50k）甚至为 **−3.59 dB**（残余随 N 变大，
   因为残余沿前导增长），而同期 `G_raw(54)=+21.6 dB`。
   不能假设额外 10log10(N)。
3. **弱目标保护**：support-disjoint 下 12 格 × 21 个 (set,N) 组合
   **252/252 全通过**（`|amp err| P95 ≤1 dB`、峰移 ≤1 sample）；
   ISR10/CFO0 nominal 实测 sic 0.153 dB vs raw 1.343 dB，峰移 0。
4. **困难 CFO 大 N 收益有限**：ISR10/CFO∓50k 在 54 符号上只有 ~13.4 dB，
   远低于 N=1 的 27.6 dB；ISR0 更差（+2.9 dB）。
5. **receiver 层**：ISR20 单径 raw 分支 `timing_failed` 0/20；SIC/clean 20/20 ok；
   SIC 把 target-to-background proxy 提升 18–22 dB。
6. **旁路**：1000/1000 `out == y` 逐字节、无伪造 C_CIR、目标零误差。

### 6.2 只有修正/新增之后才成立的发现

1. **旧“独立区”定义不成立**：`[8,8+N)` 会读训练/guard（r=8）与未相减尾部（r=63）。
   修正后**困难 CFO 远端的负 C_CIR 消失**（ISR0/CFO −1.06 → +2.94 dB；
   four/−2.72 → +1.08 dB；ISR10 9.42 → 13.35 dB）。旧负值主要是评价口径造成的。
2. **相干能量的正确分解**：`coherent_fraction = eta = N·||mu||²/e_total`；
   旧 `mean_fraction` 小 N 倍（0.0185 对 0.9996）。
3. **残余来源排序（本轮新增、有因果对照）**：
   训练区 **sensing 污染** > 训练 **AWGN** > **CFO 估计误差（仅困难 CFO 格）** >
   时延误差（整数格为 0，four-path 0.025 sample ≈0.1 dB）；
   模板/有限长在整数格为**数值零**（−152 dB）。
4. **分数时延格的真正地板**：生成器 pchip 分数内插 vs 核心 polyphase 算子
   不匹配 −22.5…−29.8 dB，导致 four-path/off0.4 的“全真值可达地板”只有
   −27.3/−19.7 dB，且 off0.4 任何参数替换无效。它是**仿真口径**问题，
   不是 SIC 算法缺陷（真实前端不存在 pchip）。
5. **冗余自由度**：单径干扰被拟合成 3 条路径（所有 ISR），
   说明模型用额外路径吸收非 comm 成分；这也是“增益偏差”与“训练污染”同源的另一面。
6. **拟合增益的物理含义**：S3“仅换真值增益”单独就带来 +29.6…+30.8 dB，
   说明在线增益=LS 拟合值，而该拟合把 |s| 的投影吃进增益，
   绝对泄漏能量跨 ISR 近似不变（10^−1.83…10^−2.08）。
