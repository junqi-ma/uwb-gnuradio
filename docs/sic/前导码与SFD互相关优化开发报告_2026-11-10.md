# 前导码与 SFD 互相关优化开发报告（2026-11-10）

## 1. 结论与摘要

本轮开发针对通信接收机解调与 SIC 前端中的前导码同步（`stage_timing`）与 SFD 搜索（`stage_sfd`）互相关核心进行了专用向量化优化。

主要成果与结论如下：
1. **Preamble-Only SIC 核心耗时跨入亚毫秒门槛**：平均总核心时间（Mean Core Time）从历史基线 1.15–1.25 ms 降低至 **828.12 µs**（P50 为 **812.35 µs**，P95 为 **999.00 µs**，全部进入 1 ms 以内），绝对耗时减少约 320–420 µs。
2. **Full-Packet SIC 核心耗时大幅压减**：平均总核心时间从 1.58 ms 降至 **1,142.42 µs**（P50 为 **1,128.12 µs**，P95 为 **1,276.16 µs**），降幅约 28%。
3. **通信前导解调与跟踪提速**：
   - 粗同步与细跟踪（`stage_timing`）：耗时由 ~380 µs 降至 **97.70 µs**（约 **3.9× 加速**）。
   - SFD 搜索与尾部精估计（`stage_sfd`）：耗时由 ~340 µs 降至 **212.04 µs**（约 **1.6× 加速**，其中 `tail_retrack` 阶段由 289 µs 降至 67 µs）。
   - 通信解调前端（`comm_rx`）：Preamble-only 模式下耗时从 ~720 µs 降至 **320.80 µs**（约 **2.25× 加速**）。
4. **数值等价与消除质量完全保真**：
   - 针对性数值 QA 测得实数展开 AVX2/FMA 点积与标量/VOLK 误差小于 $4.8 \times 10^{-7}$（QA 断言门槛 $10^{-5}$）。
   - Preamble-Only 干扰抑制比保持为 **63.29 dB**，Full-Packet 干扰抑制比保持为 **63.33 dB**，提交决策 100% 成功（`committed = true`），未发生任何解调或消除退化。
   - 包含 demod/sic/sfd/unified 在内的 9 项 CTest 全部 100% 通过。

## 2. 瓶颈定位与数学推演

### 2.1 问题与瓶颈定位
在之前的离散 CIR、稀疏脉冲重构与 CMF/PHR 融合优化后，整包与前导消除的核心耗时中，`comm_rx`（通信解调）占比已跃居首位（超过 60%）。而在 `comm_rx` 内部，耗时主要集中在：
- `stage_timing`：在连续 64 个符号窗口内进行滑动互相关（粗搜索 + $\pm 16$ 步长细跟踪），需执行多次长向量点积。
- `stage_sfd`：SFD 序列探测与多径/CFO 联合尾部重估计（`tail_retrack`）。

原实现直接使用通用复数点积 `volk_32fc_x2_dot_prod_32fc`。通用复数乘法计算 $(a + jb)(c + jd) = (ac - bd) + j(ad + bc)$，单点需要 4 次浮点乘法与 2 次浮点加法，并伴随频繁的实虚部分离与寄存器交织解包开销。

### 2.2 纯实数前导模板与降维推导
根据 IEEE 802.15.4z 标准，前导 SYNC 序列由三元伪随机序列扩张并经由根升余弦（RRC）或脉冲整形滤波器生成，基带发射模板 $s[k]$ **全为实数**，即：
$$\mathrm{Im}\{s[k]\} = 0, \quad \forall k \in [0, L-1]$$
当输入接收信号为复数序列 $x[k] = x_r[k] + j x_i[k]$ 时，互相关内积为：
$$R = \sum_{k=0}^{L-1} x[k] \cdot s^*[k] = \sum_{k=0}^{L-1} (x_r[k] + j x_i[k]) \cdot s[k] = \left( \sum_{k=0}^{L-1} x_r[k] s[k] \right) + j \left( \sum_{k=0}^{L-1} x_i[k] s[k] \right)$$
因此：
1. **乘法计算量减半**：由 4 次实数乘法骤降至 2 次实数乘法，完全省去虚部交叉乘法项（$ac - bd$ 与 $ad + bc$）。
2. **零解包开销（Duplicate-Taps 向量化）**：
   将实数模板预先处理并复制存放在连续内存中：
   $$\mathbf{T} = [s_0, s_0, s_1, s_1, s_2, s_2, \dots, s_{L-1}, s_{L-1}]$$
   此时 $\mathbf{T}$ 的内存布局恰好与复数输入数组 $[x_{r0}, x_{i0}, x_{r1}, x_{i1}, \dots]$ 的实虚部交织结构一一对应。使用一条 AVX2 256 位乘加指令 `_mm256_fmadd_ps`，即可在单周期内同时完成 4 个复数输入与模板的内积累加。

### 2.3 4 滞后（4-Lag）并行互相关展开
在 `fine_track` 细时延跟踪中，算法需要计算滞后 $\tau \in [-W, W]$ 范围内的能量，即：
$$R(\tau) = \sum_{k=0}^{L-1} x[k + \tau] \cdot s[k]$$
若逐滞后调用点积，输入数据 $x[k]$ 会被重复从 L1 缓存加载 $2W+1$ 次。
优化设计中实现了 `real_template_dot_4lag_avx2`：
- 单次加载一个 256 位的模板向量 `T`（包含 4 个连续样点复制：`[s0,s0, s1,s1, s2,s2, s3,s3]`）。
- 结合非对齐读取 `_mm256_loadu_ps`，同时从内存加载 $x[k], x[k+1], x[k+2], x[k+3]$ 对应的 4 个复数窗口。
- 使用 4 组独立的累加寄存器，利用 FMA 双发射端口在单次流水中并行产出 $\tau, \tau+1, \tau+2, \tau+3$ 四个时延点的复数相关值。
- 该并行展开将内存读取总开销降低了近 70%，并将细跟踪性能提升了约 4 倍。

### 2.4 SFD 符号级 Kronecker 分解与种子窄窗联动
1. **SFD 符号级降维**：SFD 字段由 8 个符号组成（每个符号对应调制为 $\pm 1$ 的 SYNC 序列）。优化重构了 `sfd_dot`，避免大跨度盲目相关，利用单个实数 SYNC 符号积分累加值结合 SFD 码序列点乘。
2. **种子定时窄窗精搜**：
   在统一 SIC 控制器 `uwb_sic_unified.cc` 中，感知前导先验已提供粗同步参考。当 `channel.q >= 0` 时，动态启用 `demod_prof.timing_seed_refine_radius = 16`。通信接收机跳过全局 $\pm 256$ 盲搜，直接以 33 个点（$\pm 16$）为中心精搜；若粗同步偏差导致未捕获，自动回退到全窗搜索，无缝保障了稳健性与性能的最优兼顾。
