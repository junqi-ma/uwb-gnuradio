# CFO/转换/数值检查的隔离诊断

本轮用户授权拆分原约2.3ms的CFO/转换/数值检查。生产重构融合循环保持原样。
新工具 `benchmark_fullpacket_cfo_diag` 使用与重构库相同的generic O3编译，不加native或fast-math。
从公开元数据/raw IQ重新估计、解码并调用原重构，捕获有效支持区的实际accum、IQ和原model；
保留绝对采样坐标与相位参考，不读取注入sidecar或分量IQ。

四种离线scratch重放：原融合双检查、融合仅model检查、融合不作显式检查、完整拆分双检查。
减少检查仅用于已知有限快照的成本对照；每次计时后仍完整检查并与原库model逐位对照。
生产IQ输出不接入诊断变体，不以取消NaN/Inf或试减溢出检查换性能。

拆分阶段：1024基表、旋转因子、double→float、复乘、model有限性扫描、试减、试减有限性扫描。
拆分增加缓冲读写并改变编译器优化，子计时只属于拆分实现；不直接当成原融合2.3ms的精确归因。
仅model检查变体同时省掉试减表达式，不将差值全称为“有限性谓词成本”。

预算：3组针对性QA；两个代表格各16快照，每变体每轮128次、两轮，8次热身，变体顺序交错。
每个变体前都在计时外复制相同快照到复用热输入缓冲。正式运行独占benchmark锁，
绑定源码、实际库、工具、编译选项和源IQhash；记录subnormal数量与MXCSR模式供解释。
本轮不重测整包队列/吞吐，不自动采用优化实现。
