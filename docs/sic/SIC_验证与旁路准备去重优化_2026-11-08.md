# 事务验证与旁路准备去重

## 修改

稀疏脉冲事务入口保留一次原始 IQ 有限值扫描及一次旁路复制/清零。内部使用私有 apply 实现复用准备结果，去掉第二次整窗 IQ 扫描、输入复制和干扰缓冲清零。有 ihat 时直接复用外层清零结果，不再对支持范围清零；ihat 为空时仍对实际累加区清零。

公共 apply_discrete_cir_pulses 签名和独立调用行为保留：自行检查输入并建立旁路。CRC/PHR、事件列表、模型/ROI、容量和截断检查保留；此前已关闭的最终输出数值扫描仍关闭。没有完全删除输入扫描，本轮优化的是重复操作。

私有 transaction_prepared 标志仅由 fullpacket_cancel_discrete 在完成验证和缓冲初始化后设置，不进入公开模型或 scratch，避免调用者错误跳过准备。

## 验证

独立新 build：gr-uwb/build-sic-fullpacket-validation-reuse。estimator/reconstruct 两项 CTest 通过。新增事务 QA 覆盖 ihat=nullptr 的实际输出、输入末尾 NaN、FCS 拒绝，以及调制完成后的 context_truncated；使用脏输出缓冲确认失败仍 out=y、ihat=0。

两轮新旧实际输出对照各 8 窗，均逐位一致，通信/感知/提交一致。紧凑四径的 28.184 dB 消减保持。未改信道、估计方法和解码。

## 配对性能

紧凑四径、32 B、20 tap、lag_lo=-1。新旧均跳过最终输出检查。独占 benchmark lock，ABBA，每轮 8 次预热、64 次观测，每配置 128 次。第一轮有明显慢窗，只补一次同规模，以下合并两轮全部观测，每配置 256 次，不筛慢窗。

| 阶段 | 旧 mean µs | 新 mean µs |
| 参数估计 | 262.8 | 235.3 |
| 通信解码 | 1291.0 | 1411.8 |
| 外层验证及一次旁路准备 | 286.3 | 357.6 |
| 调制/脉冲列表 | 34.9 | 45.2 |
| 干扰重构 | 233.7 | 219.7 |
| 相减 | 85.3 | 102.9 |
| 包装/copy 余项 | 288.4 | 10.7 |
| 总 SIC | 2482.4 | 2383.3 |

包装余项从 288.4 降至 10.7 µs，去掉重复准备及扫描的收益明确。总 SIC mean 约下降 4.0%，但通信解码、外层验证等未改阶段有较大波动，实际收益不能等同包装余项差值；两次新路径总均值 2.393/2.373 ms，对照 2.468/2.497 ms。

总 SIC 合并 P95：4.189→4.294 ms，未改善，不宣称尾延迟优化。上一轮较安静环境的 2.156 ms 不能直接作当前配对基线。保留一次输入扫描，外层 validate 仍为主要内存操作开销。
