# SIC 帧与输入验证：实际耗时拆解

配置：紧凑四径、32 B、20 tap、lag_lo=-1、稀疏脉冲路径，最终重构数值检查已跳过。接收窗口 236,416 个复数采样。这里的 validate 还包含旁路缓冲准备，不能全部称为校验。

## 外层 validate

临时细分计时均值，单位 µs：

| 操作 | 耗时 | 作用 |
|---|---:|---|
| 复制输入至输出 | 64.52 | 提前建立失败时 out=y 的旁路图像 |
| 清零干扰缓冲 | 52.40 | 提前建立失败时 ihat=0 |
| 容量、模板、profile、帧长与 FCS 标志 | 0.37 | 支持配置与结构性检查 |
| 重算 CRC/FCS | 1.01 | 对已解码 PSDU 再核对末两字节 FCS |
| 生成并核对 PHR | 0.48 | 校验长度/配置对应的 19 个 PHR bits |
| 模型与 ROI | 0.16 | CIR/CFO/相位参考/支持与边界检查 |
| 扫描原始 IQ 的 NaN/Inf | 134.04 | 遍历 236,416 个复数输入 |
| 父阶段 validate | 253.42 | 包含少量计时及包装余项 |

内存准备约 116.93 µs，占约 46%；输入有限值扫描占约 53%；CRC/PHR/参数等实际小检查合计约 2 µs。上一轮 268.9 µs 是父阶段，不能把它解释为 CRC 或 PHR 开销。

## 重构入口重复操作

apply_discrete_cir_pulses 在外层验证之后还执行：

| 操作 | 耗时 µs |
|---|---:|
| 再复制输入至输出 | 49.69 |
| 再清零干扰缓冲 | 41.48 |
| 事件列表检查（8,384 条及首 SYNC 模板） | 9.63 |
| 模型/模板/ROI 检查 | 0.27 |
| 再扫描整个 IQ | 173.48 |
| 小计 | 274.55 |

这部分发生在 channel_us 启动前，统计进入 copy/包装余项，不在重构合计内；copy bucket 不能按字面理解为纯 memcpy。本轮诊断 copy bucket 为 275.89 µs。

两层合计：输入 IQ 扫描约 307.52 µs，旁路复制/清零约 208.10 µs。成功路径重复准备两次旁路；进入真正 CIR 累加前，还会对重构支持范围再清零一次（已计入 channel.zero），本表不重复相加。

## 简化方向

优先去除同一事务内第二次 IQ 扫描；是否保留第一遍按性能需求决定。其次让事务 wrapper 与内部 apply 共用一次旁路准备，公共独立 apply 仍自行负责失败输出。CRC/PHR/模型/边界校验便宜，删除它们收益很小。事件列表检查约 10 µs，可留在公共接口，内部可信生成器路径后续再考虑简化。本轮仅测量，未实施这些删除。

## 证据与范围

生产源码、binary/library 未修改。临时复制 reconstruct 源码，加 12 个段计时，编译独立诊断共享库，用 LD_PRELOAD 只对本次诊断进程替换函数；使用同样 -O3，不增加 -march=native。前 8 次预热不入段统计；串行 base/diag/diag/base，各轮 64 次计时，每变体 128 次，独占 benchmark lock。8 窗诊断与生产实际输出逐位一致。

生产对照 validate/copy 为 292.89/266.05 µs，诊断为 253.42/275.89 µs，存在运行波动；细分值用于判断成本量级，不把差值当作加速收益，不与过去某一轮总 SIC 直接相减。

产物：`gr-uwb/build-sic-fullpacket-no-final-check/results/validate_detail_20261108_011753/`。包括原始逐窗、段计时日志、summary、复制的诊断源与 .so/编译参数、运行脚本、库绑定和哈希。本轮没有新增产品代码，也没有扩大测试。
