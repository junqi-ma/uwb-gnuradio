## 3. 实施规格与技术细节

### 3.1 瓶颈 1：`stage_sfd` 尾部 40 符号复用与 SFD 8 符号预折叠（Track B）

#### B1：`run_tail_and_cfo_refit` 尾部 40 峰条件复用

首次定时与尾部重跟踪都在原始 `rx` 上做 SYNC 相关，存在免重复相关的机会。实际候选数由 `local_best` 的半开区间和边界决定，不固定声称是 `40 × 17` 次或预先承诺微秒收益。

- **准入条件**（全部满足才复用）：
  1. 保存首次 `stage_timing` 的有效结果，在后续 `res.timing` 被覆盖后仍能可靠访问；使用 scratch 预留存储，避免逐包额外分配。
  2. 首次 `detected_peaks == full_repetitions`，且 `peak_samples`、`peak_metrics`、`peak_corr` 三个数组长度均等于 `full_repetitions`；`template_len > 0`，`0 < tail_repetitions <= full_repetitions`。
  3. 首次实际 `timing_track_radius == 8`，本次实际 `seed_radius == 8`，尾部 anchor 的跟踪半径同为 8、禁止回溯。输入、模板归一化、相关核、功率归约和窗口端点规则一致；不以“半径非零”代替参数一致性。
  4. 令 `tail_first = full_repetitions - tail_repetitions`，`start1 = initial.peak_samples[0] - (template_len - 1)`。要求 `tail_start == start1 + tail_first * kQm35SamplesPerSymbol`，且 `initial.peak_samples[tail_first] - (template_len - 1) == tail_start`。
  5. 尾部所有峰的有限度量均达到实际 anchor 阈值（当前 0.20），且首峰也确实由同一窗口、同一选峰规则得到。当 `tail_first == 0` 而首次首峰来自不同的 acquisition 搜索时，保守重搜。
- **实现**：切片复制尾部峰数组，按原 `stage_timing` 的相同运算顺序拟合斜率/截距，并正确填充 `ok`、`metric`、起点、峰数等后续读取字段。保持现有 CFO 拟合和最终 SFD 验证。
- **回退与诊断**：任一条件不满足、实际 `seed_radius == 0` 的宽窗重试均执行原路径；不得将覆盖后的 CFO 定时结果当作首次跟踪结果。增加独立的复用计数，不伪造 `seed_refine_narrow_attempts/success`，计时反映实际执行工作。
- 此优化是免重复相关，仍有峰数组复制，不称为“零拷贝”。满足准入条件的复用结果应与重跑一致；不承诺所有配置均可复用。

#### B2：`stage_sfd` 的 8 符号 Kronecker 窗口线性预折叠与模板键快检
- **问题定位**：
  - 在 [`uwb_demod_core.h#L924-L988`](/home/junqima/workspace/uwb-gnuradio/gr-uwb/include/gnuradio/uwb/uwb_demod_core.h#L924-L988) 的 `scan_window` 中，每个粗搜候选（17 个）和细搜候选（15 个）均遍历 8 个 SFD 符号做 8 次 1016 点实数点积。
  - 同时 [`uwb_demod_core.h#L819-L828`](/home/junqima/workspace/uwb-gnuradio/gr-uwb/include/gnuradio/uwb/uwb_demod_core.h#L819-L828) 在纯实数快路径下仍调用模板身份哈希并维护 8128 点复数 `scratch.sfd_template`，而后续 `sfd_dot` 在 `real_sync_template.is_real` 为真时根本不读取 `scratch.sfd_template`。
- **数学变换与实现要求**：
  1. **跳过冗余复数 SFD 模板构造**：
     - 在 `stage_sfd` 中，先检查/构建 `scratch.real_sync_template`（以模板内容和长度校验身份，记录 64 位内容哈希及实际归一化状态，避免同长度模板变化时误用旧缓存；只比较指针或长度不足以判定有效）。
     - 当 `profile.rx_fast_sfd && scratch.real_sync_template.is_real` 为真时，跳过 `sfd_template_key` 与 `build_sfd_template`（仅在 `!scratch.real_sync_template.is_real` 或 `!profile.rx_fast_sfd` 时构造复数 `sfd_template`）。
  2. **8 符号窗口线性预折叠（Pre-folding）**：
     - 对于 `scan_window` 中给定的搜索范围 $[j_{\text{lo}}, j_{\text{end}}]$（通常 $j_{\text{end}} - j_{\text{lo}} \le 128$），任意候选偏移 $j \in [j_{\text{lo}}, j_{\text{end}}]$ 处的 SFD 相关满足：
       $$\sum_{i=0}^{L_{\text{sfd}}-1} s_i \sum_{k=0}^{\text{sym}-1} \text{rx}[j + i\cdot\text{sym} + k] \cdot t[k] = \sum_{k=0}^{\text{sym}-1} F[(j - j_{\text{lo}}) + k] \cdot t[k]$$
       其中折叠序列 $F[m] = \sum_{i=0}^{L_{\text{sfd}}-1} s_i \cdot \text{rx}[j_{\text{lo}} + m + i\cdot\text{sym}]$，长度仅为 $\text{fold\_len} = (j_{\text{end}} - j_{\text{lo}}) + \text{sym}$（对于 $\pm 64$ 窗仅为 $128 + 1016 = 1,144$ 点）。
     - 在 `DemodScratch` 中预分配 `std::vector<std::complex<float>> sfd_folded`（在准备阶段按支持窗口上限预留容量；写入前 resize 到实际长度，热路径不扩容，容量不足回退原路径）。
     - 在 `uwb_rx_sync_opt.h` 中实现 `fold_sfd_window(const std::complex<float>* rx_base, size_t sym, const int8_t* sfd_seq, size_t sfd_len, size_t fold_len, std::complex<float>* out)`（含 AVX2 向量加减法核 `vector_sub_complex_avx2`）：清零或以首个非零符号初始化 `out[0..fold_len)`，对其余非零符号按 $s_i \in \{+1, -1\}$ 调用 AVX2 复数向量加/减。
     - 在 `scan_window` 中，当 `profile.rx_fast_sfd && scratch.real_sync_template.is_real` 时，先调用一次 `fold_sfd_window` 生成 `sfd_folded`，随后：
       - **粗搜循环**：对每个粗搜候选 $j$，直接调用单次 `real_template_dot_single(sfd_folded.data() + (j - j_lo), taps_dup, sym) * sfd_scale`；
       - **细搜循环**：对连续 4 个细搜候选 $j$，直接调用单次 `real_template_dot_4lag(sfd_folded.data() + (j - j_lo), taps_dup, sym, acc4)` 并乘以 `sfd_scale`，尾部不足 4 点调用 `real_template_dot_single`。
     - 窗口滑动功率 `pwr` 仍在原序列 `rx` 上按原有公式更新，候选访问顺序、阈值与并列比较规则保持不变。检查折叠读取最末样点及四滞后末行支持，裁剪窗口和尾部不越界。
     - 预折叠是精确算术下的等价变换，浮点加法顺序变化不保证相关值逐位相等，也不能据此保证任意临界输入的选峰不变；按第 4 节误差与已测决策门槛验收。
     - 实数快路径中独立计算逻辑 `sfd_len = len * sym`，不能因跳过复数模板而读取旧数组长度或触发空模板失败。复数模板与非快路径继续保留原实现；不重新解释或丢弃模板虚部。

### 3.2 瓶颈 2：Full-Packet 相位累加 SIMD 与 NS-SFD 稀疏滑窗（Track B）

#### B3：`sync_phase_gain` 保持原顺序的 SIMD 累加

- 当前 `stage_cir_softchips` 累加默认 54 个 SYNC，`sync_phase_gain` 另外从零累加最后最多 32 个 SYNC。现有收缩循环已经通过 `if (!spread[c]) continue` 跳过零项，不将稀疏跳零重复计作新优化。
- 当一个符号窗口完整可读（`lo == 0` 且原边界检查通过）时，调用 `rxopt::vector_accumulate_complex`；下边界裁剪继续走原标量循环，保留尾部处理与非 AVX2 回退。
- SIMD 仅并行不同样点，对每个样点保持按原符号顺序从零相加；后续非零码元与 tap 收缩继续采用原运算顺序，本轮不增加 FMA 重排。
- **删除累计和相减提取**：不使用 `sum(10..63) - sum(10..31)` 代替 `sum(32..63)`。float 下存在舍入和消减误差，整数周期与未裁剪条件不足以保证精度；也不新增 `sum_precomputed` 接口。
- 保留现有 FIR 支持、相位起点、归一化和失败回退。相位增益接近零时以绝对误差核对，不使用不稳定的相对误差判定。

#### B4：`stage_ns_sfd` 有序稀疏偏移表与滑动能量

- 在 `DemodScratch::CachedSequenceState` 中缓存按原始 chip 偏移升序排列的 `(offset, sign)` 表、完整模板长度及范数。按 `code_index` 与 `sfd_mode` 更新/失效；表应与本次实际 `sfd_sequence` 内容匹配，不能仅凭 `chips_per_symbol == 508` 使用缓存。
- 当前默认完整模板为 4,064 chips，非零数由实际 SFD 序列计算，不硬编码 512；偏移类型需覆盖支持的模板长度，无法表示或缓存不匹配时回退原路径。
- 对候选按原顺序遍历非零项，以 `corr += sign * soft_chips[k + offset]` 累加；不将正、负项拆成两组重排。所有输入有限性与窗口支持检查仍保留，零码元不能用来绕过 NaN/Inf 检查。
- 首个候选对完整窗口做 double 能量累加，后续以 `E += double(v_in)*v_in - double(v_out)*v_out` 更新，平方根前做合理的非负截断。double 降低滑动漂移，不代表消除舍入误差；非有限或明显非法能量走原失败/回退语义，不能直接截成零。
- 保留原候选集合、阈值、极性与并列规则。完整 NS-SFD 模板、soft-chip 生成范围及绝对坐标不变，不重新引入约 500 chips 的裁剪。
- 滑动 double 能量与旧 float 能量并非逐位等价；相关量按误差门槛验证，已测用例的选峰位置和解码决策保持一致。

### 3.3 瓶颈 3：`estimate_channel` Ipatov 去旋转向量化与粗搜去重（Track A）

#### A1：提前生成并复用 Ipatov CFO 旋转表

当前 Ipatov 训练平均仍采用逐点双精度相位递推，残差检验另行调用 `build_cfo_rotation`。将旋转表提前生成，在同一包内共享，不缓存到下一个 CFO 不同的包。

1. 先按原逻辑筛选合法训练窗口；有效窗口数由边界决定，不固定为 7。根据残差样点和合法窗口实际相对坐标推导旋转表长度，检查整数转换、容量和每次索引范围，不按经验公式访问。
2. `build_cfo_rotation` 存储 `exp(-j*omega*m)`：训练去旋转使用 `rot[m]`，残差重构使用 `conj(rot[m])`。保持 double 计算、相位原点及每 1024 点按绝对坐标重锚定，不改变 CFO 符号。
3. `lo >= q` 的窗口使用共享旋转表，四路展开独立样点，保持每个 `avg[j]` 的符号累加顺序。合法窗口若含负相对坐标，保守保留原标量绝对相位路径，不为少见配置增加负索引表方案。
4. 仅对精确 `cfo == 0.0` 走免表、免复乘路径；不能把估计得到的小非零 CFO 截断为零。零 CFO 残差直接计算 `obs - z[m]`。
5. 删除本包残差阶段的重复建表。新的表锚定与旧窗口递推归约存在浮点差异，验收检查数值误差与决策保持，不要求浮点量或 `model_id` 无条件逐位一致。

#### A2：保守的邻域重搜去重与首确认峰复用

粗搜已覆盖 stride=1 的整数候选，但当前四滞后与单滞后核的归约结果不能未经验证就视为逐位相同。回溯还可能使最终 `q` 与全局峰位置不同。

1. 记录候选坐标及其对应的 `(corr, norm)`，确保值确实属于最终 `q`。`peak_norm` 是检测过程保留的峰度量，回溯后不一定属于 `q`，**禁止直接用它填 `rep_norms[0]`**。
2. 只有 `stride == 1`、未发生 origin 回溯，且已有结果与被省略调用的相关核、能量计算及数值结果一致时，才允许去掉重复邻域查询或复用 `rep_corr[0]/rep_norms[0]`；非实数模板或其他内核也需逐一满足该条件，不能从某个 AVX2 用例外推全部实现。
3. 对四滞后/单滞后无法确认数值一致的分支，保留现有局部单点复查；可复用已经执行过且坐标匹配的单点计算。发生回溯、`stride > 1` 或缓存不匹配时保留原精搜和确认路径，不改变历史 origin/peak 更新规则。
4. 不预先承诺省去 7 次点积。仅去重且使用完全相同数值的分支应保持模型逐位一致；如只满足容差而未满足上述复用条件，本项继续使用旧路径。

### 4.1 针对性 QA 与相关回归

在现有模块 QA 中补充/扩展以下五组小用例：

1. A1：零及正负非零 CFO，对照原训练平均和残差；包含原边界筛选，不放宽已有断言。
2. A2：stride=1、stride>1、origin 回溯及重复峰，检查不满足条件时保留原计算；特别检查 `rep_norms[0]` 属于最终 `q`。
3. B2：预折叠对照原单符号点积组合，覆盖粗搜、四滞后尾部、同长度模板变更和复数模板回退；相关值满足误差门槛，已测选峰位置一致。
4. B1：完整峰列且准入满足时对照重跑；半径不匹配、弱峰或后续宽窗重试时不复用，检查实际诊断计数。只有使用相同输入、核与归约的复用分支要求结果逐位一致。
5. B3/B4：SIMD 相位累加对照原顺序参考；稀疏 NS-SFD 对照稠密参考，核对边界、极性、位置及度量。

统一误差口径：复相关/增益用 `abs(new-ref) <= 1e-6 + 2e-5*abs(ref)`，归一化 metric 与 `fit_residual` 绝对误差 ≤ `1e-5`，抽头相对 L2 ≤ `2e-5`。已测用例的 `q`、SFD 位置、状态、提交决策和已解码 bits 保持一致；归约变化可能改变模型哈希，不将 `model_id` 相等作为数值等价的替代证据。已有更严格的模块门槛继续保留，失败不以放宽门槛处理。

在独立 `build-sic-unified-round3` 构建后，确认实际加载新 build/lib，使用 `env -u LD_LIBRARY_PATH ctest --test-dir <build> -R "demod|sic|sfd|fast_rx|unified|discrete" --output-on-failure` 一次运行相关回归（当前约 12 项，以实际登记数为准）。沿用现有负样本和逐位旁路 QA，不另建矩阵。有后续修改时仅重跑受影响项。
