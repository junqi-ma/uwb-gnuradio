# FullPacket comparison contract v1

Implementation uses gr-uwb/build-sic-fullpacket. One generated case directory has public.json and windows/w000000 etc. Online public metadata only: sample_rate=998400000, n, roi_lo/roi_hi (coarse comm origin candidate search), observed_end (public ROI high + 8*1016 + guard; no truth), sensing_seed (public desired RX schedule), consumer_lo/hi (full output allowed region), target_lo/hi (desired SYNC CIR evaluation region). For first version consumer_lo=0,consumer_hi=n. Per-window raw.cf32, clean.cf32, sensing.cf32, interference.cf32 (latter three OFFLINE ONLY), comm_sync.cf32, comm_preamble.cf32, sensing_sync.cf32. Public templates can be shared at case root. sidecar.json holds injected parameters, comm_psdu_hex, sensing_psdu_hex, fields with absolute bounds and input hashes. Generator emits manifest.json with fixed cases and seeds; no oracle files read by C++ online runner.

C++ benchmark_fullpacket_compare --case CASE --out OUTPUT [--repeat N --warmup N --paced-rate HZ --paced-seconds SEC --mode both|preamble|full --dump-iq]. Reads public.json and window directories sorted; raw/template CF32 only. Runner JSONL OUTPUT/windows.jsonl contains window_id, source_window, mode, committed, reason, model_valid, model_id, observed_end, n, input_hash (runner SHA256 via orchestration or external verifier), comm_fcs, comm_psdu_hex, sensing_fcs, sensing_psdu_hex, sensing_status, times_us={estimate,comm_demod,validate,tx,channel,subtract,copy,sic_total,cir,sensing_demod,service}, events={required_sample,submit_us,start_us,finish_us,result_us}, support=[lo,hi]. Dump output to wNNNNNN_MODE.cf32 only when --dump-iq (functional runs). Models represented separately where needed. Preamble comm_fcs=null (no decoding). All totals include failed paths. Warmups excluded. No sidecar accessed by online runner. Hashes/provenance added by Python experiment driver outside timed section.

C++ uses boost property_tree to read JSON; manual JSON output. Atomic model reuse within each invocation is allowed only for shared immutable templates, NEVER cached model/decoded payload across input windows. Each mode separately estimates same frozen model, keeping compute comparison honest. Full mode decodes raw mixed IQ using detected origin, and then fullpacket_cancel; no desired-assisted retry. Consumer CIR/demod timing separate. Offline C verifier should recompute metrics from raw/clean and output; source_window joins truth. Non-dumped performance runs permit summary validation only, clearly labeled. Root driver owns orchestration and schema additions; communicate changes to agents.


## Implemented profile and timing clarification

The narrow legacy pulse with a 512-sample public ROI needs coarse_stride=1 in SIC and both demod profiles; stride14 can miss the correlation lobe. Both main groups share stride1 and unchanged .40/.25 gates. This is a new experiment profile; frozen algorithm source is unchanged.

Online C++ reads only raw IQ, public.json and templates in SIC modes. Explicit raw/clean reference modes are separate offline consumer baselines, never used to assist decoding or fit SIC. Full cancellation waits for the whole public context, a conservative policy; it is NOT an optimized exact-frame-tail admission implementation. Preamble first_clean_us refers to first available prefix, not a finished desired CIR or packet. Final result_us includes desired full demod and CIR. Offline runs are prebuffered; only paced runs have actual sample-origin waiting. Actual packet duration from sidecar is offline diagnostics only.

Stage timers are steady-clock service wall times. times_us.thread_cpu is total pipeline thread CPU from CLOCK_THREAD_CPUTIME_ID (includes consumer, excludes producer/queue/I/O). Both modes independently estimate every window. Timing/paced reuse16 independent source IQ windows for processing observations; rates and confidence bounds count unique packets separately. Do not interpret1024 replay observations as1024 independent payload trials.

The output region is the full context. Thus no_overlap means no overlap with desired target region; cancellation outside that region is allowed and should not be confused with no-interference exact bypass.

Rejected rows emit status only: their first_clean_us placeholder is not an IQ output timestamp and must be excluded from causality/latency output statistics. Accepted rows retain sample-ready causality checks. Archived paced results were rechecked with the corrected verifier without rerunning measurement.
