# S0 整改测量合同（R01 / R04，冻结）

依据 `docs/sic/S0_整改意见报告_2026-10-16.md`。本文件冻结 R01/R04 新增字段与 gate，
供 app 与 verifier 双方一致实现。R02/R06 将在此之上扩展，届时另附。

## 通用规则
- 评估区间由 **真值/生成器侧** 定义：完整重叠区间 `[overlap_lo, overlap_hi)`（真实
  干扰支持 ∩ sensing 处理窗）。**绝不**依据估计 mask 缩短到最有利区间。
- 零干扰能量（`||i||²==0`）时所有抑制度标为 **N/A**：不计入正样本效果统计，用
  `n_interference_windows` 与 `n_na_windows` 明确计数；禁止用约定的 60 dB 混入。
- 负样本按 **误 commit 与输出是否改动** 验收，不进入正样本抑制度统计。

## R01：以真实输出计算的消除指标（主 gate）

新增字段（`windows.jsonl` 的 `recon` 与 `summary.effect`）：
```
recon.nmse                     # ||i - i_hat||^2 / ||i||^2            （完整重构，保留为诊断）
recon.suppression_db           # -10 log10(nmse)                     （完整重构，保留为诊断）
recon.actual_nmse              # ||i - (y - y_clean)||^2 / ||i||^2   （真实输出，主指标）
recon.actual_suppression_db    # -10 log10(actual_nmse)              （主 gate）
recon.sub_lo, recon.sub_hi     # 实际应用的相减 mask [lo,hi)
recon.coverage                 # (sub_hi - sub_lo) / (overlap_hi - overlap_lo)
recon.uses_truth               # oracle 诊断单列，不计入效果 gate
```
- `delta_actual = y - y_clean`；`y_clean` 是 SIC 实际输出的 IQ。
- **主效果 gate 使用 `actual_suppression_db`**：中位数 ≥10 dB 且 ≥95% 窗 ≥3 dB；
  同时必须报告 `coverage` 与完整重叠区/确认相减区。
- 未 commit（旁路）窗口 `actual_suppression_db = 0`（或 N/A 视干扰能量），不得记为消除。

**独立复算所需数组**：`recon/window_*.npz` 必须包含 `y`、`y_clean`、`i`、`i_hat`
（与被评估窗口同长），供 verifier 从数组复算，**不从声明 mask 合成输出**。

**必须被正确判定的反例**（对抗测试）：
1. 完整 `i_hat` 很准（`nmse` 很小）但只相减小量符号 → `actual_suppression_db` 判不足。
2. 未 commit 但存在良好 `i_hat` → 不得记为消除通过。

## R04：目标保护使用未归一化 raw CIR / 固定投影

- 目标 ROI `[target_lo, target_hi)`（CIR tap 域）在**校准集**上固定，不得在 SIC 结果
  上重新寻找最有利目标。按 sensing profile 冻结并写入配置/hash。
- 使用 **raw（未逐窗 L2 归一化）复 CIR** 与固定参考尺度 `ref`（同窗 clean 或校准增益）。
- 新增字段：
```
cir_raw_target_amp_db          # 20 log10(|c_raw[target]| / ref)
target_amp_err_db              # 相对 clean 的绝对幅度误差
target_phase_err_deg           # 相位误差
target_peak_shift             # 目标 ROI 内局部峰位相对 clean 的偏移（work samples）
weak_target_detected           # 目标 ROI 内是否检出（相对本底）
false_peak_count               # 目标 ROI 外的假峰计数
```
- Gate：≥95% 窗 `|target_amp_err_db| ≤ 1 dB` 且 `|target_peak_shift| ≤ 1 work sample`。
- L2-normalized CIR 指标保留为**形状诊断**，不替代绝对幅度 gate。

**必须被正确判定的反例**：
3. 输出整体衰减、归一化形状不变 → 目标保护判失败。
4. 主峰保持但弱目标丢失/移动 → 目标保护判失败。

## 版本与一致性
- 功能、core、GR、native 使用同一 case/config/template/输入长度；差异显式标注。
- 生成 effective runtime config 与 hash，写入 manifest。
- 旧（normalized-only、mask-shaped）结果在报告中标注 superseded。
