## 1. 共同目标与范围

A：通信前导干扰感知前导，评价 accumulation 后的 sensing CIR。
B：感知前导干扰通信 payload，评价完整包解调/PER。
主网格固定 998.4 MS/s，1016 样点/Ipatov 符号，前导 64 符号。
暂不开展 native、UHD、FPGA、TWR、多干扰源或连续 1 GS/s。旧 native 11.89 dB 不作为本轮阻塞条件。
原始设计仍读根目录 UWB_Preamble_SIC_GNU_Radio_Design.md；旧 S1 报告是历史基线，不覆盖。

## 4. 数据/真值/可重复性合同

- y_raw=s+i+w，clean=s+w，SIC 输出 y_sic；三路共用同一 payload、信道、
  采样坐标、噪声 realization 和幅度尺度。原始 CF32，不逐路峰值/L2 归一化。
- 在线代码仅接收混合 IQ、公开 profile、公开粗搜索 ROI 和前缀可见性。
  注入起点/CFO/路径/干扰 IQ/目标位置真值仅在 sidecar 和离线 verifier；
  不通过真值动态收紧 ROI、设置起点、gain、mask 或门控。
- 真值 payload 可用于生成器和最终评分，不能供 SIC 或接收机判决使用。
  控制 seed：A calibration 11000000+，acceptance 12000000+；
  B calibration 21000000+，acceptance 22000000+；每 case 有确定性的互斥子流，
  payload/noise/path seed 分别记录。同一窗跨 N/三路配对重用是有意配对，
  不算独立样本；不同验收窗口不得误重用噪声/数据。
- 阈值、目标 ROI、SNR 点在 calibration 冻结后才运行 acceptance；
  发现问题重跑时保留历史 run，记录修改和是否已接触 acceptance，不能悄悄调参。
- ISR=10log10(P_i/P_s)，SNR=10log10(P_s/P_w)，均在事先定义的有效重叠区
  以信号能量定义，记录参考区/实际值。A 的 s 是 sensing；B 的 s 是 comm payload。
  无重叠/零能量为 N/A。B 同时记录所用 SNR 是样点 SNR，不冒充 Eb/N0。
- 每窗唯一 ID、失败状态、SIC commit/bypass、训练范围、支持覆盖、完整 frozen model
  fingerprint、原始 IQ 抑制度；所有失败均入分母，禁止只保留成功窗。

## 5. QA、构建与交付

新 GNU Radio block 非首选；如必须新增，先查本地相似 block、
说明类型及 scheduler、先写 QA、热路径预分配，然后构建/测试。
算法先参考 UWB_demodulation 下 buildUwbReference/decode_uwb/CIR 相关 MATLAB，
记录实际阅读的文件与对应语义。可用时做 MATLAB 对照，不用 Python 自洽代替独立验收。
保持 S1 core/adapter QA、既有 demod/radar 回归；不能放宽旧测试以容纳新结果。

每个方向先写设计/测试契约，再小 QA、smoke、正式矩阵、verifier、报告。
CLI 需真实可执行，提供 --help、--smoke、--self-test 或等效入口，以及 calibration/acceptance 选项。
计划中的命令必须标“待实现”，不要声称现有 CLI 已支持新选项。

每 run 保存 manifest（commit/dirty patch、所有相关源/库/exe/template/input hash、
有效配置、种子、CPU/flags、窗口长度）、逐窗 JSONL、汇总 CSV/JSON、图和索引。
每 cell 至少留 8 个固定规则选择的重构/原始复数组，并保留最差失败窗；
有选择偏差的最差窗不用于总体分布统计。小 smoke 全归档。
大数组放本方向 build/results，不提交几十 GB IQ；提交生成器、配置、verifier和文本报告。
archive_policy 明确归档数/总数及未归档窗口不能独立复算的限制。
verifier 不仅读 summary，要从归档数组独立复算并检查聚合一致；
增加故意错误产物的拒绝 QA（错分母、漏失败、错 ROI、错库、改数组）。
“实现/数据可复现通过”与“算法效果达到目标”分开报告；失败和未实跑均可正常交付，
但不得标全部效果验收通过。性能不可沿用 S1 历史数字作为新测量。

最终不自动合并，不自动推进硬件；提供自己的提交、测试/失败清单、可复制命令和报告。
