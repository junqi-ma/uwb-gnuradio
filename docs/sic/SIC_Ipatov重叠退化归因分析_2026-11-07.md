# Ipatov CIR 在 SYNC 重叠时的退化归因

**主因：code 9 sensing 在 code 10 相关器上的交叉响应被当作通信 CIR，并扩展到整包重构。** Ipatov 相关可以保留，但不能直接把混合信号的完整相关响应当作纯通信信道。

## 分解方法与结果

固定原 run 每窗的检测起点、CFO、6 个训练窗口和 128 点响应，利用 sidecar 对应的离线 IQ 分量分别计算 CIR：

`raw = comm + sensing + noise`

相关与卷积均为线性操作，故可分解 `g_raw = g_comm + g_sensing + g_noise`，并将每项与同一份未成形通信整包脉冲序列卷积。这里的分量真值仅供离线归因，不进入在线估计器。

16 个 sync_base 源窗按能量汇总：

| 项目 | 结果 |
|---|---:|
| 原 LS 路径实际输出抑制 | 35.63 dB |
| 新 Ipatov 路径实际输出抑制 | 19.63 dB |
| 只用独立通信分量相关，保留同样的起点和 CFO | 50.13 dB |
| sensing 污染项单独产生的误差能量 / 实际残余能量 | 99.914% |
| 噪声污染项单独产生的误差能量 / 实际残余能量 | 0.020% |
| 新旧起点差异 | 全部为 0 |
| 新旧 CFO 差异 | 全部为 0 |
| 检测起点相对注入起点误差 | 全部为 0 |
| 离线分解重构与实际重构的最大相对误差能量 | 4.95e-15 |

各误差分量存在交叉项，以上能量比不是严格可加的贡献百分比；交叉项很小，不影响主因判断。该离线复现从未修改生产代码。

## 为什么另一码进入 CIR？

设通信冲激序列为 s_c，感知序列为 s_s，含成形脉冲的响应分别为 g_c、g_s：

`y = s_c * g_c + s_s * g_s + noise`

用 s_c 相关并除以序列能量 E 后，结果包含：

`g_hat = (R_cc/E)*g_c + (R_cs/E)*g_s + noise_term`

R_cc 是自相关，R_cs 是交叉相关。不同 Ipatov code 在任意相对时延下并非交叉相关恒为零。sync_base 使用 code 10/code 9，第一窗 sensing 比通信晚 26 点，sensing 另有晚 37 点的路径。

本轮 CIR 中 sensing 污染的最大幅度约为纯通信 CIR 峰值的 3.94%–4.02%。多个虚假响应共同参与整包卷积，最终产生约通信能量 1.09% 的残余，对应约 19.6 dB 抑制。

## 为什么累加 6 个 SYNC 没有消除污染？

本格两路前导周期相同、相对延迟固定、注入 CFO 均为零。每次重复中的交叉响应相同，属于相干污染；重复累加会同时加强通信响应和这部分污染。噪声可被平均，确定性的交叉响应不会因增加重复数自动消失。

## 为什么旧路径明显更好？

旧路径在该格只保留 [-1,2) 的 3 个传播信道 tap，另由已知成形波形产生完整脉冲响应。新路径保留 [-8,120) 全部 128 点的含 shaping 响应，弱交叉响应也全部参与重构。

两种参数表示的 tap 数不能直接比较，但旧路径施加了更强的信道支持约束，减少将 sensing 投影误认为通信多径的机会。此次替换同时改变了估计方法与支持约束。

固定同样 6 个训练窗口，仅缩短新 CIR 范围，离线整窗抑制如下：

| CIR 范围 | 点数 | 抑制 |
|---|---:|---:|
| [-8,30) | 38 | 23.72 dB |
| [-8,56) | 64 | 21.79 dB |
| [-8,120) | 128 | 19.63 dB |

缩短范围可减少污染，但仍达不到旧路径的 35.63 dB，不能仅靠固定裁短解决；多径场景还需要足够长的响应。

## 补充：按相同 3 个信道参数比较

用户提出新旧都应使用 3 tap，公平性原则成立。但旧路径 3 个系数作用于成形波形；新路径 3 个采样点直接作用于冲激序列，会截掉 pulse shaping。旧 [-1,2) 三个延迟与 48 点脉冲卷积，对应 [-1,49) 共 50 点等效响应，并非 3 点等效响应。

固定已经估计的起点、CFO 和相关 CIR，在 16 窗上补做离线对照：

| 方法 | 整窗抑制 |
|---|---:|
| 旧路径：3 个信道参数 | 35.63 dB |
| 新相关 CIR：128 点全部保留 | 19.63 dB |
| 新相关 CIR：保留峰值及左右各 1 点，共 3 点 | 9.83 dB |
| 新相关 CIR：只裁到等效的 [-1,49) 共 50 点 | 23.13 dB |
| 新相关 CIR：约束为相同 3 个信道参数生成的响应 | **35.55 dB** |

最后一种只在相关结果所在的 CIR 域求 3 个系数：令 A 的三列为已知 48 点脉冲分别延迟 -1/0/1 后的响应，求 a=argmin ||A a-g_raw||²，再使用 g_projected=A a 重构。它不读取离线通信/感知分量，也没有重新扫描原始 IQ；支持位置固定为已记录的旧路径支持，因此是条件对照，不是新的在线支持选择算法。

结果支持：此次约 16 dB 退化主要来自放松物理信道约束、引入更多独立响应系数，不能由 128 点对 3 参数的结果认定 Ipatov 相关获取方式不适合。相同 3 参数约束下，新旧抑制基本一致。需要区分响应跨度与独立参数数目；仅裁成 50 点仍有 50 个独立系数。

非重叠 payload_base 对照：旧 51.87 dB，新 3 参数约束 51.90 dB；仅保留峰附近 3 点为 9.84 dB。此补充只验证消除效果，没有测该约束步骤的时间开销，也未修改在线路径。

数据与脚本：诊断目录下 three_tap_comparison.json、compare_three_taps.py。

## 为什么训练残差没有拦住？

新路径训练残差平均 0.0809，旧路径为 0.0903，新路径反而更低。混合训练区本身含 sensing；把它的一部分拟合进通信模型，也会降低训练残差。训练残差只反映对混合 IQ 的解释程度，无法单独证明 CIR 属于通信信号。当前继承的 0.8 门限也不会拒绝本格。

## 后续方向

保留 Ipatov 相关作为 CIR 获取方法，优先评估小规模 CIR 域脉冲子空间约束；本次同等 3 参数对照已恢复抑制。再扩展到未知支持、多径，或交叉码分离。若两路公开 code 均已知，可研究联合估计/交叉项抵消。先用本格检查 sensing 泄漏和真实输出残余，再验证分数多径响应是否被误删。单纯增加 SYNC 数量、放宽残差门限或固定裁短均不能保证解决。
