# S1 修改指示：八符号估计、冻结模型、全前导消除

日期：2026-10-17。执行对象：OpenCode。
基础：`feature/sic-research` / `fb77e52`；当前指示是开发任务，尚未实施。

依据：用户最新指示“使用 8 个符号估计出 CIR 之后，就可以直接减掉；硬件结构主要是 loop”，
以及 [S0 修改意见](S0_整改意见报告_2026-10-16.md) 和
[OpenCode 上轮整改结果](S0_整改开发报告_R01-R10.md)。

**优先级**：本指示对当前 S1 流程优先于旧 S0 的 fit/validation/support 耦合约定。
保留既有 QA 和原始结果，不静默重写历史合同；旧设计可作为显式 legacy 对照。

## 1. 本轮目标和核心决策

先在现有 GNU Radio 仿真中验证以下方法：

> 只用前 8 个 SYNC 的可见 IQ 检测并估计干扰时延、CFO、多径/复 CIR；冻结参数，
> 按已知的完整 comm 前导波形及名义长度循环重构、消除其余前导。

首 8 个符号可保存在有界缓冲中，参数可用后回溯清理；随后符号按冻结模型前向清理。
离线 PDU 实现也必须遵守相同数据依赖，不能因为持有整窗就用后续 IQ 改进估计。

**默认路径不再等待额外 52/56 个符号验证后才允许相减。**
默认准入依靠训练区检测/重复性、拟合残差、有限参数、真实 cond2(A)、配置和容量检查。
后续符号可以用于独立效果评估或只读监测，不反向改变基线模型。
可另外保留“8 个训练 + 8 个在线验证”的保守对照，但须显式命名和计入观察延迟，
不得作为默认路径的隐含前置条件。

本轮主场景仍为 sensing 接收端：code9 sensing 完整 RX 与 code10 comm SYNC 时间重叠；
单干扰源、64 SYNC、998.4 MS/s。先 work-grid，再验证 CG400 native。
通信接收端 payload 碰撞、UHD、FPGA/RFNoC 和连续 1 GS/s 实现不在本轮范围。

## 2. 为什么要这样修改

当前核心 `uwb_preamble_sic_core.cc` 仍按
`detected_start + confirmed*sps + post_tail` 限制支持，confirmed 又受 fit+validation 限制。
8/52 配置主动留下约 4 个 SYNC，覆盖率约 93.9%。

即使其余部分消除准确，6.1% 的原干扰残余也使整段抑制度约受限于 12 dB。
这不是 CIR/重构算法天然只能做到 10 dB。

上轮独立复核使用 `main_sweep_r10b` 名义 cell 的一个存档窗口：

| 操作 | 最终独立评估区实际抑制度 | 完整 sensing 解调 |
|---|---:|---|
| 原 8/52 实际输出 | 0.10 dB | cfo_failed |
| 不重新拟合，应用已有完整冻结 i_hat | 28.28 dB | success、FCS pass |

这只是诊断，不是 S1 已通过；但它反驳了“独立评估与完整消除不可兼得”的泛化结论。
冻结模型可以作用于未参与训练/门控的样点，独立评估检查其输出即可。

## 3. 必须分开的四个范围

| 范围 | 定义与用途 |
|---|---|
| acquisition/search | 获得干扰粗起点；基线只能访问当时可见的输入前缀 |
| training | 到达起点后前 8 个 SYNC 的合法可见样点，估计所有模型参数 |
| cancellation | 名义完整前导支持与本端公开处理 ROI 的交集，含有定义的成形/多径拖尾 |
| evaluation | 训练后的保留符号，离线用真实输出评估，不向训练和默认准入反馈 |

**评估区需要被消除，不是需要留着不减。**
“不参与训练”与“不能应用训练所得模型”没有关联。

主配置：training 为 repetition `[0,8)`；independent evaluation 为 `[8,64)`。
额外把末 4 个 SYNC 单列为 tail-eval，以直接覆盖旧缺陷。
在可选 online-validation 对照中，训练 `[0,8)`、验证 `[8,16)`、独立评估 `[16,64)`；
相减仍覆盖全部前导，而不是只有训练/验证部分。

名义长度、code 和模板属于公开 profile，可以用于预测未来波形；真实注入起点、CFO、
路径、ISR、干扰 IQ 和真值边界只能用于生成器/verifier，禁止传入估计/相减策略。

## 4. 八符号模型估计与冻结

### 4.1 可见性和起点

增加明确的 `observed_end_sample` 或等效 prefix API。训练函数只能读取该位置之前的 IQ。
禁止让全窗粗相关、重复确认、CFO 或 CIR 局部相关读到评估区后再宣称只观察了 8 个符号。

注意现有“最后一个训练重复 + 1016 点模板 + 正 lag”的相关可能越过训练末端。
只使用完全落在可见区间内的相关/LS 行；不足就减少相关重复数或报告 unavailable。
若确需额外 guard，单列实际样点数/观察时间，不能继续标作严格 8-SYNC 模式。

起点检测应在可见前缀内完成；已知 sensing 的本端计划可用于公开粗 ROI，但不得
利用仿真 comm 起点作为 seed。前导从中间进入窗、周期编号不确定时显式 partial/
ambiguous 或旁路，不冒称完整前导起点已被观测。

### 4.2 估计内容

- CFO：仅训练区复相关峰相位，不能继续使用 fit+validation 或完整 64 符号。
- CIR/路径：训练区估计候选路径，distinct Top-K，默认 K=4；复增益而非幅度峰。
- 分数时延：只优化训练区损失，保留现有有界搜索；记录实际分辨率和成本。
- 增益：保留已整改的 Householder QR + QR 因子 Jacobi SVD/cond2 判定，不恢复
  正规方程或对角比值的错误条件数约定。
- 脉冲、码、前导长度及有限成形模板来自冻结 profile；保留自然尾部。

生成 immutable `SicModel`（名称可按仓库规范调整）：

```text
model_id/config_hash/template_hash
origin_integer + fractional_delay[k]
gain_complex[k], path_count
cfo_hz, phase_reference_sample
sample_rate, nominal_sync_reps, samples_per_symbol
predicted_support_lo/hi, support_source
training_lo/hi, observed_end_sample, estimation_ready_sample
fit_residual, cond2, quality/status
```

训练后这些字段冻结。不得在 apply 阶段通过后续 y 更新 CFO、时延、gain 或路径数。
本轮不增加隐式 PLL、在线 SFO 跟踪或反复重拟合；如未来研究它们，另立对照模式。

### 4.3 名义支持与失配

主模式允许由“检测到的起点 + 已配置名义 64-SYNC + 模板/路径拖尾”预测相减支持，
标注 `support_source=configured_nominal_prediction`。它不是实测完整 64 个符号边界。
不要求先扫描完 64 个符号才应用已知波形，也不允许只因训练了 8 个符号就把支持截为 8。

profile 错误、实际短前导、突发中断、信道时变和 CFO 漂移属于外推风险，须做压力实验。
可选监测若发现异常，只停止/降级未来输出并报告；已提交样点不能被事后“撤回成功”。
离线整窗 trial/commit 与可因果输出的模式须分开报告，不拿全窗事后否决掩盖实时风险。

## 5. 全前导相减与硬件 loop 对应关系

冻结后重构：

```text
i_hat[n] = exp(j*omega*(n-n_ref)) * sum_k h[k] * p_full(n-origin-tau[k])
y_clean[n] = y[n] - i_hat[n]     # 仅在许可相减区内
```

相位常数应与训练 gain 的参考一致，避免重复补偿或重新从零开始相位。
`p_full` 是有限长前导及成形拖尾；稳态中可用 repetition/template index 循环，
首尾必须处理瞬态，不能无限重复首个被截尾的 1016 点模板。

实现建议：拆成 `estimate_model(prefix, config)` 和 `apply_model(model, chunk, offset)`。
现有 PDU adapter 可以继续接受整窗，内部先限制 prefix 估计，再分块回放 apply；
无需本轮新建连续流 block。首 8 符号缓冲回溯清理后与其余输出按原样点顺序交付。

apply 热路径预分配、无堆增长、无读盘和逐点 sin/cos；CFO 相位递推并周期性绝对重锚。
保持跨 chunk 的模板索引、分数时延、CFO 相位、首尾状态连续；分块边界不得重置相位。
旁路和 mask 外逐位不变，窗口长度和时间坐标不变。

用户所说的硬件 loop 可映射为模板地址/重复计数器、分数相位选择、K 路复乘累加、
CFO 旋转、IQ 相减及对齐 FIFO。**这是冻结后 apply 的结构，不代表训练/求解也只是
一个简单 loop**。硬件吞吐还取决于 K、插值形式、每拍样点数、存储带宽和流水并行。
本轮只给结构/操作量和 CPU 实测，不实施 FPGA，不承诺接近 1 GS/s。

## 6. 本轮同时关闭的遗留问题

### S1-01：相减支持解耦（对应 R02/R06）

删除相减长度对 fit/validation/confirmed 计数的隐式依赖；独立存储预测/确认支持、
许可 ROI、训练与评估范围。默认严格 8-SYNC 训练，取消自动扩大 validation 来获得覆盖。
旧 `--sic-cover-preamble` 只能作为 legacy 对照或迁移为清楚的新模式，不能继续
充当“必须训练到尾才减到尾”的开关。

### S1-02：同配置的功能与性能（对应 R03）

效果、core、GR、CIR、完整 demod、native 使用同一 `estimate8/frozen/full-support`
模式及配置 hash。使用真实 code9/code10、脉冲、完整 sensing RX、ISR/SNR 和样点长度。
不得把旧 8/56 的成功/速度归到新 8-SYNC 模式。

### S1-03：纯目标路径的定速测量（对应 R09）

上轮 `paced_r09b` 实际仍执行 clean/raw/SIC 三路消费者，并在提交循环内做离线评估。
因此约 9.86 窗/s 不是纯 SIC→CIR 路径容量，R09 不应直接写 CLOSED。

新的正式 paced 模式默认只运行目标路径；把配对效果评估、Python 重复扫描、数组
复算/绘图/大量落盘放到计时环外。预生成至少 64 个不同内容窗口，保持有界 credit。
记录绝对计划提交、实际提交、终态、入口积压、worker queue、未提交和 deadline miss。
不能用处理完成后才提交下一窗来降低实际负载；容量不足按原计划记录失败。
非计时评估程序不得在后台争抢 CPU，从而污染正式性能测试。

### S1-04：独立验收数据

上轮主矩阵 72 个 cell 实际都使用 calibration seeds。冻结阈值/profile/目标 ROI 后，
正式效果和负样本使用 acceptance seeds；训练参数调优只用 calibration。
记录实际使用 seed 集而非仅证明两个名单不相交，校验没有重用窗口或噪声。

### S1-05：实际效果、目标保护、真值边界（保留 R01/R04 成果）

主指标继续为 `i-(y-y_clean)` 的实际残余，完整 i_hat NMSE 仅作重构诊断。
独立评估区和末 4-SYNC 区都计算**实际输出**抑制度，而不是仅计算重构误差。
零干扰抑制度为 N/A；负样本看误 commit/输出改动。目标保护使用 raw complex CIR，
冻结目标 ROI，保留弱目标幅度/相位/局部峰位/检出率，不能退回归一化幅度。

### S1-06：版本与报告（对应 R10）

上轮报告与产物存在次数/数值不一致，real benchmark 表的库/可执行文件 hash
也不等于最终构建。新实验必须在冻结后的同一构建运行，保留准确 source/config/
template/input/library/executable hash，标明 dirty patch，不事后猜测或补写测量版本。
重建后需要重跑的正式结果不得沿用旧 hash，历史 run 标 superseded。
`index.json` 必须引用真实最新 run；报告不再出现“全部关闭但含 OPEN”的自相矛盾。
MATLAB、native、性能目标未完成时分别列明，不通过修改报告把它们关闭。

## 7. 针对性 QA 与关闭标准

先新增下列 QA，再实现对应改动；每次有意义修改构建/测试。

| 测试 | 必须验证 |
|---|---|
| prefix 隔离 | 修改/清空训练后的 IQ，不改变已冻结模型；检测/相关/插值无越界偷读 |
| CFO 隔离 | 修改后续相位/CFO 不改变训练估计；独立区效果随失配真实变差 |
| full support | 固定训练 8 SYNC，64-SYNC 输入不再仅消除 8/16/60 个符号 |
| 独立尾部评估 | 末 4-SYNC 已实际相减，不再维持约 0 dB；有原始数组可复算 |
| chunk 不变性 | 整窗、固定分块、随机分块的输出在冻结容差内一致，坐标/相位连续 |
| 前导边界 | 起点±偏移、分数时延、有限模板拖尾、窗口裁切无越界；名义支持与实测支持明确区分 |
| 外推失配 | 实际短前导、突发中断、错长度、相位跳变、SFO/时变信道；测过减与目标损伤，不仅看检测通过 |
| bypass | 无干扰、错码、不可信模型和无许可重叠时输出逐位不变 |
| 数值安全 | 原 R05 条件数反例、近相关列、不同尺度/列置换仍通过独立参考 |
| 生命周期 | credit/字节预算/queue-full、异常、stop/drain、唯一终态及顺序保持 |

数据依赖测试比较完整模型参数（包括 delays、complex gains、CFO、support 和准入状态），
不能只比较 n_paths/committed 等少数字段便宣称整个模型独立。

主效果集沿用 ISR=0/10/20 dB、offset=0/0.4/8/−8、CFO=0/±50 kHz、single/four-path，
每 cell 100 个 acceptance 窗。先名义 smoke、再小矩阵、最后全矩阵；失败先定位。

**本轮工程目标**：

- 名义 ISR=10 dB、SNR=30 dB、单径配置：完整重叠区、独立区、末 4-SYNC 区的
  实际抑制度中位数均≥20 dB；以≥25 dB 为优化目标，不能拿重构抑制度替代。
- 主矩阵继续按原 S0 的每 cell 中位≥10 dB、≥95% 窗≥3 dB 和目标保护门槛报告，
  同时明确是否达到新的 20 dB 名义目标；不得降低旧门槛。困难条件失败需保留。
- 名义静态配置实际重叠区覆盖≥99%，未覆盖的边缘/拖尾须解释，不能以缩小评估区获通过。
- 名义 100 窗报告 clean/raw/SIC 的完整 PSDU/FCS；目标为 clean 与 SIC 均 100/100，
  并报告所有 failure stage，不把平均功率改善当作解码成功。
- 负样本 acceptance 至少 1000 窗/可行动类别，误 commit≤1%，旁路逐位一致，报告置信区间。

新增名义目标是本轮验证目标，不是已实现能力，也不是 UWB 的统一通信标准。
30–40 dB 及 PER–SNR 曲线是后续研究方向；本轮不以此自动扩大范围。

## 8. 时间和算力必须重新拆分

分别报告：acquisition、8-SYNC 参数估计、模型准备、首 8-SYNC 回溯、后续 apply、
adapter/队列、CIR 和完整解调。apply 用 ns/sample、Msample/s、每 K 的操作量计量，
不能把训练开销平均到所有样点后隐去启动延迟。

998.4 MS/s 下 8×1016 样点约 8.14 µs，只是波形观察时间，**不是 CPU 参数就绪时间**。
算法可见性、设备/传输、采集分块、调度及计算延迟分别测；PDU 模拟不直接证明硬件时延。
基线假设一次前导内信道/CFO 足够稳定；实测 8 符号 CFO 精度不足时写明，而非偷读后续。

同一真实输入/config 下，先单 worker core，再 GR、SIC→CIR、SIC→full demod，最后 native。
200 warmup、至少 64 个不同输入轮换，正式性能每配置≥10000 窗、3 轮，串行执行。
定速先 100/s、再 200/s，60 s；达到目标后才做 10 min。失败单列，不无限等待。
无碰撞、10% 碰撞和全碰撞分开，模型准备与重构的条件成本不能只用平均触发率掩盖。

原低延迟目标仍保留：SIC mean≤0.5 ms/P99≤1 ms，200/s 的 CIR 终态 P99≤5 ms。
达不到也必须交付完整结果和瓶颈，不允许更改负载/判据后写通过。
最终比较“8-SYNC 严格训练”与旧 cover 模式的精度、观察时间、训练成本、apply 成本，
不能预先宣称少看符号一定达到实时。
